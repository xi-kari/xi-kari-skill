# 两场共学活动的可审议安排

本题所有人物、预算和时段均为 `synthetic` 教学设定。没有向任何人发送消息、预订场地或实施活动。使用[安排设计工作流](../../../references/output-modes/arrangement-design.md)。

## 用户请求与完整源材料

请求：只依据以下条件，为同一天的两场共学活动写完整安排草案并说明取舍。当前只需要草案。

**A1，任务。** 甲班、乙班各需60分钟，分别有6位参与者；每场必须有两名合格志愿者同时在场。任务目标是当天完成两场，不能以合并内容代替。参与者均已表示14:00—17:00内可参加，但尚未收到具体分场时间。

**A2，资源。** 唯一两名合格志愿者为甲、乙，可用时段均为14:00—17:00。场地有两间房，但没有其他合格人手。可只用一间房；首次准备、两场之间复位、最后收整各需两人共同工作15分钟。每场材料费20元，可用预算100元；本题不设其他费用。

**A3，现行约定。** 尚未对外承诺两场必须同时开始，允许提出错峰草案。甲可做主讲与报名联络，乙可做协助与器材检查；两人均可提出停止。正式采用须由组织者按现行程序确认，当前用户只授权起草。

## 完整成果示例

### 建议当天错峰两场，保留15分钟余量

在所给条件下，两间房不能解决人员冲突：若两场同时进行，共需四名合格志愿者，现有两人不能重复计算。错峰能保留当天完成两场的目标，也符合参与者声明的可用时间。因此建议使用一间房依次开展，第二间不作为默认扩容依据。

另一种安排是当天只办一场、另一场改期，能减少当天工作量，但会使原定当天完成两场的任务未完成；新日期的人员和参与者条件还未取得，当前不能把它列作同样已可行的替代。如果两名志愿者当天不能维持所列时段，再重开这一改期方案，比虚构新增人手更合适。

### 供组织者审议的活动约定

拟议日程如下。所有时段都在已给的人员和场地窗口内，不假设提前到场或活动结束后继续无偿兜底。

| 时段 | 事项 | 同时占用 |
|---|---|---|
| 14:00—14:15 | 准备场地与材料 | 甲、乙 |
| 14:15—15:15 | 甲班活动 | 甲、乙 |
| 15:15—15:30 | 复位与下一场检查 | 甲、乙 |
| 15:30—16:30 | 乙班活动 | 甲、乙 |
| 16:30—16:45 | 收整与记录 | 甲、乙 |
| 16:45—17:00 | 预留处理短延误 | 仅在需要时使用 |

组织者确认后，由甲联络两班参与者，告知各自时段并核对是否出现新的不可参加情况。乙核对器材和两份材料包；甲负责内容准备与报名变化，乙负责场地检查，双方在14:00共同核对是否满足开场条件。这些是拟议分工，尚未发生的联络不能写成已经确认。

两场材料预算合计40元，余下60元仍是预算余额，不等于已经花费，也不能自动购买未批准的服务。若出现其他费用，重新核预算和采用程序。完成记录分别保存实际开始、结束、到场与异常，不能仅凭报名名单宣称全部参与者已获得预定学习效果。

若一名合格志愿者缺席，或器材问题使所需条件不成立，不启动只有一人支撑的活动。若延误超过15分钟余量，必须重新比较剩余时段和两场完整时长，不自动压缩课程或延长志愿者到17:00以后。停止或改期时，说明哪场未完成及后续仍需确认的安排；不能把通知已发当作改期已被所有人接受。

### 可行的范围与仍需兑现的部分

上述安排使用165分钟完成准备、两场活动、复位和收整，留下15分钟余量；在给定模型中，两名志愿者没有重叠承诺。它支持的是所列时间、人手与材料预算的可行草案。实际采用、通知、到场和活动结果仍需各自证据。当前已经完成用户要求的起草任务，无须因尚未获得实际采用确认而拒绝交付草案。
