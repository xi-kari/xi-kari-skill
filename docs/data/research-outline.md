# Xi-Kari 研究大纲

当前以框架 8.3 为对照。以下问题用于逐项回看理论、思想与人类经验，不预设必须产出新版本。

完成状态请以项目介绍页统一发布的研究进度为准。

## 01 框架自身、理论借用与解释权

- [ ] **01.01 原始问题与目标变化**：从社群观察、承担者处境到广义结构解释，哪些问题被保留，哪些被后来的理论目标替换？
- [ ] **01.02 概念、隐喻、机制与定理的身份**：同一借用究竟提供观察角度、定义、可检验机制还是形式推论；身份何时被不自觉抬高？
- [ ] **01.03 主动取舍与历史空白**：哪些接受和拒绝有明确原文，哪些只是今天的重构；未提及是否被误写为主动舍弃？
- [ ] **01.04 解释优先次序与理论殖民**：结构、利益、权力、心理、文化、技术是否在证据之前取得主因地位；什么观察能改变排序？
- [ ] **01.05 框架本体、应用层与工具层**：领域术语被抽象后是否仍暗带原领域假设；保护核心是否会变成拒绝修正核心？
- [ ] **01.06 边界、同一性与圈层建构**：划定对象对什么任务有用；分组、命名、成员关系与共同意愿怎样分别确认？
- [ ] **01.07 反例、失败、替代与退出**：反例是否实际改变理论；增加例外与承认失效的界线在哪里？
- [ ] **01.08 思想框架与 Skill 工程包装**：理论复杂度、阅读完整性、执行负担和输出可读性各自承担什么功能；程序何时接管理解？

## 02 知识论、科学哲学与理解传统

- [ ] **02.01 经验论与理性论：休谟、笛卡尔等**：经验归纳与推理一致性各能支持什么；观察不足与逻辑缺口怎样分别处理？
- [ ] **02.02 证伪、范式与研究纲领：波普尔、库恩、拉卡托斯**：什么应被反驳，什么属于背景承诺；范式变化是否被误写成任意换框架？
- [ ] **02.03 实用主义：皮尔士、詹姆斯、杜威**：有用、可行动、可纠错与为真是什么关系；短期有效会遮蔽什么？
- [ ] **02.04 实在论、建构论与批判实在论**：对象独立性、分类的社会作用与知识位置能否同时保留；何时需要避免两极化？
- [ ] **02.05 现象学：胡塞尔、海德格尔、梅洛-庞蒂**：第一人称经验、身体、时间和生活世界怎样进入分析；被结构转译后丢失什么？
- [ ] **02.06 解释学：狄尔泰、伽达默尔、利科**：理解意义与识别因果各回答什么；当事人解释与分析者解释如何相互纠正？
- [ ] **02.07 语言、概念与语境：维特根斯坦、奥斯汀等**：词语在不同实践中是否同义；命名和言说是否也在改变对象与关系？
- [ ] **02.08 认识不正义与位置性知识**：谁的证言容易被降权，谁的经验缺少可表达词汇；如何不把保护弱信号变成免于核查？

## 03 因果、测量、比较与历史证据

- [ ] **03.01 相关、因果与机制识别**：时序、通道、共同原因和反事实分别需要什么证据；机制故事何时仍只是候选？
- [ ] **03.02 实验、自然实验与观察研究**：识别条件、外推、伦理和测量反应有什么差别；不能实验时还可以知道什么？
- [ ] **03.03 案例研究、过程追踪与比较历史**：怎样避免只选择适合框架的成功案例；历史独特性与可比较机制如何共存？
- [ ] **03.04 统计建模、贝叶斯更新与不确定性**：先验、似然、模型选择和缺失如何区分；何时只能给方向而不能给概率？
- [ ] **03.05 测量效度与代理指标**：指标究竟测到了目标还是替代物；跨群体、跨时间、跨文化的量尺是否保持意义？
- [ ] **03.06 古德哈特与坎贝尔问题**：评价指标如何改变行动和信息生产；怎样区分测量失真与真实行为适应？
- [ ] **03.07 复现、发表偏差与经典实验争议**：米尔格拉姆、斯坦福监狱、棉花糖、旁观者和启动效应等各有哪些原始证据、异议与适用界线？
- [ ] **03.08 史料、档案、口述史与沉默**：谁留下记录，谁被档案抹去；后见之明、幸存者偏差和叙事整齐性如何影响结论？
- [ ] **03.09 考古、物质文化与无文字社会**：遗物、遗址、环境资料和口述传统各能支持什么；缺少书面档案是否使某类人的历史被遗漏？

## 04 系统论、控制论与复杂性

- [ ] **04.01 一般系统论与系统思维：贝塔朗菲、梅多斯**：边界、关系与反馈提供什么新增解释；何时“系统”只是重新命名？
- [ ] **04.02 控制论：维纳、阿什比**：目标、反馈、必要多样性、控制能力与自主性如何区分；谁有权定义目标？
- [ ] **04.03 二阶控制论与观察者反身性**：观察与诊断如何改变被观察者；如何区分观察效应、策略反应和基线变化？
- [ ] **04.04 复杂适应系统与涌现**：局部互动何时产生总体模式；涌现是否被用来跳过具体机制？
- [ ] **04.05 网络耦合、级联与非线性**：阈值、放大、同步与崩溃需要什么条件；是否把每次剧变都解释成临界点？
- [ ] **04.06 韧性与适应循环：Holling 等**：恢复何种功能、为谁恢复、以什么代价；维持有害秩序是否也可能具有韧性？
- [ ] **04.07 路径依赖、锁定与滞后：Arthur 等**：过去通过什么载体改变现在；控制当前状态后历史仍有何增量？
- [ ] **04.08 组织生态与系统生命周期**：进入、增长、死亡和替代是否具有共同机制；阶段图何时误成必经命运？
- [ ] **04.09 可观测性与测量盲区**：哪些内部状态可由现有观测区分；沉默、无记录与状态未变能否被误认为同一件事？
- [ ] **04.10 可控性与真实干预能力**：能够识别问题是否意味着有可用的干预手段；权限、通道、时延和副作用如何分别约束？
- [ ] **04.11 好调节器定理与内部模型**：形式定理的前提能否迁入治理；调节者需要何种模型，不能从理论名称推出什么？
- [ ] **04.12 系统动力学、库存、时滞与过冲**：库存、流量、多重时钟与反馈延迟怎样产生反直觉后果；机制错配与信号失真如何区分？

## 05 信息、形式理论与跨尺度方法边界

- [ ] **05.01 Shannon 信息论、信道与噪声**：信息量与意义、真假、价值有何区别；把社会沟通视作信道遗漏什么？
- [ ] **05.02 压缩、表示与有损转义**：哪些差异为任务所需；表示变换、尺度变化与现实关系变化怎样分开？
- [ ] **05.03 熵、耗散结构与社会秩序类比**：物理量需要什么单位和系统条件；社会失序是否有资格被叫作熵增？
- [ ] **05.04 守恒、势场、力与承载的借用**：这些词是量化模型还是表达工具；跨类型成本能否合并或宣称守恒？
- [ ] **05.05 哥德尔、不完备性与可计算性**：形式定理的对象和前提是否在框架中成立；承认盲区是否需要借用这些定理？
- [ ] **05.06 有效理论、尺度闭合与粗粒化**：什么被保留、消去或变成未知；宏观变量何时不足以支持预测和干预？
- [ ] **05.07 信息本体、量子与宇宙类比的历史退场**：旧信息基底、涌现层级与物理拼接为何进入又退出；哪些方法启发可独立保留？
- [ ] **05.08 模型选择、简约与表达能力**：较少概念是否更好，较多变量何时有增益；简化的损失由谁承担？

## 06 人性、演化、文化与能动性

- [ ] **06.01 人性论、性善性恶与情境论**：稳定倾向、制度条件和规范判断是否被混为一谈；哪些争论实际问的是不同问题？
- [ ] **06.02 自然选择、适应与漂变**：功能适应解释需要什么比较；存在、流行或幸存是否被误当更优？
- [ ] **06.03 文化演化与双重继承：Robert Boyd、Peter Richerson 等**：遗传、学习、传播、制度保留怎样区分；文化适应是否一定有利于个人？
- [ ] **06.04 合作演化、亲缘与互惠**：亲缘、互惠、群体过程与制度激励分别适用于何种对象；不能互相替代哪些证据？
- [ ] **06.05 人格差异与情境交互**：个体差异何时是主要解释而非残差；跨情境稳定性应如何检验？
- [ ] **06.06 意图、自由、责任与行动能力**：受约束是否取消能动性；因果解释为何不能直接决定责任和免责？
- [ ] **06.07 习惯、身体实践与环境塑造**：行动怎样在反思之前形成；改变环境与改变习惯有哪些不同条件？
- [ ] **06.08 超越激励的行动与反还原**：承担、创造、拒绝和无偿给予能否被穷尽为效用；如何避免把解释残差神秘化？

## 07 认知、判断与决策

- [ ] **07.01 有限理性与满意化：Simon**：注意、时间、信息与计算约束如何改变选择；最优化是不是必要假设？
- [ ] **07.02 启发式、前景理论与框架效应：Kahneman、Tversky**：损失、参照点和表述怎样改变判断；哪些结果可跨场景迁移？
- [ ] **07.03 自然情境决策与专业直觉**：经验在何种反馈环境中可靠；熟练自信与实际能力如何区别？
- [ ] **07.04 信念更新、动机性推理与认知失调**：维护身份与修正事实如何冲突；怎样辨别推理错误和不同信息基础？
- [ ] **07.05 情绪、风险知觉与身体状态**：情绪何时提供相关信息，何时限制行动；不要把情绪一概降为噪声。
- [ ] **07.06 注意力、记忆与时间偏好**：稀缺、疲劳、即时压力和长期承诺怎样作用于同一决定？
- [ ] **07.07 群体决策、群体思维与群体智慧**：信息独立性、权威和异议怎样影响汇总；多数与平均为何不自动可靠？
- [ ] **07.08 可逆选择、试探与信息价值**：等待、行动、退出和小规模试探怎样比较；不行动的成本如何进入？

## 08 发展、人格、创伤与心理解释

- [ ] **08.01 发展心理学：皮亚杰、维果茨基、埃里克森**：阶段、社会支持和能力形成如何解释变化；阶段论何时过度统一人生？
- [ ] **08.02 依恋、关系安全与分离：Bowlby、Ainsworth**：关系模式有哪些证据；依恋类型能否被越界用作人格标签？
- [ ] **08.03 心理动力与无意识：弗洛伊德、荣格及其批评**：解释传统、临床方法与可检验命题是什么关系；不能用叙事自洽替代证据。
- [ ] **08.04 学习、强化与习得性无助**：奖励、惩罚和可控性如何改变行为；表面顺从是否意味着接受？
- [ ] **08.05 创伤、应激、解离与恢复**：个体、关系与制度的伤害通道如何分开；哪些判断需要专业证据？
- [ ] **08.06 家庭系统与代际传递**：代际重复经由资源、教育、互动、制度还是生物途径；不把相似经历直接当遗传。
- [ ] **08.07 复原、治疗与社会支持**：恢复功能、减少痛苦、获得安全和满足规范分别是谁的目标？
- [ ] **08.08 诊断分类、神经多样性与污名**：分类何时帮助获得支持，何时生产排斥；当事人如何参与命名与拒绝？
- [ ] **08.09 多迷走神经与身体取向理论**：原理论、支持证据、争议与临床应用之间有哪些不同层次；身体经验不能被哪种单一生理故事代替？
- [ ] **08.10 精神动力学人格结构的具体模型**：分类、解释和治疗假说分别怎样受到检验；不得把一种临床传统当作人的本体定义。
- [ ] **08.11 内部家庭系统 IFS**：部分、自我与内部关系是什么性质的概念；隐喻、治疗过程和经验机制的边界在哪里？
- [ ] **08.12 认知行为治疗 CBT**：认知、行为、情境和学习机制分别承担什么解释；不同问题与人群的证据能否合并？
- [ ] **08.13 辩证行为治疗 DBT**：接纳与改变、情绪调节和关系技能如何连接；理论取舍与具体适用证据怎样分别研究？
- [ ] **08.14 EMDR 与经验整合**：不同组成环节的效果和机制如何区分；哪些是理论假说、哪些已有独立研究支持？
- [ ] **08.15 心智化与心智化治疗**：理解自己与他人心理状态的能力如何形成和变化；误读、投射与关系安全怎样分别研究？
- [ ] **08.16 图式治疗**：早期经验、持续模式和当下情境如何连接；图式是否被过度固定成人格标签？

## 09 爱、照护、存在与生命意义

- [ ] **09.01 爱作为经验、关系与行动**：爱的描述、动机解释和价值承诺有什么区别；能否不把它当效用或残差？
- [ ] **09.02 照护伦理：Gilligan、Tronto 等**：依赖与责任怎样分配；照护者和被照护者的自主性怎样同时保留？
- [ ] **09.03 承认、尊严与主体间性：Hegel、Honneth 等**：承认怎样使行动成为可能；承认关系是否也会依赖服从？
- [ ] **09.04 存在主义、荒诞与意义：Kierkegaard、Sartre、Camus、Frankl 等**：人如何面对未定、失败和意义断裂；意义不能仅以系统功能衡量。
- [ ] **09.05 死亡、哀悼、记忆与终结**：个体死亡、关系终止、组织退场有哪些不可互换的意义；告别是否必须被解释为修复？
- [ ] **09.06 牺牲、礼物、奉献与自我消耗**：自愿、不能拒绝和结构性抽取如何区分；付出越多是否被误当越有价值？
- [ ] **09.07 希望、信仰、承诺与未来**：希望怎样支持行动而不成为强迫坚持；什么使承诺可以修订？
- [ ] **09.08 孤独、归属、友谊与亲密**：群体归属为何不能替代被理解；保留个体距离与形成关系如何并存？
- [ ] **09.09 痛苦、幸福、欲望与生活质量**：快乐、满足、意义、尊严和免于伤害能否分开评价；任何单一幸福指标会遗漏什么？

## 10 伦理、正义、权利与公共理由

- [ ] **10.01 德性伦理、义务论与后果论**：人物品质、行动义务和后果评价分别回答什么；不能把不同问题压成单一排名。
- [ ] **10.02 功利主义与价值可通约性**：总体收益可以合并到什么程度；少数伤害与权利能否用平均值抵消？
- [ ] **10.03 正义、公平与制度选择：Rawls 及其批评**：规则从什么位置选择；机会、资源、结果与基本自由如何冲突？
- [ ] **10.04 能力方法：Sen、Nussbaum**：资源、能力、实际生活与主体选择有什么区别；谁决定值得追求的能力？
- [ ] **10.05 自由、非支配与共同体**：免于干预、自主行动、免于任意权力和归属义务怎样比较？
- [ ] **10.06 人权、文化差异与普遍性**：权利如何被论证、解释和落实；不能用文化解释取消伤害，也不能抹掉处境差异。
- [ ] **10.07 责任、补救、代际与生态正义**：致因者、获益者、有能力者和授权者的责任怎样分别成立？
- [ ] **10.08 道德困境、悲剧性选择与不可比**：没有无损选项时怎样说明代价、异议和剩余义务；程序通过是否仍留伦理负债？

## 11 中国思想与实践传统

- [ ] **11.01 儒家仁礼、角色与关系：孔子、孟子、荀子**：关系义务、修养、秩序与批判权力怎样共存；角色不能直接生成无限承担。
- [ ] **11.02 道家：老子、庄子**：无为、自然、齐物与有限知识如何理解；不行动何时是智慧、何时是卸责？
- [ ] **11.03 墨家：兼爱、非攻与尚贤**：普遍关怀、功利考量和组织纪律怎样相互限制？
- [ ] **11.04 法家：法、术、势**：可预期规则、权力技术与支配有什么关系；秩序效率怎样与主体保护冲突？
- [ ] **11.05 兵家与战略：孙子等**：势、知彼、虚实、成本和不战如何用于理解互动；何时军事化语言污染日常关系？
- [ ] **11.06 宋明理学与心学**：格物、知行、良知与主体修养怎样连接公共实践；内在确信如何接受纠错？
- [ ] **11.07 经世、民本、制度与地方实践**：为民、治理能力和参与权怎样分别理解；善意治理是否替代当事人决定？
- [ ] **11.08 周易、时位与术数的取舍**：历史借用的是时序、条件和变动组织，还是形而上及预测前提；二者怎样切开？

- [ ] **23.02 父权制、性别分工与社会再生产**：家务、生育、照护和就业之间的成本怎样分配与被看见？
- [ ] **23.03 女性主义诸传统**：自由主义、社会主义、激进、交叉性与关怀取向各提出什么问题；不能合成单一女权立场。
- [ ] **23.04 亲密关系、冲突、暴力与退出**：依赖、控制、沟通失败和安全威胁如何区别；关系维护是否压过人的保护？
- [ ] **23.05 儿童、成长、代际权力与自主**：代理决定何时保护、何时剥夺；儿童的表达能力如何进入证据？
- [ ] **23.06 身体、性、规范与自我决定**：医学、道德、市场与亲密规范如何塑造身体；差异如何被病理化或商品化？
- [ ] **23.07 残障、疾病、老龄与依赖**：支持基础设施如何改变能力；独立性是否被误当主体价值的唯一尺度？
- [ ] **23.08 女性劳动与职业家庭关系：Goldin 等**：劳动统计、制度约束、职业时间结构和家庭分工怎样共同产生差异？

## 24 人口、代际、生命历程与迁徙

- [ ] **24.01 人口转型、生育与死亡**：人口指标如何受生计、医疗、教育、性别和制度影响；不能用单一文化解释。
- [ ] **24.02 年龄结构、老龄化与照护**：财政、劳动、家庭和城市设施怎样分担代际成本？
- [ ] **24.03 队列、时期与年龄效应**：所谓代际差异来自人生阶段还是共同历史经历；怎样避免给一代人贴人格标签？
- [ ] **24.04 生命历程、关键期与累积优势**：早期条件怎样影响后续机会；路径依赖不等于人生不可改变。
- [ ] **24.05 移民、难民、侨民与边界**：迁移的主动性、强迫性和接收条件怎样区分；身份与权利怎样断裂或重组？
- [ ] **24.06 代际更替、继承与组织传承**：记忆、资格、资源和权威怎样交接；个人退出后什么能够继续？
- [ ] **24.07 人口政策与生殖正义**：集体目标怎样影响身体与家庭选择；政策成本由谁承担？
- [ ] **24.08 失散、离乡、归属与跨地生活**：迁移不仅改变资源，也怎样改变语言、亲属、照护和自我理解？

## 25 教育、知识、专业与科学制度

- [ ] **25.01 教育目的：杜威与其他教育哲学**：能力、自由、社会化、就业与公民形成怎样比较；目标由谁选择？
- [ ] **25.02 批判教育：Freire 等**：教育是知识灌输还是共同提出问题；解放话语怎样避免代替学习者发声？
- [ ] **25.03 文化资本、隐性课程与资格**：学校怎样同时促进流动与再生产差异；考试成绩代表什么？
- [ ] **25.04 教师、学生、家庭与组织环境**：角色要求、资源约束、情绪劳动与评价指标如何影响教学？
- [ ] **25.05 大学、学术共同体与知识生产**：资助、同行评审、发表、声望与职业制度如何影响什么被研究？
- [ ] **25.06 专家、职业化与公众知识**：专业权限如何成立；经验知识与专家证据怎样交流而不互相抹除？
- [ ] **25.07 知识共享、公民科学与开放实践**：开放资源、贡献承认、维护成本和质量控制如何协调？
- [ ] **25.08 终身学习、技能形成与技术变化**：个人适应义务与组织社会支持如何分担；学习不能替代结构性机会。

## 26 网络、媒体、语言与叙事

- [ ] **26.01 弱连接、结构洞与网络资源：Granovetter、Burt**：桥接怎样带来机会与风险；连接数不能代替关系质量。
- [ ] **26.02 扩散、阈值与复杂传播：Granovetter、Watts、Centola**：信息接触与行动采纳有何不同；不同传播机制怎样区分？
- [ ] **26.03 社会认同、自我分类与群体边界：Tajfel、John Turner**：归属、比较和威胁如何形成群体行为；认同是否必然带来敌意？
- [ ] **26.04 议程设置、框架与媒介选择**：媒体怎样影响可见问题及解释方式；受众选择与平台分发怎样分开？
- [ ] **26.05 沉默、螺旋、谣言与错误信息**：表达风险、信任和验证条件如何作用；沉默不等于认同或无意见。
- [ ] **26.06 叙事、记忆、隐喻与公共解释**：故事如何连接事实与价值；叙事一致性能否遮蔽反例与不在场者？
- [ ] **26.07 平台注意力、推荐与舆情**：规则怎样改变表达和收益；传播热度、公共意见与合法性为何不同？
- [ ] **26.08 跨语言翻译与概念迁移**：哪些意义被保持、折叠和新增；谁有权代表或翻译他人的经验？
- [ ] **26.09 语言学习、语言制度与表达不平等**：口语、书写、多语、标准语和方言怎样形成参与能力；语言制度如何使某些人的知识失去承认？
- [ ] **26.10 不确定性—认同与最优差异性**：不确定感、归属和独特性如何共同影响认同；封闭认同与清楚边界是否必然相同？
- [ ] **26.11 群体情绪、恐惧管理与道德恐慌**：情绪气候、现实威胁、象征威胁和替罪羊化怎样区分；不能从总体情绪推定每个人。
- [ ] **26.12 认同融合与高代价共同经历**：共享经历何时形成融合、何时造成创伤或服从；高代价行为不能单独证明自愿与认同。

## 27 艺术、审美、文学、游戏与日常文化

- [ ] **27.01 审美经验、美与判断**：形式、情感、意义和社会位置怎样进入审美；美能否被还原成功能？
- [ ] **27.02 艺术生产、制度与文化产业**：创作者、平台、资本、评论和受众如何塑造作品及其可见性？
- [ ] **27.03 文学、叙事伦理与多视角理解**：虚构怎样提供经验想象；人物理解、道德评价与现实因果不能互相替代。
- [ ] **27.04 游戏、仪式、体育与游玩：Huizinga、Caillois 等**：规则、竞争、共同参与和自由游戏怎样组织关系；游戏并非都为收益最大化。
- [ ] **27.05 粉丝社群、次文化与共同热爱**：作品、身份、维护劳动、商业与冲突怎样作用；回到框架最早的问题入口。
- [ ] **27.06 消费、时尚、品味与身份**：消费怎样表达归属或区分；不能把所有选择都解释为地位竞争。
- [ ] **27.07 思想实验与科幻：如《三体》**：黑暗森林、威慑和猜疑链如何作为条件情景；虚构不能成为现实机制的经验证明。
- [ ] **27.08 日常生活、节日、饮食与身体实践**：看似微小的重复怎样承载意义、照护与权力；宏观框架是否抹平生活细节？
- [ ] **27.09 历史记忆、博物馆与文化遗产**：哪些记忆被保存、展陈或消除；保存传统与当下主体改变生活的权利怎样协调？

- [ ] **28.08 技术转型、替代与能力丧失**：效率提升怎样改变技能、依赖、意义和劳动分配；退出技术是否真实可行？

## 30 生态、资源、公地与可持续生活

- [ ] **30.02 公地、共同资源与集体治理**：排他性、竞争性、监测和地方规则如何作用；不能只在国家与市场间二选一。

## 31 风险、灾害、公共卫生与安全系统

- [ ] **31.06 流行病、公共卫生与社会信任**：传播、信息、卫生资源、行为和权利怎样交互；公共目标如何避免污名化？
