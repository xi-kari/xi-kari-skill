## 5.10　跨圈层关系变换

尺度变换与圈层关系变换必须分开。尺度变换回答同一问题在 SP0 与 SP1 之间哪些变量保持、改变或丢失；圈层关系变换回答两个或多个候选圈层在同一或不同尺度上如何并列、包含、重叠、桥接、竞争或临时形成。一个关系变化可能伴随尺度变化，但不能用其中一个词替代另一个合同。

跨圈层记录至少包含关系源、关系目标、静态关系类型、成员或接口基准、方向、通道、时延、阈值、时间窗、证据、反例和前后快照。transformed 只作为关系更新结果：原平行关系可能因桥接者出现而转为桥接，重叠关系可能因制度整合转为嵌套，临时圈层可能制度化或解体。每次转化都要检查 K 是否保持；K 失效时记录对象转换，不以改名延续旧对象。

| 变换问题 | 需要调用 | 不得偷换 |
| --- | --- | --- |
| 个体状态能否代表团队 | 聚合 M01、尺度合同与分布损失 | 成员属于团队不等于代表团队 |
| 团队是否被组织包含 | 嵌套 M02 与具体包含基准 | 共同上级不等于成员包含 |
| 两圈层是否因共享成员相关 | 重叠关系、成员映射与共同环境 | 重叠不自动产生有效反馈 |
| 桥接者是否改变另一圈层 | M03 传播、通道和反事实 | 接触不等于传导，传导不等于代表 |
| 临时群体是否形成持久对象 | K、纵向对象材料与 M05；主张分组增益另检 G1，主张历史条件残差另检 G3 | 留痕不等于制度化，持久事实不必依赖额外历史残差 |

多重成员关系要求同一行动者在多个圈层中保留不同角色、可见信息、责任、风险和退出能力。不得先把行动者聚合为单一状态，再把该状态复制到所有圈层。跨圈层推演应从局部状态出发，经已声明的成员或接口通道传播，并逐步登记聚合损失。

翻译有任务，也有权限。正确转述某人的话、帮助双方互相理解、获准发表原话、代表该人签署协议，是四种不同能力或资格。同一译法能完成预约，却可能不足以保存诗歌节奏或法律身份差别；对后一任务的不足，不能倒写前一任务从未完成。应保留能成功的有限转译，同时明确未被转移的意义和权利。〔研究12.10、26.08—26.09〕

### 5.10.1　三类变换必须分开

尺度变换回答同一问题在两个尺度剖面之间哪些变量保持、改变或丢失；圈层关系变换回答候选圈层之间的并列、包含、重叠、桥接、竞争或临时关系如何更新；表示或表述转义回答一个有来源的载荷怎样进入目标任务的词汇、变量或表达。三者可以同时发生，但必须拆成有序记录。

转义是一类独立说明保持、改变与损失的运行合同。它可以调用传播、压缩、横向迁移或其他算子；合同之间按各自输入、输出、判据和失败条件连接，不能仅凭命名差异增加算子，也不能把多个不同操作的失败并成一个总状态。

### 5.10.2　转义损失审计

若两个在源任务中可区分的源状态，在目标表示中无法区分，则针对该项区别登记任务相关损失。恒等映射、可逆编码或对目标任务充分的映射可能没有检测到相关损失，因此规则是“不得预设无损”，而不是“必然有损”。

| 审计项 | 最低问题 | 不得偷换 |
| --- | --- | --- |
| 保持 | 哪些事实、关系、模态、权利或不确定性必须不变 | 保持标题不等于保持语义 |
| 改变 | 哪些格式、单位、粒度或表达允许变化 | 允许改变不等于任意改义 |
| 折叠 | 哪些源差异在目标端合并 | 折叠不等于源差异不存在 |
| 遗漏 | 哪些内容未进入目标表示及原因 | 保护性不公开不等于不存在 |
| 新增 | 哪些解释、推断或目标变量由转换产生 | 新增变量不等于发现现实实体 |
| 回返 | 异常出现时回到哪个父记录或合同 | 回返只重开审查，不修补旧运行 |

往返重构可以作为检验，但不是充分条件。一个转换可能借助隐藏源记录实现表面往返，却没有保持目标任务语义；另一个单向摘要可能对指定任务充分。复核必须回到预先声明的保持项、损失容限和目标侧结果。

目标表示是否保留所需区别，与实际规则是否正确使用该区别，是两项判断。处置错误不能单独证明转义损失；差异仍可辨而使用错误时，把缺口登记在规则或执行环节。表示损失与执行错误也可能并存，应分别说明依据，并保留其他已经成立的局部结果。

两类失败并存时，不应把同一不可避免误差重复计为额外规则故障。在某个原像中，若目标答案本来就不唯一，任何仅使用当前表示的确定规则都不可能对全部源状态答对；这本身证明表示不足。若另一个非空原像的目标答案已经唯一，实际规则却给出错误答案，则该处提供独立规则错误的充分见证。现实内部表示未知时，公开原件仍可查阅不证明执行者当时已经拥有该区别；资料存在、及时访问和实际使用要分别核对。

### 5.10.3　有效变量、闭合与残差回返

有效变量是目标尺度或目标任务中，为压缩状态并改善预定解释、前瞻或方案比较而提出的变量候选。它必须绑定对象、尺度、时间窗、任务、测量、简单基线、误差、失效与退役；有效不等于真实实体、根因、普遍变量或授权依据。

目标表示不默认动力闭合。静态描述或同尺度查询先核对来源、转换规则与任务答案，必要时使用F1及F4；形式动力模型依F2核对闭合，现实映射另取证。描述映射不适用的G专用字段可以注明理由后记为not_applicable。只有以§4.6申请尺度闭合、对象或干预转换的正式经验支持时，才进入相应G4实例的正向门与零结论门；不能为了满足格式而虚构尺度变化。未达到显著增量不能自动证明闭合；出现增量时，把相应影响登记为记忆、噪声、迟滞、未解析项或残差候选，不能按形状直接命名新实体。

统一尺度变换记录须在用途与语义字段中注明目标任务，在转换、证据和损失字段中记录父表示、折叠差异、回返位置、重构检验和目标有效变量候选。缺少有关信息时保留明确缺失状态；不得由一个表格完整推定源语义已经全部保留。
