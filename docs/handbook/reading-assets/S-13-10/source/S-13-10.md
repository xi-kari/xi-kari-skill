## 13.10　多圈层推演九闸

七闸是解释与诊断的唯一主流程；当任务明确要求动态推演、条件前瞻或有限选择时，在其基础上展开九闸。九闸不得绕过七闸已经规定的对象、证据、受影响位置、权力、反身性、强判断程序和行动上限。

| 闸 | 核心检查 | 失败输出 |
| --- | --- | --- |
| DF1 事实冻结 | 事件类型、来源、时间、证据截止和争议 | 事实问题清单 |
| DF2 联合对象 | 行动者、圈层、关系、成员与 K | 候选分组或单焦点退回 |
| DF3 双通道与时钟 | 与任务相关的物质/体验—意义条件、时钟、未知；无关项带理由不适用 | 保留状态快照；暂停依赖缺失条件的传播，独立路径分别审查 |
| DF4 机制传播 | 通道、阈值、时延、反馈和级联 | 候选机制与区分观察 |
| DF5 路径分叉 | 条件、父子节点、早期与反向信号 | 并行路径，不强制排序 |
| DF6 前瞻登记 | 目标、期限、简单基线、校准和回写 | 仅情景推演 |
| DF7 规范选择 | N、PF、受影响者、方案与不行动 | 缺失所阻断的推荐暂停；保留独立成立的评价、明示前提的条件建议与补证需求，不产生执行权限 |
| DF8 授权与执行 | J、O、责任、停止、回滚和补救 | 外部移交，不执行 |
| DF9 结果回写 | 结果、基线比较、偏差、降级和退役 | 保留失败并开新版本 |

工具在 DF2 可以提出圈层候选，在 DF5 可以提出变量候选，但任何候选都保持 candidate。DF6 未通过时，输出不能使用“将会”“预计命中”等前瞻语气；DF7 或 DF8 未通过时，输出不能给出可执行指令。DF9 不允许覆盖原运行。
