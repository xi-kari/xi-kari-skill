## 3.3　D2 有效反馈

一条意见被收到，还没回答它改变了什么；一条意见真的改变了行动，也没回答改变是好是坏。有效反馈在这里是“返回造成后续差异”，不把有效二字当作赞美。

### 原文问题与通俗解释

原文定位：第463—472行；原文锚点 section-3-3；短引文：‘D2 不保证反馈真实、及时、有益’。本题源切片逐字附后，讲解与原文分开。

有效反馈有四个可追踪位置：先前状态或输出、返回通道、接收位置、被改变的后续字段。返回可以是物理信号或有载体的信息，但要把四处连起来：什么从哪里返回，由谁或哪个部件接收，之后改变了哪个状态、转移概率、时序或约束。只在图上画一个圆圈，不会建立实际返回链。

登记作用需要比较：相对于无返回或通道被阻断的情形，后续字段是否出现可检测差异。实际研究未必能随机切断通道，可以使用适合对象的对照、自然变动、机制证据或其他识别设计，但须说明共同原因、同步干预、测量变化等替代解释。资料只显示先后顺序时，不能把所有后续变化归于该返回。

回执、意见簿、会议记录或存档能够证明到达或留痕，不能单独证明某个目标字段被改变。反过来，D2没有要求效果必须持久留痕：固定控制器根据刚收到的信号立即改变下一步输入，即使随后恢复原状、没有留下长期参数改变，也可以构成该窗口内的有效反馈。

“作用”“稳定性”“目标改善”分开。返回造成差异是作用；扰动能否消退、状态是否保持有界或收敛，要依明确的稳定概念、规则与参数判断；是否达到任务目标，还须评价代价、瞬态峰值和收益损害的分布。错误、迟到或放大的信号仍可能有作用，却造成恶化。

固定规则也能反馈，不以模型重训、人员学习或参数更新为必要条件。若再声称学习，要检查相应更新、后续调用和任务结果；载体学习分支CM-LEARNING-carried需要可定位更新、经载体保留或持续更新、重复轮次实际调用与任务结果比较，不因保留持久就自动要求G3。只有进一步主张CM-LEARNING-history，即相对明示当前表示仍有额外历史条件增量，才另需G3-instance。当当前载体充分保留所学内容时，该额外增量可以消失，而载体学习仍成立（6.3，第1320—1337行）。不能把“不学习”误判为“没有任何反馈作用”。

纠偏主张必须公开目标偏差、增益、执行时延、工作区间与失稳判据。把偏差乘以负号，并不保证现实过程自稳。下面的线性推导只在给定离散模型、无时延、无饱和等假设下成立；现实过程的时延、非线性、外界扰动和限制都需要另查。

### 公开论证与证据职责

1. 前提：一个已发生的状态或输出，有可追踪的返回通道和接收位置。
2. 候选作用：明确被改变的后续状态、转移概率、时序或约束，并给检测阈值与时间窗。
3. 比较连接：提出无返回／阻断通道的参照，检查它与实际返回状态下是否存在可归因差异；排除足以解释差异的竞争原因。
4. 限定结论：材料足以支持差异时，可登记该字段与窗口内的反馈作用；回执或档案本身不能替代这一步。
5. 强化责任：稳定、纠偏、改善及学习各加自己的判据和证据；负号、好意、记录完备和悲喜结局都不能代替它们。

### 易混概念

- **接收到／保存了**：证明信号到达或有留痕。
  **有效反馈**：返回对后续字段造成相对无返回的可检测差异。
- **有效**：在当前定义下确有作用。
  **有益／正确**：方向与价值另按目标、成本和分布评价。
- **反馈作用**：固定规则即可产生，也可以短暂。
  **学习／持久记忆**：需要相应更新与后续调用条件，不能凭反馈一词认定。
- **负反馈形式**：控制方向试图抵消当前偏差。
  **稳定或收敛**：须给动力规则、增益、时延和工作区间；不是负号的同义词。

### 真实／历史案例

#### 哥伦比亚号：请求与材料流转，不等于目标判断回路已充分

CAIB在2003年调查报告中列出三项独立发起的在轨图像请求，并记录碎片评估团队的工作；同时指出分析假设及不确定性没有完整呈报给任务评估室和任务管理团队。本节新增观察点是返回链的不同位置：请求发出、团队形成与目标风险判断获得充分材料，不能用同一条“已反馈”代替。

### 教学／数学构造

#### 数学构造：负号没有保证稳定

设x_t为偏差，系统x_(t+1)=x_t+u_t；测量精确且即时返回，固定控制规则u_t=-k x_t。代入得x_(t+1)=(1-k)x_t，递推得x_t=(1-k)^t x_0。对任意有限初值渐近趋零要求|1-k|<1，因此0<k<2。取x_0=1，无返回时u=0，序列恒为1；k=0.5时为1、0.5、0.25、0.125；k=3时为1、-2、4、-8。两种k都造成相对无返回的差异，后者却放大偏差。k=2得到1、-1、1、-1，是不趋零的等幅振荡。

假设：一维离散线性模型，无扰动、无执行时延、无饱和，反馈系数固定；观察精确；序列是演算而非观测数据。
边界：仅证明该模型中的作用和渐近收敛范围，不能证明现实控制器安全、收益为正或已形成学习。

#### 数学构造：同一增益，加一拍时延会怎样

无时延且k=1时，上式从任意x_0一步到零。若改为x_(t+1)=x_t-x_(t-1)，并给x_-1=x_0=1，则x_1=0，x_2=-1，x_3=-1，x_4=0，x_5=1，x_6=1，随后重复。增益和减号没变，使用的信息晚一拍，就不再得到同样的收敛结论。

假设：仅改变为恰一拍时延；仍是无噪声、无扰动、无饱和的数学模型，初值全部明示。
边界：构成不能忽略时延的反例，不给现实过程设定统一时延阈值。

#### 教学构造：作用没有留下长期参数改变

假设控制器每步只读取当前传感值并套用固定公式，动作后丢弃本次读数，参数永远不变。只要返回对下一步状态造成可检测差异，D2的作用仍可成立；“参数没有学习、没有持久日志”不能取消该差异。若恰处x=0且无扰动，两种动作都是0，这一次比较则不提供非零作用见证。

假设：为区分瞬时作用、学习和检测窗口而设；不声称具体设备这样实现。
边界：不能据此免除现实研究保存必要证据的职责；没有研究证据与系统自身无长期记忆是不同事情。

### 反例与边界

- 一次返回后状态不变，可能是当前平衡点、死区、饱和、观测分辨率不足或确实无作用；应按材料区分，不从一条零差异记录否定所有窗口的反馈能力。
- 为了研究而切断现实安全通道可能有严重风险；这里的阻断只作为识别参照或数学构造，不授权实际实施。
- 反馈造成伤害不否认其作用存在；反馈没有永久痕迹也不自动否认它曾改变了时序或转移。
- 一个组织的某条目标回路未获支持，不等于整个组织处处无反馈；同样，局部成立不能扩为所有通道有效。
- 数学稳定域只适用于所写模型。现实的时延、饱和和观测误差不能省略后还沿用同一数值门槛。

### 理解问题与答案

1. **系统每条投诉都自动发回执，能否判有效反馈？**
   答案：只能确认回执这一字段被生成，不能由此证明投诉改变了所关心的后续服务或规则。须指定目标字段、返回链和无返回参照，避免把回执替代目标作用。
   理由：本节原文及上述公开推导

2. **固定温控规则没有重训参数，就没有反馈吗？**
   答案：不是。若读数经返回改变后续动作或状态，固定规则也可满足D2；学习是另一组条件。
   理由：本节原文及上述公开推导

3. **k=3的数学例是“无效反馈”吗？**
   答案：按D2不是无作用：它相对无返回改变了状态，只是偏差放大、不满足该模型的渐近收敛条件。日常“无效”若指不达目标，应明确采用的是另一评价。
   理由：本节原文及上述公开推导

4. **阻断后的结果更差，是否自动证明原反馈有效且有益？**
   答案：仍需确认阻断是否同时改变其他通道或环境、比较是否可信，并限定结果和成本分布；不能把一个混杂对比当作无条件归因。
   理由：本节原文及上述公开推导

5. **一次在平衡点看不到差异，能否推断系统从来没有反馈？**
   答案：不能。该次窗口只未提供可检测作用见证；需结合平衡、死区、饱和和分辨率等条件，再判断其他窗口或扰动下的作用。
   理由：本节原文及上述公开推导
