## 6.3　CM-LEARNING 反馈介导学习

基础推理依赖：CM-FEEDBACK。E4、CAUSAL 与 EVIDENCE 是方法门。反馈介导学习要求返回造成可保留更新，该更新实际进入后续任务；当前载体传递与当前表示之外的历史增量是两个分别取证的分支。

CM-LEARNING-carried 是载体分支。使能条件为：有效反馈改变可定位的内部状态、参数、规则、记忆或结构；更新经明确载体保留或持续更新，并在重复轮次中实际调用；相对于预先声明的基线或替代过程，后续预定任务出现可复核差异。因果主张须有中断、替换、恢复或具备识别条件的比较，并处理共同输入、持续训练、选择、失访与测量改变。主张迁移或预测增益时，另需与该主张相称的独立任务或样本外评价。机制链为：

有效反馈 → 可定位的内部更新 → 更新载体保留或持续更新 → 后续轮次实际调用 → 预定任务结果改变

一次参数变化、一次成功、一次写回或材料归档都不足以证明这条学习机制。更新未保留、未被后续调用、任务结果仅由共同输入解释，或只改变代理指标而未触及预定任务时，相应机制主张未获支持。有效反馈、一般学习、跨情境迁移和净收益分别判断；学习成立也不表示变得更好、拥有统一目标或取得行动授权。

目标本身发生改变时，应说明形成新目标的理由与决定程序，保留旧目标下的结果、失败和成本，再为新任务建立比较。不能用后来重构的目标把旧任务失败改写为成功。

一般学习可以由相应领域的证据得到支持，例如可重复完成的新任务、保留并调用的技能、可追查的教学或组织过程。它不必先取得本框架的正式机制实例身份。报告可以同时说明“做法已改变”“后续净效果尚未确定”“反馈介导机制尚未识别”，不将几种判断压成一个通过或失败。〔研究16.02、25.01—25.08、31.08〕

学习评价还应区分支持下完成任务、撤除支持后的独立迁移与后续生活结果。必要支持可以构成表达或协作任务的组成部分，此时无支持失败不取消已有成功；原目标若是独立迁移，则需相称的撤援比较。选择目标、确认更新保留、测量任务表现和判断净收益分别承担责任，不能用支持仍在否认功能获得，也不能把辅助成绩替代独立技能。

CM-LEARNING-history 是历史增量分支：在载体更新、重复调用与任务比较之外，还须由 G3-instance 支持相对于明示当前表示的额外历史条件增量。当当前载体充分保留所学内容时，这一增量可以消失，而载体学习仍然成立。不得删去已知当前载体制造增量，也不得在结果后改换分支救援原检验；两条路线分别声明比较、反例与失败条件。
