# 参考文献

20项文献提供可回查的入口；题录、页段支持、独立证据与现实用途需要分别判断。

## 原文定位、阅读方法与20项导读
原文对应：参考文献位于全书第5051—5091行，锚点part_21；完整原文由随包source-slice.md逐字提供（对应原包source-slices/REFERENCES.md）。本单元有20项，包含工作稿、期刊与会议论文、法律解释、判决、官方统计说明和会计规定。原文特别写出“本文引用第326—327页”，也将若干文献称为“专业模型参照”。这些限定本身就是理解本节的关键，不能在展示时删掉。

中心判断：参考文献是回到具体依据的入口，不是一张替全书担保的权威名单。读者应能回答四件事：究竟是哪份文本；作者用了哪一段；该段支持哪种主张；从那里走到当前判断，还缺什么。只知道题名能完成身份辨认，却不能证明已经读过正文。读过正文也不保证其中每项经验断言正确。

本书的理论概念与外部学科文献存在对照关系，但关系类型不止一种。有的来源限定选案和评估，有的提供正式规范文本，有的记录一个统计版本怎样更新，有的提供数学模型作参照。把它们都压成“科学证据支持本书”，会抹去证明、解释、史实、规范与应用的不同责任。更合适的读法，是让每一条引用只承担它实际完成的工作。

与全书的连接：§2.7.1要求保留材料身份和实际阅读范围，§2.7.2提醒同源材料不能计作独立验证，§16.15讨论材料回查，§16.24反对以流程产物替代方法价值。参考文献给这些原则一个可操作的入口：一个作者稿被正式发表，不等于两次研究；一个PDF被翻译或重发，不等于多一份独立观察；一份规范文本的更正可能改变逻辑条件，不能仅保留最熟悉的旧链接。

下列20项按原书顺序展开。每项分开列身份、原书位置、本次实读范围、可支持内容与尚缺事项。“未找到以作者名明示的逐句引注”只描述当前文本中的可定位关系，不判断作者未受该研究影响；建议联读处也不冒称原作者已经作了那项引证。所有外部材料核读时间为2026年10月14日。

如何比较形式参照：Moore的输入—输出可区分性、SMDP的状态—动作抽象、结构方程模型的干预保持、有损表示下的宏观推断，不是同一问题的四种叫法。数学迁移至少要展示对象集合、映射、保持的关系、量词、动作或干预集和误差条件。§4.19明确由自己的有限模型及证明承担结论，所以外部数学文献的作用是指出联系与差异，而非为它补上未经核实的普遍最优性。这里未逐式核完后几篇论文，结论限于研究对象与来源角色。

如何处理经验与规范来源：Scheffer和Mansoury可以引导辨别动态信号、反馈与测量对象，但模拟或模型并不直接证明真实人的损害；Montgomery与CRPD使读者回到具体法律文本，却不自动给任何人现实处置权。ILO释义、财政部规定与统计方法报告也各有适用对象。所谓“原文引用正确”只是第一步；要把它用于一个当下个案，还需法域、时间、对象、事实和权限的额外材料。

反方向的检查同样重要。不能因只读到摘要就宣布论文内容不可靠，也不能因一个链接打不开就宣布引用不存在。Sen1981和ICJ是本单元具体的未决：前者已核期刊身份及摘要，后者已核正式转送题录，但本书指定页段仍未完成直接核读。这里应暂停依赖这些页段的细致解释，同时保留不依赖它们的文献身份判断和本书原句的文本解释。

本节是静态书目及证据职责教学，不需要构造三阶社会演化故事。版本形成、勘误和重发有真实时间顺序，可以照实解释；从文献列表推演一个制度将成功、某人必定受到伤害或某政策取得合法性，则没有足够对象和证据。完整的书目讲解不等于完整复现20项研究，诚实的阅读范围比一个虚假的“全部验证”更有用。

可采用的阅读次序：先读书中具体断言，再打开匹配的版本和页段；把支持关系写成一句有限主张；寻找同段的条件、例外与反向说明；最后才判断能否迁移到新情境。若原页段暂缺，留下明确页段而不是泛称“资料不足”。若只有参照关系，保留比较问题而不宣称等价。这样的终章把全书重新接回可查、可争论、可修订的材料世界。

## 论证拆解
- 前提一：每项文献具有对象、版本、位置和用途；这些要素不同，可能回答不同问题。
- 前提二：本书有明确页段引用，也有专业模型参照。引用角色须由原文和来源共同决定，不能从知名度推出。
- 推理连接：先建立“原书断言—具体页段—可支持命题”关系，再检查原段限定和迁移所需条件；没有读到的环节保持未核。
- 公开结论：20项形成有边界的回查网络，不能合并成对整套理论、所有经验用途或现实处置的普遍背书。
- 条件与责任：数学主张需相符定义和证明，经验主张需研究设计及观测，规范主张需法源与适用对象，现实行动还需权限。
- 反方回应：这并不要求每次教学都复现整篇论文；读到足以支撑当前有限陈述的范围即可，但陈述不得超过它。

实际页段是否蕴含目标主张，要读文字、条件与例外。

### 本书定位 / 教学联读
原书哪一行引用什么来源，可以直接核对。
讲解者建议比较的章节，不应冒充原作者的逐句引证。

### 部分阅读 / 全文研究复现
明确读过的摘要、段落或页面，可承担有限解释。
需要全部相关方法、数据、证明或实现；本单元不声称做到。

### 版本关系 / 证据独立性
更正可能替换内容，重发可能仅更换载体，两者都要核。
新文件、新年份或新网址不自动增加独立样本。

### 规范文本 / 事实及授权
能支持该文本如何规定或解释。
某现实情境满足条件与谁能执行，仍要另行确定。

## 真实版本案例
### 真实版本案例：WPP2024的2026年局部更新
联合国人口司在2026年1月19日说明，对Togo因重复漏报调整造成的问题进行修订，并明确哪些序列更新、哪些没有更新。这里新增的观察点不是人口趋势，而是同一产品名下不同表是否处于同一版本范围。使用者若拿更新后的国家人口与未更新的汇总强行相加核对，就可能把版本错配误当作真实人口矛盾。正确处理是分别标注表、情景、时期和更新范围，不自行改写发布方未更新的值。
来源：[R07](https://population.un.org/wpp/assets/Files/WPP2024_Release-Note-rev1.pdf)；两页修订说明，修订范围与使用说明。
支持边界：读的是修订说明而非全部数据表；没有复算多哥人口，也没有声称原版全部无效。

### 真实文本案例：CRPD第27段的2018年勘误
2014年一般性意见的第27段后来有正式替换文本。勘误中第三项之前的连接是or，不能仍按旧文and把三项解释成必须同时满足。此处关键并非更新了一个网页日期，而是逻辑联结改变了判别方式。引用原意见时联读勘误，才不会让看似准确的段号承载过时文字。这个例子不说明任何现实支持安排已经违法，只说明解释该段时应使用哪个文本。
来源：[R03 + R03C](https://docstore.ohchr.org/SelfServices/FilesHandler.ashx?enc=XBJrja1NI23jjzoD%2BXg0DS7wIHEnIp93rTAvLUIgIGhNhE2likgU4AkIThrKpkkNWeW7IQ3hrAlle3kxQv83LLDoo%2BSXjSfNEtrtgzN4f%2FU%3D)；2014意见第27段；2018-01-26 Corr.1第27段替换文本。
支持边界：未全读该意见；委员会解释不能单独确定任一国家具体制度效力或个人代理权限。

### 真实题录案例：2017年研究在2026年重发
PMLR页面同时给出UAI2017论文、151—160页，以及2026年10月4日重发的备注。原研究年份与载体重发年份都应保存。若把两个日期当作两项独立研究，再声称获得两次因果一致性验证，会重复计算同一文献；若抹去重发日期，又会让读者难以解释当前入口的版本记录。
来源：[R17](https://proceedings.mlr.press/r15/rubenstein-17a.html)；PMLR题录与BibTeX note。
支持边界：未读全文证明；重发不增加一次实验或独立研究，也不把2017研究改记为2026新成果。

## 教学构造
### 教学构造：三份文件，一项观察
假定A是一次研究原稿，B是A的中文译本，C是A的原样重发；无新增样本和独立采集。
文件数为3；按同一底层研究分组，{A,B,C}只有1组。因此可说有三个阅读入口，不能说有三次独立验证。若D另外采集样本，则至少要核对是否真的独立、是否共享关键偏差，才讨论它增加了什么。这个算例不估计真实研究间相关系数。
教学构造，不是对任何本书文献抄袭、重复发表或质量缺陷的指控。

### 教学构造：连接词怎样改变判断
设三个可判真假的条件A、B、C，暂只比较布尔逻辑，不代入任何个人法律资格。
当A=true、B=false、C=false时，A且B且C为false，而A或B或C为true。由此可见将且误读成或，或反过来，会改变同一事实组合的判别结果。CRPD真实勘误提供了必须查看连接词的理由；该算例只说明逻辑，不替任何安排作法律认定。
真实条文含词义、上下文与适用范围，不能只靠三个布尔值完成法律判断。

## 反例与边界
- 真实反向材料：WPP的局部更新否定“同一产品名意味着所有文件同步更新”；CRPD勘误否定“段号不变意味着文字与逻辑不变”。
- 真实测量边界：Mansoury研究的是模拟中系统偏好表征，不能拿“偏好变化”四字抹掉它与内在偏好的差别。
- 未决边界：Sen1981指定433—435页和ICJ指定五段未完成直接核读；细致页段支持不得标记已证实。
- 条件反例：若一论文有三个镜像PDF，或工作稿与发表稿共用一次实验，文件数增加不等于独立实证次数增加。
- 部分阅读并不等于否定文献；来源存在也不等于论断真实。判断应具体落在尚缺的桥接证据上。
- 法律、劳动、会计与医学相关来源只在本节承担文本教学；没有实施个案诊断、代理决定、资格处分或法律处置。

## 理解问题与答案
### 一个网页显示2026年，论文题录写2017年，应改写为2026年研究吗？
不能先改。先区分原发表日期、当前载体重发日期和内容修订日期。Rubenstein这条已核为2017研究、2026重发。
依据：R17

### 已经看到Sen1981论文摘要，可以写“433—435页已逐段核实”吗？
不能。摘要支持研究主题与有限概括，指定页段未读仍是缺口。还应说明它是QJE论文，不以同年专著代替。
依据：R14

### 模型中用户档案越来越相似，是否足以证明用户内心被改造？
不足。先区分系统记录或表征与独立测得的内在偏好；模拟结果没有自动完成现实心理测量。
依据：R11

### 两份联合国人口表名称都带2024，能否假定更新状态一致？
不能。应查实际修订说明中的国家、序列、情景、时期与汇总范围；Togo局部更新正是反例。
依据：R07

### 一份原文链接失效，能否断言作者编造了文献？
不能。可核正式题录及其他合法入口，并标注正文未取得；存在性和具体论断支持是两项判断。
依据：R15

### 参考文献有四篇因果或动力抽象论文，是否已经证明本书所有层级转换正确？
没有。必须比较模型类别、映射、保持关系与前提，再核具体命题；参照文献不能替代本书自己的证明或经验材料。
依据：R16—R20；原书§4.19
