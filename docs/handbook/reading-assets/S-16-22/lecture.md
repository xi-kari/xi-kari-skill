## 16.22　GOV-22 多圈层复杂度与前瞻治理

变量越多、故事越精密，越需要问：它究竟提前知道了什么，比简单办法多帮了多少，又让谁承担了错误？前瞻治理不是收藏成功预言，而是让每次预告与后来可核的结果持续相遇。

### 原文问题与通俗解释

原文定位：第3532—3537行；原文锚点 section-16-22；短引文：‘不允许只公开命中案例。’。本题源切片逐字另附于source-slice.md，讲解与原文分开。

五类治理债是能力扩张积累的待处理责任，不是可直接相加的一笔数值债务。对象债来自给圈层取名后就把它当独立实体，忽略边界与交互证据；变量债来自把未解释残差自动补成某个隐藏变量确实存在；复杂度债来自变量、路径增长却没有样本外增益；校准债来自发布预测却不登记结果；权力债来自预测进入筛选、监控、惩罚或操纵。每类都需要自己的证据与预先门槛，不能用总体模型分数高掩盖权力风险。

对象债与变量债尤其容易由语言制造。把一组人的相似反应命名为某圈层，不证明存在统一意图或稳定边界；观察到模型残差，不证明解释残差的候选机制已经发生。需要额外材料识别边界、耦合、替代解释与可检验变量，否则保留候选或unknown。把解释标签直接输入预测再以预测结果反证标签真实，会形成未经独立检验的闭环。

复杂度债要以样本外增益检验，而非训练集拟合好看。样本外材料不得用于反复调参后仍冒称未见数据；输入截止之后才获得的信息更不能回填成事前已知。比较应使用同一目标、相同可用信息、相同观察窗口与预先指标，并包括简单基线。基线也不是故意设置的稻草人，应代表任务中合理可得的简单方法。复杂模型没有新增收益时，更多参数与术语不能自行证明价值。

校准关注概率表达与可观察结果的对应关系，例如多次报相似概率的事件，其结果频率是否与表达相称；它不等于挑出几个猜对的事件，也不等于一切预测质量。下面的Brier均方损失同时受多个性能因素影响，不能把一个小样本得分直接当作长期校准结论。原文要求持续登记结果，使校准恶化能被发现，而不是只公布命中宣传。

前瞻注册表必须保留成功、失败、未决、目标失效与无法评价。成功失败应按预先目标和评价规则判定；未决是观察窗口或结果尚未到达；目标失效是原登记的评价对象或条件已不再成立；无法评价是相关证据或评定条件不足。后三类不能悄悄删除，也不能为了分母好看强塞进成功。报告指标时需说明哪些记录可评分、哪些未纳入以及原因，同时展示完整登记范围。

外部审查者应能复核模型版本、输入截止、简单基线、指标和结果回写。版本说明用哪套规则作了预告；输入截止阻止事后信息伪装为事前知识；基线约束复杂性是否有增益；指标限制挑选有利评价方式；结果回写让每次声明承担后续检验。允许合理更新，但新信息、新模型和新的预测应有新记录，不能覆盖原预测来抹去失败。

任一债务超过预先门槛，就应缩小模型、降低输出、暂停高影响用途或退役相应模块。长期校准恶化、跨群体误差集中、复杂模型不再优于基线、结果持续依赖事后变量，会使前瞻能力声明自动降级。这里的自动降级是本框架的治理要求，不是已经实现的软件功能，也不授权现实惩罚。门槛应在看到结果前定下，避免失败后临时改变评价尺度。

跨群体误差集中揭示平均指标可能遮蔽代价位置。即使总体表现改善，某些群体承受更多错判，也需要分组材料、足够样本与影响评估，不能只看总数。预测准确与使用正当又是两回事：准确估计某人会做什么，不产生监控、操纵或惩罚的授权；误差治理和权力治理都不能被高分替代。

最强反方认为开放保留失败会让模型显得比只报告成功的对手更差。恰恰因此需要共同透明的登记与比较条件；删掉失败会破坏能力声明的可检验性。另一反方认为无法评价应全算失败以保持严格，也不成立：严格不等于伪造已知结果，应分开呈现未能评价的规模与原因，必要时因此降低能力声明，而不是把未知事实强行补为零。

### 公开论证与证据职责

1. 对对象、变量、复杂度、校准和权力五类债分别登记证据及预先阈值。
2. 固定模型版本、输入截止、合理简单基线与评价指标，避免事后信息混入事前预测。
3. 全部预测保留成功、失败、未决、目标失效或无法评价及各自依据。
4. 在相同评价条件下比较样本外表现，检查长期变化和跨群体误差分布。
5. 达到降级条件即限制相应能力声明与用途，不用复杂性、平均分或个别命中维持高影响资格。

### 易混概念

- **命名圈层**：为分析设置待检验边界。
  **证明独立实体**：仍须对象边界、关系和机制材料，不能从名字推出。
- **残差候选**：未解释部分提示可能的新问题。
  **隐藏变量已证实**：需要独立识别材料，不能自动补事实。
- **样本外增益**：在未用于选择调整且信息时点合规的材料上优于合理基线。
  **训练拟合与事后解释**：可以很好看，但不能据此宣称前瞻能力。
- **无法评价**：评价所需材料或条件不足，保留该状态及原因。
  **已证实预测失败**：已能按预先规则判定结果不符，不能混同。
- **预测性能**：对结果的描述能力。
  **预测用途授权**：筛选、监控、惩罚等还须自身正当性和权限条件。

### 教学／数学构造

#### 数学教学构造：复杂模型输给常数基线

设四个已登记二元事件结果依次为0、0、1、1；复杂模型事前概率为0.8、0.2、0.8、0.2，简单基线均报0.5。采用二元Brier损失L=Σ(p−y)²/4，越低越好。复杂模型四项平方误差为0.64、0.04、0.04、0.64，L=1.36/4=0.34；基线四项均0.25，L=0.25。仅在此构造记录和指标上，复杂模型较差0.09。

假设：四项数据与模型名称完全教学构造；概率在结果前固定；所有事件均可评价且同权。
边界：不证明真实复杂模型无用、统计显著性或长期校准；二元定义不自动等同多类软件指标的缩放。

#### 教学构造：全部登记不等于全部可评分

假想五条预告分别处于成功、失败、未决、目标失效和无法评价，各一条。应展示五条及原因；当前若只有前两条满足评分条件，就说明可评分二条而非五条，不能只展示成功一条并称全部命中。

假设：状态分配纯教学假设，非实测成功率。
边界：失败与目标失效须由事前定义和真实材料区分，不能事后随意改类。

#### 教学构造：事后变量破坏前瞻资格

假想在月初预测月末项目是否完成，却把月末验收结论作为输入。即使复算完全正确，也只是在利用已知答案整理结果，不能称月初前瞻。正确处理是保留原输入截止和预测，新增记录说明后续信息，而不是覆盖旧输入。

假设：项目与日期为构造，不使用真实组织数据。
边界：不否定事后解释的独立用途，只限制其不能冒充事前预测。

### 理解问题与答案

1. **为什么输入截止需要外部可核？**
   答案：否则事后可得信息可能被回填成事前知识，使前瞻能力声明失真。
   理由：本节原文及上述公开推导

2. **算例复杂模型0.34而基线0.25说明什么？**
   答案：在指定四条构造记录和二元Brier指标上复杂模型损失更高，差0.09；不推出一般长期结论。
   理由：本节原文及上述公开推导

3. **无法评价能否从注册表删除？**
   答案：不能；应保留原因，说明评分分母与未知范围，必要时降低能力声明。
   理由：本节原文及上述公开推导

4. **准确预测就能用于惩罚吗？**
   答案：不能，性能不产生现实使用授权，权力债需单独治理。
   理由：本节原文及上述公开推导
