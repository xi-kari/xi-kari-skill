# 第二部分　边界与方法

本框架的最终对象域是广义经验结构世界：凡是能够留下可比较材料，并允许研究者声明候选对象、状态、关系或转移、接口、时间窗、尺度剖面和同一性判据的自然过程、技术系统、生态过程、人类行动、组织与制度，都可以进入结构解释。人类结构化世界不是全部世界的同义词，而是其中一个需要追加人类领域条款、规范承诺和授权程序的特化域。纯形而上断言、无法给出任何经验字段的对象，以及只靠命名或叙事连贯性成立的“系统”，不进入经验判断；它们可以被讨论，却不能借用本框架的经验结论等级。

每次使用仍须另行声明当前适用范围：对象、SP/T/K、地域或环境、资料窗口、外推单元和排除项。属于广义经验结构世界，只意味着原则上可以建立合同，不意味着任何结论可以跨窗口、跨对象或跨领域直接普遍化。

这一范围选择同时规定了框架的克制。框架试图解释对象如何形成可识别结构、如何运转、如何在条件作用下变化或解体，以及不同尺度上的描述如何转换；它不预设世界具有统一目的，不把人类意图投射到非人过程，也不从“是什么”直接推出“应该怎样选择”。现实选择另由规范层与操作程序承接。

## 2.1　两阶段对象准入

结构建模从候选对象开始，而不是从已经证明有效的对象开始。在本框架中申请正式根实例支持时，对象准入分成两个不可倒置的阶段。这个程序管理G与依赖它的C、CM强经验主张，不作为所有领域知识、历史记录或日常理解的统一真值门。

第一阶段是候选对象声明。分析者以 D0 合同登记 S*=<B,X,R,I,T,SP,K>：边界 B、状态变量 X、关系或转移约束 R、接口 I、时间窗 T、尺度剖面 SP 和同一性判据 K。星号表示它仍是分析候选。字段完整只证明问题已经被说清楚，不证明该分组在世界中具有相对独立的经验地位。字段不完整时，只能提出探索性问题。

第二阶段是根实例检验。当分析者以G1—G4的名义主张对象识别、指定通道效应、历史条件增量或尺度闭合，并申请本框架的正式支持资格时，必须建立相应的G-instance，在查看结果前以不可变合同版本和可审计时间戳冻结零模型N0、唯一子型、从该子型允许列表中唯一选择的成功判据、控制、模型、样本与外推单元、评价指标、正向阈值、决策规则、零结论规则、证伪条件和暂停条件。多目标或多模型实例还要冻结主目标或聚合、模型选择或集成及多重比较规则。此种支持资格属于通过检验的具体实例，不属于D0声明，也不属于G1—G4的抽象模板。

支持资格要求把探索与确认、正向结果与零结论、冻结完成与事后偏离分开。只有按证据前冻结合同完成的确认或复制实例，才能提供正向支持；反驳实例只支持预注册的反驳或零模型判断。探索、草案、证据后偏离或未披露偏离只能生成候选、登记偏离或保持未决，不能以正式实例资格支撑要求该资格的C分支。正向门未通过也不自动支持 N0；等价性或充分性、功效或灵敏度与容差没有预注册并通过时，结论只能是“未获正向支持”或“未决”。因而，“候选对象已登记”“正向 G 未获支持”“零模型获得支持”和“对象获得有限正向支持”必须保持为不同状态。

这一两阶段结构防止两种相反错误：一是把分析者的命名、聚类或边界选择当作对象已经客观成立；二是在对象尚未声明时，就用零散材料事后拼出一个不可证伪的“系统”。

### 2.1.1 领域证据与正式实例资格

已有研究、档案、口述、考古材料和可定位原文，可以依其实际研究设计支持相应的描述、解释或有限因果结论。使用这些材料时，应如实保留它们是预注册确认、事后发现、探索、历史重建或其他研究，不能补造结果前合同。材料不能据此自动获得G-instance支持，也不因尚未转换成G-instance而失去原来有依据的内容。

若要把既有发现用于新的正式根实例，可先把它作为问题和模型的来源，随后在独立材料、后续窗口或合适的复制设计中检验。用于探索的数据和用于确认的数据、模型选择与最终评价必须分开；没有可行的新检验时，保留领域结论和待检关系，不伪造确认。

形式证明按其公理、语义和推导规则成立，文本解释按版本、语境和论证材料接受批评，规范主张公开价值前提与理由。它们能够参与分析，但不能互相冒充经验机制、事实真值或现实授权。

### 2.1.2　形式结论与经验实例的接续

形式命题先给出状态域、映射、目标、允许操作和逻辑前提，再由证明确定其结论。完整有限域的穷举可以检验该域内的全部情形；数值计算还须说明精度、边界判定和实现误差。证明、穷举与数值检查可以相互校验，但不共同生成现实样本，计算次数也不增加独立经验支持。

把形式结论用于现实对象，须另行说明现实中的量如何对应模型变量、哪些前提已有材料、误差和适用区间是否可接受，以及何种反例会使映射失效。可以同时承认“命题在给定模型中成立”与“现实对象是否满足模型仍未确定”。数学反例已经足以否定它所命中的无条件推理；没有完成现实试验，不会使这一形式答案消失。反过来，形式可行、算法存在、预算内可计算、资料及时可得、实际执行正确和有权采用，是分别需要依据的六项判断。
