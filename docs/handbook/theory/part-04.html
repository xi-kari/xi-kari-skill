第四部分　经验问题、结果合同与条件形式命题 ​

G1—G4是四类经验问题：候选分组是否带来条件增益，指定通道是否对目标转移具有可识别效应，历史项是否在当前表示之外提供条件增量，以及指定表示在何种任务、动力和干预下闭合。问题族本身不是关于所有对象的定律。具体G-instance同时登记待检事实断言与证据规则，二者不能混写：效应是否存在由世界和所问条件决定，现有证据是否足以支持该断言由研究设计与结果决定。

本部分把经验检验、结果使用与形式证明分开。G实例回答事实问题，C合同说明既有依据能组合成什么有限输出，F命题给出明示数学条件下的必然关系。重复登记同一结果不增加独立证据，根族或合同的通过数量也不衡量整套框架的效用。

4.1　根实例合同 ​

本节给出一套用于确认性检验的标准记录程序。采用该程序时，每个实例分为预注册与结果两段：预注册在读取结果前完成，结果段在执行后追加并保留原登记。尚未运行的内容明确记为未评估，不虚构时间、观测值或材料。两段共同确定什么结果算支持、什么结果算反驳，以及结论允许外推到哪里。

这里的唯一主判据是防止结果后择优的默认设计，不是所有研究的唯一合理形式。多个结果、多个模型、联合判据、探索后确认和顺序研究可以有各自的有效设计，但须事先说明主目标或联合规则、选择程序、停止规则及适用的多重比较处理。下文G与H的单主判据子型属于这套标准程序；程序外材料仍按实际研究设计评价，不能因字段形式不同就被判为无知识价值。四个问题族也不被宣称为穷尽全部科学问题或相互逻辑独立的公理。

合同部分必填字段作用
身份与冻结instance_id、root_id、contract_version、preregistration_timestamp区分实例与根模板，以不可变版本和早于结果访问的可审计时间戳证明合同先于证据
候选对象candidate_object_id、object_contract_id指向 D0 候选对象及其合同，防止把名称当作对象支持

命题实例化selected_subtype、selected_success_criterion、candidate_specification、zero_model、controls、model_classes在证据出现前只选一个子型，再从该子型的允许列表中只选一个成功判据，并声明候选命题、N0、控制和模型族
抽样与外推sampling_unit、generalization_unit分开资料来自何处与结论允许推广到何处
决策规则evaluation_metric、decision_threshold、decision_rule、null_decision_rule分开正向门与零结论门；冻结主目标或聚合、模型选择或集成、多重比较、等价性或充分性、功效或灵敏度及容差

结果与时间result_timestamp、observed_primary_result、decision_rule_outcome、null_decision_rule_outcome、result_state结果时间晚于冻结时间；只记录预冻结主目标和规则的观测结果，分别登记正向门与零结论三门是否通过，并使用封闭四态结案
证据与分析制品evidence_refs、analysis_artifact_refs指向可解析外部材料、数据冻结、代码、模型或日志；内部概念编号、字符串前缀和自报结论不能代替实例

采用单主判据程序时，选择规则记为one_subtype_and_success_criterion_before_evidence：在结果出现前确定一个selected_subtype和一个selected_success_criterion。联合或多结果方案须单独登记其整体判据，不得事后把若干未通过的单项改拼成成功。评价指标、正向阈值、零模型、decision_rule、null_decision_rule 和证伪条件都围绕该判据冻结。若结果不利，不能把多个子型或多个成功判据事后并取，也不能改换目标、模型、指标或阈值来挽救经验问题族。

decision_rule 还封闭多目标与多模型的研究自由度：目标变量多于一个时，结果前必须冻结唯一主目标或聚合规则；模型类别多于一个时，必须冻结模型选择或集成规则；存在多重比较时，必须冻结校正规则。没有这些规则，一个实例只能有一个主目标和一个主模型。null_decision_rule 则另行声明：何种等价性或充分性检验、功效或灵敏度门与容差可以支持 N0。执行后，decision_rule_outcome 必须结构化记录阈值、观测值、是否通过及分析制品；null_decision_rule_outcome 分别记录零结论三门。正向判据未通过，不等于零模型已获支持；零结论门未冻结或未全部通过时，结果保持 unsupported_or_undecided。

经验实例采用四种汇总状态：supported、unsupported_or_undecided、null_supported、not_evaluated。汇总状态不取代具体结论：必须另记哪些预定判据通过、哪些被反证、哪些仅因精度或材料不足而未决，不能把明确反证与无法判断混为一种证据。supported 要求合格实例的正向门通过；null_supported 要求等价性或充分性、功效或灵敏度及容差全部通过；not_evaluated 只表示尚未运行。结果记录必须链接 evidence_refs 与 analysis_artifact_refs，并保留结果时间、合同版本和偏离记录。抽象根族或格式正确的实例 ID 都不能独立产生支持。

实例能否支撑 C合同还受 support_eligibility_rule 约束。正向支持只来自带可审计版本和时间戳、在结果前状态为 frozen_before_evidence、并按冻结合同完成为 completed_from_frozen 的 confirmatory 或 replication 实例，同时要求 decision_rule_outcome.passed=true、结果状态和外部证据/分析制品可解析。falsification 实例只可支持预注册的反驳或零模型判断，不能反向救援正向 G。exploratory、draft、deviated_after_evidence 或存在未披露偏离的实例只能生成候选、记录偏离或保持未决，不得以正式实例资格支撑要求该资格的C分支。内部定义、概念标签和框架自身说明均不构成实例的经验支持。

四个根的尺度不变量共同包括预选子型、成功判据、decision_rule 与 null_decision_rule；尺度迁移时必须保留，不能改换。申诉可以挑战候选对象、子型、成功判据、N0、主目标或聚合、模型选择或集成、多重比较、控制、正向阈值、零结论规则、数据分割、外推单元、合同版本、预注册状态、偏离记录和证伪条件。任何一项被证明在结果后改变，都要降低支持资格，不得以事后版本覆盖已经冻结的记录。

4.2　人类经验实例合同 ​

H1、H4、H5 不是通用经验问题族，却同样是抽象经验假设族，不能靠名称、接口字段或框架定义获得真值。它们使用独立的 human_empirical_instance_contract：身份字段以 claim_id 取代 root_id，且只允许 H1、H4、H5；其余预注册段、结果段、缺失编码、版本冻结、阶段、结果四态、偏离披露、正向门、零结论门、证据引用和分析制品纪律与根实例合同同构。相应实例正式称为 H1-instance、H4-instance、H5-instance；经验真值属于这些具体 H-instance，不属于抽象 H 命题。

H-instance 也必须在读取结果前唯一预选一个子型和该子型的一个成功判据。下表是单主判据程序的标准登记分类，不是意义、权力或历史载体的穷尽分类。所问对象或设计超出列表时，另行说明可检验问题与研究程序，不能硬塞进一个有利类别。

命题必须唯一预选的子型或结果家族允许的成功判据结论停止位置
H1 意义与协调资源配置结果、行动选择结果、协调结果三选一meaning_arrangement_resource_allocation_effect、meaning_arrangement_action_choice_effect、meaning_arrangement_coordination_outcome_effect 中与所选子型对应的一项只登记指定对象、尺度、窗口和结果家族内的条件性指向锚点；不推出统一内心、真实同意或共同意志
H4 权力、中介与反身性证据覆盖、表达安全、对象行为、反身响应四选一position_or_mediation_evidence_coverage_effect、position_or_mediation_expression_safety_effect、mediation_or_publicity_behavioral_response_effect、observation_or_publication_reflexive_response_effect 中与所选子型对应的一项只登记指定位置、中介、公开条件、通道和结果家族内的遮蔽、放大、行为或反身响应；不推出恶意、责任或自动处置
H5 历史留痕载体先在 institutional_or_textual_record、role_or_organizational_arrangement、habit_or_practice、trauma_record、collective_memory_carrier 五个载体家族中唯一预选一个子型，再填写与该子型一致的 selected_carrier_family_id 和一个具体 selected_carrier 原子引用threshold_persistence_over_preregistered_window、repeat_detection_across_preregistered_windows、persistence_after_event_or_exposure_end 三选一只登记指定载体、可观察量和窗口内的候选留痕；后续载体效应另按§4.5取证；当前表示之外的历史增量才另需G3-instance

H1 不能在资源、行动、协调三个结果中“任一有利即成立”；H4 不能在证据覆盖、表达安全、行为和反身响应之间事后择优；H5 不能在多个载体或多个持久判据中寻找一个幸存结果。H5 的 selected_carrier 必须是一个非空原子引用而不是列表，selected_carrier_family_id 必须与所选子型的 carrier_family_id 完全一致；否则实例在读取结果前就不具备资格。多目标、多模型与多重比较仍须在 decision_rule 中冻结唯一主目标或聚合、模型选择或集成及校正规则。正向门未过时默认是 unsupported_or_undecided；只有预注册 null_decision_rule 中的等价性或充分性、功效或灵敏度及容差全部通过，才是 null_supported。探索性、证据后偏离或未披露偏离的 H-instance 只生成候选或未决，不能把 HV03、HV08 或 H5 历史载体路由升级为经验成立。

H2、H3、H6 不进入这份经验实例合同。H2 是承接与责任分型规则，H3 是制度写回分类规则，H6 是开放性承担的规范边界；它们可以限定接口怎样分类或停止，却不能凭分类成功产生经验机制支持。任何 H-instance 即使获得 supported，也只提高描述或解释强度，不产生价值、责任、义务、正当性、授权或现实处置。

4.3　G1 候选分组的条件增益 ​

命题：在对象、尺度、时间窗、K、候选分组和阈值均已预先登记的实例中，若候选分组在控制共同环境、采样或分类偏差及分组泄漏后，相对于复杂度匹配的N0仍取得预定样本外增益，并通过边界扰动及独立时间块或地点复核，则该分组在该SP/T/K下获得有限的对象识别支持。

G1 检验的不是“世界上是否终极存在这个对象”，而是当前候选分组是否比复杂度匹配、且不使用该分组信息的 N0 更能解释预定的样本外差异。G1a 只允许选择 out_of_sample_predictive_gain，G1b 只允许选择 out_of_sample_intervention_gain；子型与判据都不能在结果后互换。共同环境、采样程序、分类偏差、分组泄漏和模型复杂度必须进入控制或竞争解释。

最低正向支持需要预定评价指标与阈值、相对 N0 的样本外增益、边界扰动稳健性，以及独立时间块或地点复核，并且实例满足支持资格。样本外增益未过正向阈值，或边界扰动、独立复核未再现，默认只表示 G1 未获支持或结果未决；只有预注册 null_decision_rule 中的等价性或充分性检验以及功效、灵敏度与容差门通过，才可支持 N0 或反驳对应 G1-instance。对象、分组、成功判据、N0、决策规则、阈值、数据分割或泄漏控制未在结果前冻结时，实例暂停。通过 G1 只允许登记限定 SP/T/K 内的对象识别强度、边界可信度和分组适用窗，不允许作终极本体裁决，也不生成主体、目标、价值、责任或授权。

4.4　G2 指定通道效应与逐维有限性 ​

命题：G2必须在结果出现前唯一预选一个子型及成功判据。在预先指定的载体或通道实例中，只有预选的受控扰动、受控干预或具备识别条件的自然变异使指定状态转移出现超过预定阈值的差异，才把该通道登记为该转移的候选因果承载。容量、时延、可靠性、可控性和损耗必须逐通道、逐维度分别测量；未测维度不随命题成立。

G2a 预注册受控识别，并必须在 controlled_perturbation_effect 与 controlled_intervention_effect 中唯一预选一个；不能把“扰动或干预任一成功”写成一个事后析取判据。G2b 预注册具备识别条件的自然变异，唯一允许判据为 identified_natural_variation_channel_effect。两种子型都要先指定通道、目标转移、量的类型与单位、比较阈值和待测维度。零模型只按被选判据书写：预选的扰动、干预或自然变异不使目标转移出现超过阈值的差异；未预选判据不参与实例成败。各有限维度分别以无差异或预定基线为 N0。

G2 不宣称所有因果过程都有当前可见通道，也不宣称所有通道在所有维度都有限。只测得时延，不能连带宣布容量、可靠性、可控性和损耗已经成立。只有同型量，或具有明确类型转换、单位、核算边界与会计规则的量，才可进一步追踪转移。预选判据未产生阈值以上差异，默认只记正向 G2 未获支持或未决；只有预注册为反驳或零判断、且相应零结论规则通过，才可反驳该实例。共同输入、替代通道或测量协议能够解释差异时，应撤回候选通道支持；未预选判据的有利结果不能救援。G2 只能定位候选因果承载与已测维度的限制，不能创造跨领域统一成本，更不能把载体变成责任主体。

G2检验指定通道与已测维度，不是全部因果知识的唯一入口。若合格比较识别了某项处理的总效应而尚不能区分通道，应保留该总效应并把通道标为未决；不得为了填写G2而补造机制。若总效应接近零，也不能仅据此否定相抵或补偿的局部过程，相关过程仍须独立证据。干预实现、共同输入、选择与测量条件改变时，重新审查当前主张；事后转用有利判据不恢复原确认性资格。

4.5　历史形成、当前载体与G3条件增量 ​

历史研究首先区分三个问题：先前经历怎样形成当前状态；当前载体怎样保留、更新并继续影响后续结果；在给定当前注册表示之后，历史资料是否还提供额外信息或作用。前两项可以成立而第三项不成立，也不能由第三项未获支持反推前两项成立。G3只检验第三项，不能代替全部历史因果、学习、累积、持续或再生产的研究。

命题：G3必须在结果出现前唯一预选一个子型及成功判据。若历史变量在观察未来结果前已经定义，并在控制当前注册状态、环境与测量协议后，对预定结果提供可复核的样本外条件增量信息，则G3a可支持预测性路径依赖；G3b除该条件增量外，还必须在历史擦除、历史恢复或等价干预中预选一个判据，并且只有该判据超过预定阈值时才支持因果路径依赖。

G3a 检验预测性路径依赖，唯一允许判据为 historical_conditional_predictive_gain。G3b 检验因果路径依赖，必须在 history_erasure_effect、history_restoration_effect、equivalent_intervention_effect 中唯一预选一个；不能等结果出来后再从擦除、恢复或等价干预中挑选有利结果。前者要求历史变量在当前注册状态之外，对预定未来结果提供样本外条件增量；后者还要求被预选的因果判据改变结果。G3a 与 G3b 都以当前注册状态构成充分统计量、历史项不提供条件增量为零；G3b 还要求自己预选的干预判据不改变结果，未预选判据不参与成败。

痕迹被保存，不等于痕迹进入未来转移；预测增益存在，也不等于历史具有因果效力。历史变量若在见到未来结果后才定义、当前状态明显遗漏，或子型与成功判据未唯一预选，实例暂停。控制当前状态、环境和测量协议后历史项未提供正向增量，或 G3b 预选判据未过正向阈值，默认只记未获支持或未决；只有按冻结的反驳或零结论规则完成，才形成相应反驳。其他未选判据不能用于救援。通过 G3 只允许在预注册窗口内登记预测性或因果性路径差异，不能推出历史宿命、绝对不可逆、责任或授权。

适用范围说明：G3a与G3b是本框架对“当前注册状态之外的历史条件增量”的窄分类，不是全部历史因果的定义。设较早经历H改变当前技能S，S再影响结果Y；若S已充分携带相关历史信息，则在给定S后，H对Y可以不再增加预测信息。此时G3窄条件未满足，但H→S→Y的历史形成过程和一般意义上的学习仍可能由独立的过程材料或研究设计支持。应分别报告总历史作用、当前载体和条件残差，不能通过遗漏已知S制造G3增益。〔研究03.03、04.01—04.04、24.04、25.08〕

跨期判断分别登记载体传递路线与历史增量路线。载体传递路线要求已测得的当前状态或载体、此前输入或变化进入该载体的依据、载体在声明窗口内的保留或更新，以及它继续影响预定结果的纵向材料。只见结果持续或载体存在，不能确认传递机制；因果主张还须按§2.4比较中断、替换、恢复或具备识别条件的自然变异，处理共同输入、持续暴露、选择、失访与测量改变。只有相关性材料而缺少相应识别依据时，止于跨期描述或机制候选。

申请下文载体分支的正式机制支持时，还须由符合资格的G2-instance或该接口指定的H-instance支持相应通道和结果；H5只支持所选载体与窗口内的留痕，不能单独满足后续效应或因果门。原实例的对象、结果与窗口必须覆盖所作主张，不能用一次即时效应外推长期效应，也不能将若干分别成立的局部环节当作整链已接通。已有领域证据仍按§2.1.1保留自己的结论与限制，不因本节分流自动取得G或H实例资格。

历史增量路线另按G3合同检验当前注册状态之外的条件增量，预测性与因果性结论继续分开。载体传递可以成立而G3未获支持；G3正向门未通过也不证明载体传递成立。不得为取得历史增量而遗漏已知当前状态，不得在结果后切换路线挽救原主张；每条路线独立说明依据、竞争解释、失败条件和结论上限。累积、持续、学习、迟恢复和跨期再生产都不凭名称取得支持。

历史条件增量依赖当前表示的选择，不能作为脱离表示的系统本质。设完整当前状态为 x_t，登记表示为 z_t=π(x_t)，所保留历史为 h_t。历史对给定 z_t 后的未来目标仍有增量，可能因为 h_t 补回了 π 折叠的当前差异；这不单独证明完整动力具有额外历史项。应在可取得且与任务相关的当前载体、测量误差和模型复杂度之间作相称比较，禁止故意删去已知当前状态制造历史增益。

现实中完整状态通常不可得，因此也不能把“原则上可扩充为充分状态”当作本案已经证明无历史增量。若资料只支持相对于当前注册状态的增量，就按这一表示、目标与窗口报告；改变表示后重做比较。用历史辅助预测的价值、历史如何形成当前载体，以及窄G3实例是否获得支持，是三个可以具有不同答案的问题。附录C.11给出当前投影遗漏产生历史增益的精确例子。

4.6　G4 表示闭合与对象或干预转换 ​

命题：G4必须在结果出现前唯一预选一个子型及该子型的一个成功判据：G4a闭合失败可检验被排除尺度变量在给定目标尺度保留变量后的条件增量信息、条件预测增益或条件干预增益；G4b对象或干预转换可检验尺度变换M与对象动力或干预的非交换、目标映射不满足预冻结K、有效关系改变或干预响应改变；只有预选判据超过预定阈值或容差，才支持对应实例。

G4a 与 G4b 回答不同问题。G4a 允许的成功判据是 conditional_information_gain、conditional_predictive_gain、conditional_intervention_gain；每个实例只能预选其中一个。其零模型是：按预选判据，被排除尺度变量在保留变量条件下不提供超过阈值的条件增量。G4b 允许的成功判据是 object_dynamics_non_commutation、intervention_non_commutation、identity_criterion_violation、effective_relation_change、intervention_response_change；每个实例同样只能预选其中一个。零模型也只按被选项书写：对象动力可交换、干预可交换、目标映射满足预冻结 K、有效关系未超容差，或干预响应未超容差，不得把五项合成一个析取兜底。

一般相关、无条件耦合、相似叙述和同尺度遗漏变量都不足以支持 G4。结果前未唯一预选子型与成功判据，或 D3/E5 映射、比较模型、正向阈值、null_decision_rule、功效或灵敏度门与容差未冻结，实例暂停。正向判据通过时，G4a 只登记预注册变量、指标、尺度和窗口内的闭合失败，G4b 只登记预注册映射、K、尺度和窗口内的预选转换候选。正向判据未通过，默认只记 G4 未获支持或未决；只有零结论规则中的等价性或充分性检验、功效或灵敏度门及容差实际通过，G4a 才可登记判据限定闭合，G4b 才可登记未发现该预选转换。单纯“未显著”或未过正向阈值，不能直接登记闭合、对象未转换或干预等价。未选判据不得参与救援或反驳。通过 G4 也不表示高尺度更真、更重要或拥有更大处置权。

4.6.1　形式闭合、近似闭合与经验资格 ​

在确定性模型中，若源状态空间为 X，表示为 π:X→Y，且 Y=π(X)，一步动力为 F:X→X，则存在宏观更新 F̄:Y→Y 使 π∘F=F̄∘π，当且仅当同一表示的任意两个源状态在更新后仍有同一表示。这个条件是模型内的精确闭合判据。若它对全状态域成立，固定动力的多步交换可由归纳得到；只在少数访问状态上成立，不能外推为全域闭合。静态查询充分也不能代替这个动力条件。

允许多个操作时，应逐个声明操作的具体版本，并检验各自的投影更新；若宏观操作不能确定对应的微观实施，还要检查不同允许实施是否给出相同或容差内的宏观响应。随机模型须检验到每个目标状态或目标块的条件转移概率，只有均值相同不足以证明分布闭合。补入某个组成比例可以修复指定时点的一步预测，却不自动给出该比例自身的更新规律或所有操作下的闭合。

近似闭合必须绑定误差量、初始条件、目标、操作集和期限。设每步投影误差至多ε，拟用宏观更新在所涉区域的Lipschitz常数不超过L，则从相同初始表示出发，第t步误差至多 ε∑_{j=0}^{t−1}L^j；此界要求每步前提始终成立。L<1时可得到统一上界ε/(1−L)，L=1时界为tε，L>1时误差界可能迅速增大。不能把单步平均误差或短时拟合误差直接代入这一逐状态、逐步骤的界。

这些证明提供条件结构，不授予现实G4-instance支持。经验上仍须核对测量、映射、样本、操作与误差条件，并分别执行正向门和零结论门。形式证明精确闭合，与有限资料中未发现偏离，具有不同证据身份；没有足够灵敏度时，后者保持未决。

4.7　一个虚拟的根实例组 ​

下面的 m1—m4 只用于展示合同怎样工作。它们描述一个虚构的多层输运模型，没有引用外部观察，不构成任何 G 命题的经验支持。

m1 / G1a。 候选对象是若干相互连接的单元组，预先冻结 B、X、T、SP、K、分组方式、复杂度匹配 N0，并唯一选择 out_of_sample_predictive_gain 及其指标和阈值。若候选分组只在训练样本有效，或边界轻微扰动后增益消失，m1 失败；只有独立时间块也复现，才得到该窗口内的有限对象识别支持。

m2 / G2a。 在 m1 的候选对象上，预先指定一条传导通道和目标状态转移，并唯一选择 controlled_perturbation_effect，再对通道作受控阻断。若阻断使目标转移超过阈值地改变，只能把该通道登记为候选因果承载。假设本例只测了时延，则容量、可靠性、可控性和损耗仍是未知，不能随 m2 一并成立。

m3 / G3a。 先定义“前三轮积压”这一历史变量，并唯一选择 historical_conditional_predictive_gain，再控制当前队列、环境输入和测量协议。若历史项对下一轮结果仍有样本外条件增量，可登记预测性路径依赖；没有历史擦除或恢复干预时，不能升级为因果路径依赖。

m4 / G4a。 结果前只选择闭合失败子型及 conditional_information_gain，冻结微观与聚合尺度、M、保留变量、被排除变量、指标和阈值。只有被排除的局部时序在给定聚合变量后按该判据提供超过阈值的条件增量，才登记该窗口内的闭合失败；不能在看到结果后改用预测或干预增益，也不能改写为 G4b 的对象转换。

这个例子显示，四个实例可以相互提供后续问题，却不会互相替代。m1 通过不保证 m2 的通道有效，m2 通过不保证 m3 的历史效应，m3 通过也不保证 m4 的尺度闭合失败。

4.8　认识论约束 E1—E5 ​

4.8.1　E1 对象声明约束 ​

E1要求明确当前判断的对象、范围、尺度、时间窗、必要变量和同一性；比较主张另须说明相应基线或零模型。缺少某一字段时，说明它对哪一项推论造成什么限制，不以格式缺失取消独立成立的来源事实。D0字段不全不能把分析者分组宣布为客观结构；普通事实、文本意义和数学证明仍按各自证据与论证责任审查。

4.8.2　E2 观察位置与模型限制 ​

观察位置、测量通道和模型选择限制可见范围，不能把一种记录当作对象的全部状态；也不预设每个具体任务都必须增加视角。表示是否充分取决于目标、期限、环境与允许操作。不可见不等于不存在。任务相关盲区显著时，应补证、收窄用途或保持未决；是否可试探仍须比较风险、窗口与授权。

4.8.3　E3 条件性观测参与 ​

只有观察、命名、评分或发布与对象发生实际因果耦合时，才登记观测参与。仅有时序先后或“被观察会改变对象”的机制故事不足以通过；必须定位通道，并建立未观测、替代观测或阻断反事实。

4.8.4　E4 竞争解释与残差保留 ​

解释应比较材料允许且足以改变判断的竞争说明，保存反例与未解释残差。竞争关系须说明争的是什么：效应大小、作用机制、语境含义、外推范围或规范前提；彼此兼容的解释可以承担不同层次的责任。没有合理竞争解释时不为凑数虚构一个，仍须说明检索范围与失败条件。开放性、爱、复杂性或理论整体感不能填补证据空白。尚未区分的竞争解释如何限制行动，须结合损害、可逆性、外部义务和当前权限判断。

4.8.5　E5 跨尺度迁移检验 ​

跨尺度迁移必须通过 D3 的映射、不变量、改变项、丢失项、误差、竞争解释与残差检验。E5 的推理硬前提只有 D3；E1、E4、EVIDENCE 与 ANALOGY 都是方法门，不进入推理无环图，也不伪装成额外经验原因。E5 不依赖 G4 为真；反过来，任何 G4-instance 都必须通过 E5。观察范围扩大不意味着授权范围扩大，J 轴不得随其他尺度轴自动外推。

4.9　人类经验条款的证据状态 ​

H1（意义与协调）、H4（权力、中介与反身性）与 H5（历史载体）是待检验的经验假设族。三者的具体事实断言按对象与证据接受检验；本程序的正式支持资格只授予完成human_empirical_instance_contract并满足相应判据的H-instance；定义、接口和框架自身表述均不是外部经验支持。没有合格外部实例记录时，empirical_evidence_records=[]，证据状态为 requires_instance_evidence。

因此，H1 需逐案在资源、行动或协调中唯一预选一个结果家族并检验意义安排的差异；H4 需逐案在证据覆盖、表达安全、对象行为或反身响应中唯一预选一个结果家族，再建立位置、中介或公开条件的通道和反事实。H5“历史留痕载体”必须唯一预选载体家族、一个具体载体原子引用和一个持久判据；只有家族与子型一致，且历史事件、基线、留痕可观察量、阈值和持久窗口均在结果前冻结，所选判据通过时，才允许登记指定载体与窗口内的候选留痕，并向 G3-instance 提交预先定义的历史变量候选。当前状态之外的历史路径增量及C4的相应修复窗口另经G3/C4；由当前载体传递的历史作用与一般介入时点效应，分别按§4.5和§6.10取得独立依据，保护、减伤或修复行动另经 C12、显式 N 前提与 O 程序。命题名称、内部定义或本框架自身叙述都不能替三者完成实例检验。

4.10　结果合同与机制条件 C1—C12 ​

各项合同依据自身的定义、经验依据、附加条件或规范与程序前提，限定能够登记的输出；其中依赖根实例的分支，必须取得相应实例支持。推理依赖列出进入无环推理图的硬前提；方法门列出协议要求，它们决定能否发布，却不充当经验原因；领域特化与适用关系在正文另行说明。下面四个固定合同字段保持与结果合同同步，证据、反例与失效边界则按推论组集中呈现。

C编号服务于不同的论证工作。C1、C2、C4的历史增量分支与C6，主要登记相应经验实例已经支持的限定结果，并添加使用范围；C3、C5、C7、C9—C11还须组合另列的机制、时间或领域条件；C8基础模式依赖另行取得的变异、差异保留与再生产证据；C12是规范程序门。共用编号不使这些内容成为同类经验定律，同一材料在根实例与推论中被再次引用，也不构成第二份独立支持。

4.11　第一组：对象、承载与反馈 ​

4.11.1　C1 对象与边界强度 ​

推理依赖：D0；G1

附加条件：使用已完成预注册并取得当前实例支持的G1-instance；候选对象S*、N0、评价阈值、外推单元和边界扰动方案已冻结

允许结论：可以在该SP/T/K及外推单元内登记对象识别强度、边界可信度和候选分组适用窗。

禁止跳跃：把有限对象识别支持改写为终极本体裁决；推出天然边界、统一主体、共同目标或S0-S6阶段；推出存续价值、责任分配、选择或处置授权

方法门：E1；E4；EVIDENCE

推导时先用 D0 冻结候选对象而不预设其有效，再读取同一 G1-instance 相对复杂度匹配 N0 的样本外增益，最后结合边界扰动与独立复核登记支持强度和适用窗。

4.11.2　C2 承载与通道约束 ​

推理依赖：D0；G2

附加条件：使用已预注册且取得当前实例支持的G2-instance；讨论转移时，源量与目标量必须是同一类型或给出明确类型转换；量的单位、恒等判据、时间窗、核算边界及转换映射或会计规则已冻结；容量、时延、可靠性、可控性与损耗逐通道逐维登记，未测维度保持未知

允许结论：可以登记指定状态转移的候选因果承载，以及已测类型、单位、窗口和维度内的通道限制；满足同型量与映射条件时才可追踪转移。

禁止跳跃：把不同类型或不可换算量合并为统一成本；把一个已测有限维度推广到全部维度或全部通道；把载体或通道自动认定为责任主体或成本承担者；从资源占用推导跨领域守恒

方法门：E1；E4；CAUSAL；EVIDENCE

推导只对指定通道、目标转移和已测维度成立。同型量可用单位恒等追踪；异型量必须经过明确转换或会计映射。未测维度与边界外量保持未知，而不是被写成守恒、消失或成本已经转移。

4.11.3　C3 有效反馈与反馈介导学习 ​

推理依赖：D2；G2

附加条件：反馈分支须有返回通道、时间顺序、被改变字段及无返回或阻断反事实；有效反馈只要求改变至少一个后续状态、概率或约束，不要求持久历史留痕。载体学习分支另按§4.5核对更新载体、保留或更新规则、后续多轮调用、预定任务比较及相应因果证据；历史增量型学习分支另需G3-instance、可保留更新、重复轮次和预定任务比较。

允许结论：基础分支可登记有效反馈及其时滞和作用字段；载体学习分支条件成立时，可登记指定更新、任务与窗口内的反馈介导学习候选；另有G3-instance、可保留更新和重复轮次时，可登记历史增量型反馈介导学习候选。

禁止跳跃：反馈入口或接收证明等于有效反馈；一次状态更新等于学习、修复或正向改进；反馈或学习事实直接推出价值方向或行动授权

方法门：E4；CAUSAL；EVIDENCE

基础分支以G2-instance识别返回通道的候选因果承载，再按D2比较有返回与无返回或阻断条件。载体学习须追踪更新怎样保留、被后续轮次调用并影响预定任务，依§4.5核对纵向与因果材料；当前状态充分不否定这一路线。历史增量型学习另外要求G3在当前注册状态之外提供增量，两类证据不能互相代替。

分支登记为C3-feedback（返回通道、后续状态或转移改变、阻断反事实）、C3-carried-learning（另有§4.5的更新载体、多轮调用与任务结果证据）与C3-learning（历史增量型；另加G3，并有可保留更新、重复轮次、预定任务样本外比较）。

4.12　第二组：历史、负荷、尺度与溢出 ​

4.12.1　C4 历史作用、路径差异与修复窗口 ​

推理依赖：D1；历史增量分支另需G3，当前载体与介入时点分支按§4.5、§2.4取得相应证据

附加条件：G3分支的历史变量须在未来结果前定义，当前注册状态、环境与测量协议已控制；预测性与因果历史增量子型不得混同。一般历史形成和当前载体作用按§4.5的独立路线取证；讨论修复窗口还需预先公开的K*/F*、不同时点介入比较与相应因果识别，只有主张额外历史残差时才追加G3。

允许结论：G3分支可以在预注册窗口及当前表示下登记预测性或因果性历史增量。当前载体路线可以按自身材料登记有限历史作用。另有K*/F*、时点比较及相应识别依据时，可登记条件性修复窗口；这不要求结果必须保留当前状态之外的历史残差。

禁止跳跃：痕迹保存等于历史效应；预测增益等于因果或不可逆；路径差异等于命运、进步、衰退、责任或阶段回退；K*/F*未公开即宣称修复

方法门：E1；E4；CAUSAL；EVIDENCE

演化先按D1分类，不能从定义推出历史作用。当前载体路线核对形成、保留、调用和后续结果；历史条件增量路线分别读取G3a的预测增益或G3b的因果依据。修复窗口比较不同时点介入对预先公开K*/F*的可达性和代价；只有它同时声称当前表示之外的历史残差时，才承担相应G3责任。

4.12.2　C5 负荷、容量与恢复 ​

推理依赖：D0；G2

附加条件：瞬时分支须有同型需求—容量定义、单位或转换映射、同窗测量和分布位置。载体累积分支须依§4.5追踪负荷进入当前损伤或容量状态、跨窗累积或恢复过程及其后续效应，并满足G2通道要求；历史增量型累积分支另需G3-instance和可定位历史载体。

允许结论：基础分支可登记指定窗口和位置上的瞬时负荷—容量缺口；载体累积条件成立时，可登记该载体、窗口和结果内的累积损伤或迟恢复候选；另有G3-instance时，可登记当前状态之外的历史增量型累积或迟恢复候选。

禁止跳跃：负荷必然单调累积或过载必然崩溃；把不同类型需求和容量直接相减；瞬时缺口自动证明持久损伤；恢复需要直接生成具名主体的牺牲义务

方法门：E1；E4；CAUSAL；EVIDENCE

基础分支冻结需求、容量、补给、损耗和时间窗的类型与单位，以G2-instance确认承载通道，再比较同窗即时缺口与溢出位置。累积与迟恢复须有跨窗材料：载体路线按§4.5识别历史负荷怎样形成当前状态、该状态怎样维持或恢复并影响后续结果；历史增量路线另由G3检验当前注册状态之外的增量。当前状态充分与载体解释相容，但不能代替其形成过程与因果证据。

分支登记为C5-instant（同型需求—容量映射、同窗测量）、C5-carried-cumulative（另有§4.5的当前载体、跨窗累积或恢复及后续效应证据）与C5-cumulative（历史增量型；另加G3，并有历史载体、后续容量或恢复差异）。

4.12.3　C6 尺度闭合与对象转换 ​

推理依赖：D3；G4

附加条件：结果前唯一预选G4a或G4b，并从该子型allowed_success_criteria中唯一冻结selected_success_criterion；M(SP0→SP1)、保留项、改变项、丢失项、误差、比较模型、正向阈值和容差已冻结；若要登记限定单尺度闭合或未发现预选转换，null_decision_rule中的等价性或充分性检验、功效或灵敏度门及容差必须结果前冻结并实际通过

允许结论：可以分别登记G4a在预注册变量、指标、尺度与窗口内的单尺度闭合失败，或G4b在预注册映射、K、尺度与窗口内的对象/干预转换；正向判据未通过默认只登记未获支持或未决。只有预注册等价性或充分性检验及功效、灵敏度与容差门通过，才可对G4a登记判据限定闭合，或对G4b登记未发现预选转换；不得外推至未选判据。

禁止跳跃：用一般相关、无条件耦合或同尺度遗漏支持G4；把G4a和G4b事后并取；在同一子型内事后改换成功判据或用未选判据救援；把未显著或未过正向阈值直接称为单尺度闭合、对象未转换或干预等价；尺度范围扩大即解释更真或授权更大；同名术语证明对象或干预同一

方法门：E4；E5；EVIDENCE

G4a 单独检验被排除尺度变量的条件增量；G4b 只检验其预选的对象动力非交换、干预非交换、预冻结 K 失效、有效关系改变或干预响应改变之一。C6 所引用的 G4-instance 必须已在结果前同时冻结一个子型和一个成功判据；子型之间或子型内部都不能在结果后互换。

4.12.4　C7 局部改善与跨边界溢出 ​

推理依赖：G2；真正跨尺度的主张另需D3/E5映射，主张闭合失败或对象/干预转换时再需相应G4实例

4.16　经验判断的范围与停止位置 ​

经验判断提供受对象、尺度、时间窗、证据和外推单元约束的描述与有限解释。G问题族中的具体事实断言须由实例检验；C登记既有结果或组合机制条件；F给出形式前提下的证明；现实机制仍需独立实例证据。定义、编号、示例和内部说明不能决定经验命题在世界中是否成立。若进一步评价价值、责任、牺牲、选择或处置，就须补入人类领域分型、规范理由与O1—O4程序，不能让经验结论自行越过这些责任。

4.17　共同方法约束 ​

方法约束管理分析者怎样构造、核对和使用模型，不宣称世界必然怎样运行。它们可以被质疑和修订，其用途须由实际错误减少、理解增益和使用成本接受比较。

4.17.1　法1 任务与表示须共同声明 ​

对象、分层、粗细尺度和目标变量绑定任务、观察位置、期限、环境与用途。转换须检查保持、折叠、遗漏和新增内容，不能预设无损，也不能反过来断言每次转换必然造成任务相关损失。目标表示是否足以恢复答案、推进动力或评价允许干预，分别检验；不同转换顺序是否等价也分别检验。需要保留的是任务所依赖的区别，不是无条件恢复全部细节。

4.17.2　法2 材料身份与支持范围须可追溯 ​

报告、观察、模型信念、形式证明、模拟输出和执行回执保留各自身份。每次推断说明它用到什么新增信息、前提和规则；不得将同一资料的再次处理计作新的独立观察。模拟状态可以成为下一轮模拟起点，递归深度本身不能增加经验支持或能力等级。新的计算或证明可以改善对已有材料的理解，但其增益来自可检查的论证，不能被包装成新现实样本。

4.17.3　法3 事实、价值与行动资格分别成立 ​

事实、预测、形式可行性和技术能力都不能单独产生价值、责任或处置权。分析推荐公开规范目标、证据、代价和异议；现实采用另须有效权限、保护底板、实施资源、停止与补救条件。规范前提约束选择，不反向证明经验机制为真。

4.17.4　方法有效性与框架评价 ​

G问题族组织经验检验，不以问题数量证明覆盖充分；C合同组织结果使用，不以合同完整证明现实可靠。检验整套框架是否值得使用，应另设具有共同目标、资料和预算的比较：它是否比足够的专业方法或较简方案减少实质错误、保留必要区别、改善解释或决策，以及是否付出了相称成本。没有这种比较，只能陈述设计用途和已核的局部结果。

个别实例效应、问题族在某一对象集合中的适用率、框架在指定任务上的净增益，是三个不同经验目标。抽样单位、外推范围和评价规则须各自登记；不得把一批成功实例或大量阅读材料当成普遍有效性的证明。

4.18　条件形式命题 ​

以下命题在明示数学对象中成立。它们给出表示、转化和行动的可检查条件，不是未经测量的现实规律。现实应用还须按§2.1.2核对变量映射、假设、误差和适用范围；证明存在某个函数，也不保证它可计算、及时可得、能够实施或有权采用。

4.18.1　F1 任务恢复 ​

设非空状态域X、表示π:X→Y且Y=π(X)、目标q:X→V。存在仅使用表示的解码器g:Y→V使q=g∘π，当且仅当π(x)=π(x′)总蕴含q(x)=q(x′)。成立时g在Y上唯一。也就是说，同一表示不能合并当前任务必须给出不同答案的状态。证明与有限标量误差界见附录C.6。

4.18.2　F2 动力与允许干预下的闭合 ​

设F:X→X为确定性一步动力。存在宏观更新F̄使π∘F=F̄∘π，当且仅当同一表示的任意两个源状态在更新后仍有同一表示。若对全状态域成立，固定动力的任意有限步演化可交换。允许动作集合U时，须对每个F_u分别满足该条件，并核对动作在同一表示内的可实施性和不同微观实现。静态恢复充分不自动满足动力或干预闭合；随机模型还须比较完整的目标块转移概率。证明见附录C.8。

4.18.3　F3 信息约束下的共同可行动作 ​

对有限单轮确定性任务，设当前材料与非空状态集合X_y相容，每个状态x有已经按目标、保护、资源和有效权限确定的合格动作集合A_ok(x)。存在只依据当前表示y作出的、对全部相容状态都合格的一个动作，当且仅当∩_{x∈X_y}A_ok(x)非空。故识别全部状态不是有限行动的普遍前提，而每个状态分别有办法也不保证目前能选对。证明见附录C.12；随机和序贯策略须建立自己的条件。

4.18.4　F4 连续转换的任务保持 ​

设f:X→Z、h:Z→W，第一段满足q=g∘f。组合h∘f仍能恢复同一最终目标q，当且仅当g在h限制到实际像集f(X)的每个纤维上常值。各步骤完成不同的局部任务，不能代替这个共同终点条件。函数表示保持、因果作用串联和共享资源下的联合实施分别核对，不能以一个接通标志互相代替。证明与反例见附录C.7、C.12。

4.18.5　F5 近似闭合的误差传播 ​

设目标空间有度量d，每一步所及状态的投影误差不超过ε，拟用宏观更新在相关区域的Lipschitz常数不超过L。从同一初始表示出发，t步误差满足e_t≤ε∑_{j=0}^{t−1}L^j。该界要求每一步的误差和区域条件持续成立；平均拟合误差不能直接替代逐状态界。L<1时有上界ε/(1−L)，L=1时为tε，L>1时上界可能迅速增大。证明见附录C.8。

4.19　任务族与动态精化 ​

结构表示应保留哪些区别，取决于所问任务及允许作用于对象的操作。表示更细可以保存更多差异，也会增加测量、存储、解释和维护成本；全部细节并不是每项任务的必要输入。在一个完全给定的有限确定性模型中，可以精确说明哪些状态能够合并，并求出满足特定要求的最粗划分。

设非空有限状态集为 X，Q 为有限个目标函数 q:X→V_q 组成的集合，U 为有限个允许动作的集合。每个 u∈U 对应一个全定义、确定性的更新 F_u:X→X；动作在全部状态均可实施，且此处不加入未登记的外部扰动。空动作串表示不更新。对动作串 w=u₁…u_k，记 F_w=F_{u_k}∘…∘F_{u₁}。这些条件限定下列命题的对象，不能由现实操作共享一个名称就认为已经满足。

F6 任务族的最粗充分划分。 对非负整数 H，定义 x∼_H x′，当且仅当对每个 q∈Q 和每条长度不超过 H 的允许动作串 w，都有 q(F_w(x))=q(F_w(x′))。这是等价关系。由其等价类组成的表示，恰好保留了给定期限内全部任务答案；任何能精确回答这些问题的确定性表示，都只能把同一等价类内的状态合并。

证明：自反、对称和传递性分别来自函数值相等的相应性质。每个目标及动作串的答案在等价类内恒定，故依 F1 可以由等价类唯一确定。若另一表示把不等价的两个状态合并，按定义必存在一个目标和一条允许动作串使答案不同；依 F1，该表示不可能精确恢复两者。因而任何充分表示所诱导的划分都细于或等于此划分。这种最粗性是相对于 X、Q、U、H 的状态划分而言，不证明参数最少、测量最便宜或某个自然语言概念不可替代。

固定有限期限的充分性不自动产生同一期限的动力闭合。取 X={a,b,c,d}，唯一目标 q(a)=q(b)=q(c)=0、q(d)=1，唯一动作满足 F(a)=c、F(b)=b、F(c)=d、F(d)=d。a 与 b 在当前及一步后都给出0，因此 a∼₁b；它们的后继 c 与 b 却在再下一步给出不同答案，所以 c 与 b 不属于同一 ∼₁ 类。对 H≥1，总能保证的是 x∼_H x′ 蕴含 F_u(x)∼_{H−1}F_u(x′)。推进时应扣除剩余期限，或另行要求固定划分在允许动作下闭合。

若要求对任意有限长度的允许动作串保持全部目标，定义 x∼_x′ 为上述所有有限串的答案均相等。此划分对每个 F_u 闭合：在任意后继串之前添加 u，便得到原定义中已经比较过的动作串。反之，任何同时恢复 Q 且在全部 F_u 下闭合的表示，可以逐步推进并恢复任意有限串后的目标，所以必细于或等于 ∼_。因此 ∼_* 是满足这些条件的唯一最粗状态划分，唯一性按等价类而不是标签名称计算。

有限域中可以直接求得这一划分。先按全部当前目标值形成划分 P₀。每一轮只读取上一轮划分 P_h，按签名 ([x]_{P_h},([F_u(x)]_{P_h})_{u∈U}) 同步分块，得到 P_{h+1}；其中 [x]_{P_h} 表示 x 在上一轮所属的块。每次严格精化至少增加一个块，至多发生 |X|−1 次严格精化；达到不再分裂时，各块既保留当前目标，又满足逐动作闭合。同步迭代第 H 层恰对应长度不超过 H 的目标比较，因此稳定划分与 ∼_* 相同。逐块异步执行也可以继续检查最终稳定性，但不得把其操作次数当成这里的期限 H。这个过程在完整有限表上可计算，不保证从不完整观测中识别真实状态，更不保证大型模型在给定预算内可解。

这一结果提供一条有条件的简化原则：合并在所问目标和允许作用下无法区分的状态；只有某项任务或操作确实区分它们时，才要求保留相应差异。增加目标或允许动作，会使所需划分保持不变或变细；缩短期限、收窄用途或限制操作，可能使更简洁的表示充分。调整任务可以形成新的合法问题，但不能据此宣称原任务已经完成。

误差容差需要另行分析。条件“两个答案的差不超过 ε”一般不传递：0 与 ε 接近，ε 与 2ε 接近，0 与 2ε 却可能超出容差。因此，近似相似性不能直接代替上述等价关系，也不能自动获得唯一最粗划分。可选择逐块直径、最坏恢复误差或明确的概率损失作为限制，但各自的最优解、稳定性与计算代价须另证。

本节是有限模型中的集合与动力命题。按输入串区分状态、形成等价类并递归细分，与 Moore 的序贯机器研究具有直接的数学联系；状态与动作的保持也与受控动力抽象相接。这里的结论由本节明确的有限模型与证明承担，不借用不同机器类别的额外最优性结论。〔Moore，1956，143及145—146页；Ravindran与Barto，2003〕它不宣布自然界有唯一正确的层级，也不把人的正当诉求缩减为现有预测目标。哪些目标必须保留、哪些动作允许实施，以及何种误差可以接受，仍由领域事实、规范理由和现实权限分别确定。
