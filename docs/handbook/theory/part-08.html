第八部分　人类状态原型 ​

8.1　本部分解释什么 ​

S0—S6 只适用于人类有意图集体：人们围绕可表达的共同问题、承诺、目标或意义安排形成，并通过角色、资源、规则、关系和反馈持续运作的团队、组织、机构、运动、共同体或治理安排。它们不是普适定律，不能直接套到个体人格、纯物理系统、物种演化或宇宙整体。即使在适用域内，S0—S6 也不是成熟度阶梯，不是历史必经序列，更不是价值排名。

编号只用于区分原型和方便检索。它允许我们问：“这个对象、这个子系统、这个时间窗，现在主要呈现什么结构构型？”它不允许我们说：“编号更大，所以人更好、制度更正当、文明更先进。”一个大型集体可以中心为 S5、边缘为 S3、技术单元为 S6、代际承接仍为 S1；同一功能也可以同时呈现两种原型。遇到这种情况，应登记 parallel 或 mixed，而不是把复杂性压成一个“整体阶段”。

状态原型只产生描述性、可撤回的分类。它不产生行动授权。任何现实干预都必须另行给出规范前提，通过 C12，比较包括不行动在内的方案，取得覆盖具体主体、对象、动作、地域和期限的 J 原子授权，并接受 O 程序、申诉与回滚。状态标签不能替这些门作证。

8.2　状态判断的最小合同 ​

每次判断都先冻结对象 object_id、同一性判据 K、九轴尺度剖面 SP=<A,X,T,O,C,R,I,N,J>、时间窗和子系统范围，然后分别记录入口条件、退出条件、可观察量、反例、证伪结果与缺失。分类模式只有四种：single_dominant、mixed、parallel、unknown。这里冻结的是本次分析用来追踪对象的判据，不要求被观察的成员构成、实际边界、角色、承诺或自我认同已经稳定。若需要改变K的定义，应另建有版本的记录，保留原判据、材料和判断，并重新核对对象同一性；核对未完成前，不将不同K下的记录直接接成同一对象的跨窗路径。

字段必须回答的问题停止位置
对象与 K我们追踪的是同一个人类集体，还是名称相同、对象已变？K未冻结、无法据其追踪对象或同一性尚未核清时，先做对象与同一性判断，不分配原型；成员或实际边界变化不自动等于K改变
尺度与时间哪些单位、空间、窗口、层级、影响位置和网络被看见？观察范围扩大不扩大 J 授权
入口与退出什么材料使某原型成为候选，什么材料使它不再主导？“像”一个原型不等于已经进入或必然退出
可观察量哪些行为、记录、通道、成本、恢复与写回能被复核？单一口号、总量或官方自述不足
反例与证伪还有什么会产生相同表象？什么结果会撤回判断？不主动找反证的标签只能算印象
证据覆盖哪些外部材料支持入口、观察与反证判断？证据能否解析并覆盖当前对象？内部定义、编号和框架叙述均不能替代对象证据
缺失是未收集、不可观察、不适用、冲突还是未知？不得把缺失补成“正常”“没有”或零值
规范与行动该分类是否给出价值、义务或处置权？全部状态均为 descriptive_only、action_authorization=none

五种缺失状态必须分开。not_collected 表示可取得但尚未收集；not_observable 表示当前权限、安全或测量条件下不可观察，不能要求弱势主体为填表而暴露；not_applicable 必须经过适用性检查；conflicted 表示合格来源互相冲突；unknown 表示已经尝试仍不能区分。关键入口、反证或尺度字段缺失本身，只支持 unknown 或暂停相关分类；mixed 和 parallel 须分别有多个原型及其对应位置的正向证据，不得把无知改名为混合。已经成立的局部材料仍按原范围保留。

8.2.1　运行时分类记录 ​

原型卡只有进入封闭的运行时记录，才构成可复核分类。记录必须同时冻结 record_id、对象与同一性标准、九轴尺度、时间窗、子系统范围、分类模式、候选状态、路径候选、五类条件结果、缺失数据、对象证据、不确定性、独立复核、申诉、回滚以及非授权边界。每一项入口、退出、观察、反例和证伪结果都使用同一结构：item_id + state_id + status + evidence_refs + reason；结果必须逐项覆盖候选原型，不能用一段总评代替。

single_dominant 恰有一个候选；mixed 与 parallel 至少各有两个候选并显式登记对应路径；unknown 不指定已获支持的原型，必须说明哪些关键材料仍不足以区分；已经成立的局部事实和组件观察保留在对象证据中，不能因总体原型未知而删除。运行记录若不容许在 unknown 的候选条件栏存放支持项，应将这些材料保留在对象证据及理由中，不伪造完整原型。任一候选至少要有入口和观察项的对象证据；一旦某个证伪项为 supported，该候选即被阻断，不能靠降低措辞强度继续保留。每次验证都必须另行提供外部 evidence_ids 注册表，记录内每一层 evidence_refs 既要解析到本记录的对象证据，也要递归解析到该外部注册表；省略注册表、顶层自报或幽灵引用均不能通过。内部编号、定义和自报判断不能替代对象证据。

复核者记录为 reviewer_id + independent + reviewed_at + material_version + outcome，申诉和回滚各自绑定结构化程序 ID 与状态。reviewer_id 经 NFKC、首尾空白与大小写规范化后不得等于对象 ID，也不得使用对象 ID 派生别名；换一个字符串不能把对象自身变成独立复核者。它们不能写成“已复核”“可申诉”之类自我声明字符串。无论复核结果如何，记录恒为 normative_status=descriptive_only、action_authorization=none：撤回或改写状态标签时，应保留原证据、异议与版本链。

U、H、G、C 编号在本部分有四种不同作用：U 提供对象、状态、通道、负荷和相位接口；H 提供人类世界中的意义、承接、制度写回、权力和历史载体适配；G 指明何时必须用独立合格实例把模式升级为经验机制；C 限制推论的停止位置。它们是合同链接，不是眼前对象的证据。

S0—S6 的配置描述不以 CM-PHASE 的多区间模式为前提。一个对象在已观察窗口中始终满足单一原型的必要条件，也可以取得相应的有限分类；它没有因此证明曾发生相位转移。进一步主张多区间、阈值或相位转移机制时，再按 CM-PHASE 及相应 G 实例检查。反过来，两区间形式模式成立，也不直接证明符合某个人类集体原型。

8.3　S0—S6 状态原型 ​

8.3.1　S0　锚点凝聚原型 ​

S0 描述的是“候选集体正在形成”，不是“低级组织”。共同问题、候选目标或意义表达开始聚拢注意、关系、时间和少量资源，但成员构成、实际边界、角色、承诺方式与共同身份的表达仍在形成或变化。分析仍须使用本次冻结且可据以追踪对象的K；形成中的状态变化不替代同一性判断。至少一个候选生成行动者反复进行翻译、召集、试探或承担真实成本，独立承接层尚未形成。候选集体可以在这里消散、休眠、并入其他安排或转向新的目标；各路径的发生比例须有相应机会总体和观察资料，不能由原型定义推定。过程结束本身不构成失败判决。

检查面S0 诊断卡
入口S0-E1：在本次冻结且可据以追踪对象的K下，共同问题或意义安排造成可见局部聚集，但成员、实际边界或承诺方式尚未稳定。S0-E2：候选生成行动反复出现，承接尚薄。
退出S0-X1：在同一K仍适用且对象同一性可追踪的窗口内，锚点、实际边界和生成角色跨窗稳定，并出现可追踪承诺与初步承接，可检 S1。S0-X2：聚集消散、分裂、被吸收或进入休眠，不必经过 S1；原K不再适用时，另做对象转换或终止判断。
可观察S0-O1 竞争表述仍在协商；S0-O2 资源聚集伴随高进出；S0-O3 生成行动者承担翻译、召集或试错；S0-O4 失败试探与备选历史仍被保留。
反例热点或平台推荐能制造短期同步；行政命名能制造形式团队。要观察奖励、曝光或命令撤除后，承诺和对象边界是否仍持续。
证伪与匹配临时聚集相比，共同方向、行动聚集与生成角色都无区别，则撤回 S0。若稳定角色、承接与重复运行早已存在，S0 也不是主导状态。
尺度必须区分生成者、早期参与者、潜在退出者与外部命名者；不能把个体人格聚合成集体状态。
证据升级意义安排造成资源、行动或协调差异须 H1-instance；指定通道造成形成须 G2-instance；历史留痕按 H5，当前载体的未来作用按§4.5；当前表示之外的历史增量才追加 G3。
合同链接U01/U02/U03/U08/U09/U11；H1/H2/H5；G1/G2/G3；C1/C2/C4/C5/C10/C12。

S0 允许的结论只是在特定对象、尺度和窗口内与锚点凝聚原型相容。它不能证明参与者缺乏能力、价值或意愿，也不能授权扶持、解散、筛选或排除。

8.3.2　S1　生成核心奠基原型 ​

S1 中，候选锚点、对象边界和至少一个生成角色已经能跨决策重复识别，基本规则、语言、资源通道和最早记忆载体开始奠基。主要翻译、决策、资源动员、冲突处理或关系修复仍集中在一个或少数生成角色，独立承接者很少。中心性是结构依赖，不是领导正当性的证明。

检查面S1 诊断卡
入口S1-E1：K、锚点和生成角色可重复识别。S1-E2：关键功能持续依赖生成核心，而非一次紧急集中。
退出S1-X1：新进入者形成持续承接、责任与边界接口，可检 S2。S1-X2：生成核心分裂、退出、被接管、休眠或对象消散，转入相应路径。
可观察S1-O1 锚点和边界初步稳定；S1-O2 关键决策依赖生成核心；S1-O3 规则和记忆载体开始重复；S1-O4 外部进入有限且定向。
反例成熟组织可能仍由创始人公开宣布决定，但实际承接层已庞大；行政新设部门也可能只是上级对象的角色单元。要追踪实际执行、停止权、反馈和核心暂时离场后的运行。
证伪生成核心低介入时，多中心承接仍稳定运行，则核心依赖被反驳。若锚点不稳定，但同一K仍适用且对象可追踪，可重新检验S0；若原K不再适用或对象同一性不明，应先检查对象转换或终止，或保持unknown，再对可识别对象分类。
尺度冻结生成角色、早期承接者、上级命名者与外部支持者；组织图与实际通道冲突时记 conflicted。
证据升级锚点或生成核心的结果效应分别需要 H1/G2；早期制度或创伤的载体效应依§4.5，留痕检 H5，历史条件残差另检 G3。
合同链接U01/U02/U03/U04/U06/U07/U09/U11；H1/H2/H3/H4；G1/G2/G3；C1/C2/C3/C5/C9/C10/C11/C12。

S1 不能被读成“幼稚”“落后”或“应被整合”。它不能赋予生成者永久领导、扩大权力、强制建制或替换他人的资格。

8.3.3　S2　首次扩展与承接分化原型 ​

S2 描述边界、成员、服务对象、地域、平台接口或协作网络的持续扩展。新进入者带来不同理解、技能、资源和风险，生成核心之外开始形成承接、退出、保留异议与未决参与位置。扩张既可能提高协调能力，也会增加翻译、反馈、恢复和权力问题。分歧本身不是失稳；只有可观察机制持续阻断承接、反馈或恢复，才能谈结构问题。

检查面S2 诊断卡
入口S2-E1：至少一类边界持续扩展并改变关系。S2-E2：生成核心之外出现可区分承接、成本、退出与未决位置。
退出S2-X1：重复负荷和压力形成连通约束、持续分割通道，可检 S3。S2-X2：扩展停止、回撤、跳跃、分裂、合并、接管、休眠或崩解。
可观察S2-O1 进入/退出和接口构成变化；S2-O2 角色与责任分化；S2-O3 反馈量、翻译成本、时滞和恢复需求变化；S2-O4 认同、异议、退出与安全被分别记录。
反例人数或用户数增长不一定改变结构；冲突公开也可能是表达安全改善，使旧问题终于可见。
证伪冻结统计口径后，增长不持续且不改变边界、角色、责任、接口或负荷，则撤回 S2。若所谓分化只来自中心单方标签，也应撤回。
尺度整体、中心、新承接者、退出者和外部化成本必须同时进入；观察范围扩大不增加对新成员的 J 权限。
证据升级扩展或通道造成结果差异须 G2/CAUSAL；跨尺度另经 D3/E5，闭合或转换主张另检 G4；锚点协调须 H1；表达、公开与权力的观测效应须 H4；历史留痕须 H5，载体传递按§4.5，历史条件残差另检 G3。
合同链接U01/U02/U03/U04/U06/U07/U08/U09/U11；H1/H2/H3/H4/H5；G1/G2/G3/G4；C1/C2/C3/C4/C5/C6/C7/C9/C10/C11/C12。

S2 不允许把不认同、退出或模糊参与者本身命名为负向主体，也不允许用“扩维需要”授权统一思想、限制退出或清退异议。

8.3.4　S3　连通约束下的发展原型 ​

S3 中，集体仍在运行或发展，但多个重复约束已经彼此连通：审批、资源、信任、责任、信息、平台或外部依赖形成互相放大的瓶颈，持续分割反馈、承接、恢复或成本回流。这里的关键不是“问题很多”，而是问题能否形成可复核的连通结构；也不是把某个人命名为壁垒。

检查面S3 诊断卡
入口S3-E1：至少两类约束相互强化并跨窗影响通道。S3-E2：运行仍继续，但末端承接、反馈、资源或恢复承担持续额外负荷。
退出S3-X1：关键关系、权限、资源或接口开始实际重构，可检 S4。S3-X2：转入回退、虚稳态、休眠、接管、强制重写、迁移或崩解。
可观察S3-O1 约束网络与瓶颈；S3-O2 输出仍有而损耗、返工、隐性劳动增加；S3-O3 修复反复启动却不写回；S3-O4 中心/边缘、指标/承接、名义/实际持续分裂。
反例高风险环境的保护性分层和冗余可能提高可靠性；主动降载重构也可能暂时放慢产出。必须检查限制是否阻断必要反馈，或提供错误隔离与替代路径。
证伪去除共同输入、测量偏差和短期峰值后，约束之间无连通关系，或承接末端的替代通道、写回和恢复持续有效，则 S3 不是主导。
尺度必须拆分中心、边缘、功能单元、承接末端和外部受影响位置，允许 parallel。弱信号消失不能当问题消失。
证据升级权力/中介遮蔽须 H4；指定通道与相互强化须 G2；历史形成的当前约束按§4.5，额外历史残差检 G3；跨尺度闭合失败须 G4。
合同链接U02/U03/U05/U06/U07/U08/U09/U10/U11；H1/H2/H3/H4/H5；G2/G3/G4；C2/C3/C4/C5/C6/C7/C9/C10/C11/C12。

S3 分类不能授权“打壁垒”、清洗、接管、强制改革或把过渡成本交给弱势位置。它只说明应继续区分约束网络与竞争解释。

8.3.5　S4　结构重构窗口原型 ​

S4 不是“改革已经正确”，而是关键结构确实处于重构窗口：旧关系、权限、资源通道、反馈写回或边界接口正在被拆解、替换或绕开，新旧安排并存，转换成本、重复劳动、知识迁移、短期产出下降和恢复需求上升。结果仍然开放，可能改善，也可能停滞、异化、强制重写或崩解。

检查面S4 诊断卡
入口S4-E1：至少一个关键字段实际改变，不只是改名或宣传。S4-E2：旧新安排并存，过渡成本可追踪，K 持续核对。
退出S4-X1：跨窗改善通道、反馈、承接与恢复且无隐藏外包，可检 S5。S4-X2：新结构不可用，转入休眠、回退、接管、强制重写、虚稳态或崩解。
可观察S4-O1 权限/资源/角色/责任/停止条件真实写回；S4-O2 双重系统和转换成本；S4-O3 缓冲、冗余、冷却、停止与回滚；S4-O4 多位置结果进入真实反馈。
反例大规模改名、换人或重画流程图可能是象征改革；拆旧、过载和产出下降也可能是破坏性清洗或资源抽离。
证伪实际关系、权限、资源和执行没有改变，则撤回 S4。不存在可用新结构且功能持续断裂时，也不能把过程包装为改善性重构。
尺度变更前基线、过渡、冷却、回滚和恢复窗均要覆盖；改革发起者、执行者、承接者与成本承担者分开。
证据升级重构导致改善/伤害须 G2/CAUSAL；对象或干预转换须 G4；失败尝试是否经当前载体影响未来按§4.5，额外历史残差另检 G3，不能用“隧穿”类比代替。
合同链接U03/U05/U06/U07/U09/U10/U11；H1/H2/H3/H4/H5；G2/G3/G4；C2/C3/C4/C5/C6/C7/C9/C10/C11/C12。

“过渡谷地”最多是待检的描述，不能为无限代价、不可逆伤害、取消申诉或牺牲低权力位置提供正当性。S4 不产生拆除、清洗或强制迁移的行动授权。

8.3.6　S5　高效协调与弹性扩展原型 ​

S5 描述在当前环境和时间窗内，资源、信息、反馈、责任、承接和恢复通道能够较低损耗地协同，局部扰动通常不能形成持续连通壁垒，边界扩展与收缩较有弹性。它仍可能被资源红利、成本外包、沉默、指标漂白或制度漏洞伪造。因此，高产出不是充分证据，长期存续也不是正当性的证明。

检查面S5 诊断卡
入口S5-E1：关键通道跨窗低损耗、可替代、可写回。S5-E2：扩展、存护与消解协同，且不靠封闭反馈或压制异议。
退出S5-X1：分布式承接、自我更新、恢复和新生成跨扰动成立，可检 S6。S5-X2：漏洞、异化、虚稳态、回退、功能转移、X0、接管或崩解使其不再主导。
可观察S5-O1 替代承接与通道真实可用；S5-O2 产出、反馈、恢复和维护同时保持；S5-O3 边界开放、保护与退出可执行，成本回流；S5-O4 漏洞审计能写回。
反例资源繁荣、选择性指标、投诉渠道失效、恐惧服从或把维护债推到未来，都能制造“成功”外观。
证伪纳入维护、恢复、退出和外部成本后效率优势消失，或中心低介入时局部故障迅速级联，则撤回 S5。
尺度管理层总量必须拆到维护者、低权力承接者、退出者和外部影响位置；覆盖高低负荷、扰动、恢复与维护窗。
证据升级高效协调成因与漏洞效应须 G2/H4；历史留痕、载体持续作用与额外残差分别按 H5、§4.5 与 G3；跨尺度复制须 D3/E5 映射与独立目标证据；闭合或转换主张另检 G4。
合同链接U01—U11；H1/H2/H3/H4/H5；G1/G2/G3/G4；C1—C12。

S5 不是“善”“成熟”或“可以输出模式”的标签。存续、增长和筛选不等于正当，也不能授权扩张、复制、接管或要求成员增加承担。

8.3.7　S6　自适应动态平衡原型 ​

S6 描述集体拥有分布式承接、有效反馈、恢复、更新和新生成能力。常规波动不会长期锁定方向，自治单元能局部自稳、横向协同并获得上级兜底，候补梯队、岗位记忆、授权和交接使后来者能真正进入并修改旧安排。它通过持续校准维持功能，不是消灭波动。

检查面S6 诊断卡
入口S6-E1：中心低介入时，多个位置仍能感知、纠错、恢复和写回。S6-E2：新承接者、规则与边界可持续更新，不依赖同一批不可替代个体。
退出S6-X1：恢复变慢、波动放大、写回失效、中心依赖或承接断裂，转入回退等路径。S6-X2：使命结束、功能转移、分裂、合并、范式替换或 X0 改变对象合同。
可观察S6-O1 扰动后的恢复与二次失稳；S6-O2 多中心协同与兜底；S6-O3 新承接者从训练到真实接管；S6-O4 反馈、审计、申诉与规则修订持续闭环。
反例强控制、弱信号消失、资源保护或中心隐性救火都能制造低波动；频繁换人和改组也可能只是人员耗材化。
证伪可比扰动下恢复持续变慢、局部故障级联、纠错依赖单点，或继任者得不到知识、权限和保护，则撤回 S6。
尺度需要跨扰动、恢复、继任和慢变量长窗；整体平均不能掩盖边缘伤害。冻结自治、横向协同、上级兜底与实际授权。
证据升级调节、反馈和多中心安排的效果须 G2/CAUSAL；学习、制度记忆和代际承接先核载体保留及实际接续；留痕检 H5，额外历史增量检 G3；跨尺度外推须 D3/E5 与独立目标证据；闭合或转换主张另检 G4。
合同链接U01—U11；H1/H2/H3/H4/H5；G1/G2/G3/G4；C1—C12。

S6 不是绝对终态、无冲突社会或历史终点。它可以回退、分裂、被接管、转移功能、进入 X0 或崩解；它也不能替任何对象取得对他者的决策权。

8.4　非线性路径库 ​

状态原型只有与路径库一起使用才不会退回阶段论。路径描述“状态配置或对象合同怎样变化”，不描述“更好的人怎样升级”。同一窗口可以有多个路径候选；证据不足时保持 unknown。

路径 ID含义关键区分
mixed同一对象、尺度和窗口中，两种以上原型的必要特征共同出现。若差异能稳定映射到独立子系统，应登记 parallel。
parallel不同地域、层级、功能或中心/边缘同时处于不同状态。不能压成“整体阶段”；各子系统分别留 K、证据和退出条件。
jump相邻观察窗从一个配置转到非相邻配置，中间原型无可辨识持续窗。先排除采样过稀和资料缺失；登记跳过的功能、代价和未知。
regression相对同一对象自身基线，一个或多个功能退化。分突发、渐进、临界跳变和级联；主动降载、X0 或功能转移不是回退。
split原对象分成两个以上具有不同 K 的候选对象。临时项目分组和模块化未必改变对象；每个新对象重新登记。
merge多个对象形成一个新对象或被一方吸收。联盟不必是合并；弱势方边界、记忆、退出与遗留责任必须单列。
dormancy可见活动降低，但记忆、关系、符号、能力或再激活条件仍保存。区分保护性撤离、耗竭停滞、资料消失与真实崩解。
takeover外部主体取得关键资源、权限或接口控制。外部支持或监管若保留真实自主与停止权，不必是接管。
functional_transfer核心功能转到另一对象，功能可连续而原身份、关系或记忆消失。外包单项任务不等于转移；功能连续不证明责任和记忆连续。
paradigm_replacement旧对象未被修复，而被不同 K、接口或规则的新对象绕过。同一对象内部升级或品牌改名不必是范式替换；遗留义务仍在。
trauma_built_development边界、身份、规则或承接方式在伤害、剥夺、失败或威胁下形成。创伤叙事不自动证明未来效应；保护与复制原始伤害须分别检验。
pseudo_steady表面指标稳定，实际承接耗竭、弱信号消失、反馈不写回或债务上升。建立表面/实际双账本，回到成本、恢复、停止权和末端反馈。
forced_rewrite高权力主体在缺少可纠错同意、退出和记忆保护时重写对象。与有授权、可撤回、可申诉的协商修订分开；检查不可逆身份抹除。
external_carrier_migration修复封闭时，把人员、能力、资源、关系、证据或记忆移到更安全承接系统。无接收能力、浪漫化离开或把伤害私有化，不构成安全迁移。
collapse原 K 不再成立，功能、承接、关系或边界非计划性断裂。与 X0、功能转移、保护性休眠和对象重组分开；资源释放不使伤害正当。

路径名也不产生价值或责任。例如，regression 不是道德堕落，split 不必然失败，merge 不必然进步，takeover 不是自动非法，external_carrier_migration 也不是要求个体自行逃离。路径只是让竞争解释进入记录；机制、正当性与行动仍需各自合同。

8.5　X0 有序退场与良性消亡 ​

X0 不是第八状态，也不是 S7；它不计作第八阶段。它是一条独立的人类集体生命周期路径：当继续维持原对象不再服务已登记锚点，核心功能可完成、终止或被更安全承接，并且人员、关系、资源、记忆、债务与申诉能被明确处理时，记录对象如何收束使命、转移功能、释放资源、保存记忆、结清责任并保留受限弱连接。

X0 不要求 S5 或 S6。S0 的临时倡议可以在发现问题已由他处承接时有序关闭；S2 的扩展项目可以在继续扩张只会制造伤害时收束；S3 的受困机构也可能在修复不可行而外部承接充分时进入退场。反过来，S6 也不能凭“高阶”标签宣布自己有资格解散。阶段能力、规范正当性和操作条件是三件事，任何状态编号都不能成为主动退场的资格前提。

机器合同用 origin_policy 把这条边界封闭为 any_registered_origin：不设最低状态前提，required_state_ids 为空，s5_or_s6_prerequisite 恒为 false。X0 的入口与完成条件不得引用 S0—S6 作为资格；编号只能说明出发位置，不能变成退场门槛。

8.5.1　X0 候选入口 ​

第一，锚点已完成、失去适用性、被更安全对象承接，或继续维持已主要服务于组织自身存续。这个判断必须能被独立复核，不能靠中心改写目标后自证完成。第二，人员、功能、资源、关系、记录、债务与不可替代价值已经形成清单，并存在可核验的接收方或保护安排。短期挫折、资金紧张、领导疲倦或责任逃避都可能制造相似表象，因此只满足叙述不能进入“良性完成”。

8.5.2　X0 完成条件 ​

完成面必须保存的内容失败信号
锚点与对象完成、终止或失效的独立验证；K 的结束时间与尚未结案项改写目标、删除失败项、中心单方宣布完成
核心功能每项标为完成、终止、转移或未决；接收方能力、权限、资源与回滚只有宣告，没有维护者或使用者连续性
人员与关系安全、基本权益、停止权、不被报复、照护与依赖关系承接把组织义务私有化为成员自行承担
资源对象、边界、顺序、时间和去向可追踪，防止高权力截留先内部瓜分，再把损失留给低权力位置
记忆与证据成功、失败、修复、岗位记忆均保存；访问、隐私、纠错和反报复明确只保留胜利史，删除或暴露弱势材料
债务与责任合同、劳动、数据、维护、环境、申诉和未来风险有持续责任主体对象一注销，责任、复核和维护同步消失
弱连接只提供咨询、经验与缓冲，边界和期限明确未经新授权复活原权力结构

X0 的结果至少应区分“候选”“进行中”“部分完成”“完成”和 unknown。只要受影响群体、遗留义务、接收能力、申诉或记忆安全仍为未知，就不能写“良性完成”。功能转移却没有记忆与责任连续，可能只是 functional_transfer；外部权力单方关闭并改写身份，可能是 takeover 或 forced_rewrite；无承接断裂则是 collapse，不能用“有序退场”美化。

X0 分类不产生解散、裁撤、资产转移、公开档案、放弃债务或代表成员同意的授权。它只能告诉我们：如果要判断退场是否有序，必须把哪些对象、义务、证据、保护和未知放到同一张账上。

8.6　调节、预警与承接如何进入状态判断 ​

状态不是靠静态截图判定。调节层要求观察目标、感知、比较、执行、反馈与时滞；预警层要求比较恢复变慢、波动放大、同类扰动后果加重和局部闪烁是否成簇；偿付层要求追踪谁承诺、谁承担、谁回流、谁被推迟到未来。S5 或 S6 的表面稳定若建立在账外劳动、沉默和未来债务上，应转为 pseudo_steady 候选。

同一序列或共同变化通道产生的多条线索，不因成簇就成为多份独立证据。相依线索仍可联合使用，其预警价值须在相符的动力、噪声、采样与观察窗口下，按固定目标、期限、实时基线和反向信号评价（Scheffer等，2009；参见D.31、§12.6）。

成簇不是预警的通用准入条件。单个业务信号也可能足以支持有限判断；缺少临界减速或第二条信号，既不证明安全，也不取消已有专业预测。联合规则需要联合分布或相应验证，其阳性预测值上升还不保证给定误报、漏报与行动成本下的总损失下降。

承接也不能只看“有没有接班人”。需要看候补梯队、影子岗位、岗位记忆、授权路径、交接窗口、合法性转译和保护条件是否实际存在。生成者退出干净而承接者无法进场，会形成权威真空；频繁换人而关键知识、权限仍锁在原中心，也不是自适应更新。这里使用 H2 区分承接载体、成本承担者、受益者、停止权与责任主体，使用 H3 判断反馈是否真的改写字段并执行，使用 H4 检查权力与观测通道，使用 H5 核留痕，按§4.5检验载体实际接续；如另主张当前表示之外的历史增量，再检 G3。

8.7　当前原型边界与排除项 ​

S0—S6 是一组可反驳、可缺失、可并行、可撤回的人类集体状态原型。每个候选都必须逐项检查入口、退出、观察、反例、证伪、尺度、证据、缺失和非授权边界；缺少这些条件时，只能保留为印象或未知。编号不表示从 0 到 6 的普遍演化路线，状态之间允许回退、并行、混合、跳跃、休眠、分裂、合并、接管、功能转移与崩解。

X0 是独立生命周期路径，不以 S5、S6 或任何最低状态为前提。阶段能力、规范正当性和退场操作条件必须分别判断；任何原型匹配都不能自行产生解散、推进、淘汰或强制转换授权。

缺少形式映射、量纲、可证伪预测和类比终止条件的物理隐喻不进入正式机制库。例如，“量子隧穿”不能解释人类集体为何跳跃转换；在本框架中将失败尝试登记为当前注册状态之外的历史条件增量，仍须由相应G3-instance支持（参见§4.5）。生物死亡与社会更新、爱与传承之间也不预设必然协作；代际承接只按角色、记忆、授权与交接接口记录。

七种原型不声称穷尽人类集体的全部状态。案例若持续落在原型之外，应先保留未解释残差，再依据独立材料检验是否需要新增、合并或拆分原型，而不是把案例硬塞进编号。

原型匹配、观察者间一致性、跨窗口稳定性及相对直接变量的使用增益是不同问题。清楚的卡片可以提高可复核性，却不证明分类已经可靠或比专业描述更有效。未取得实际比较时，不报告准确率、预测收益或阅读节省；若任务只需直接描述成员、通道和负荷，可以跳过原型。

8.8　与行动者状态和多圈层推演的边界 ​

S0-S6 描述的是有意图集体在指定对象合同下的候选状态，不描述个人人格、心理成熟度或道德等级。行动者的慢、中、快变量由第九部分管理；多个集体的平行、嵌套、重叠、桥接、竞争与临时关系由第十部分管理。一个人所属圈层被分类为 S2，不意味着该人的人格处于 S2；一个人表现出稳定能力，也不意味着其圈层处于 S5 或 S6。

多圈层推演可以让不同圈层同时处于不同原型，也可以让同一圈层在不同尺度轴上呈现混合状态。状态变化必须绑定事件、通道和时间窗；外层制度变化不能自动刷新内层关系，个体退出也不自动造成集体解体。若原型分类相对于直接变量没有增量价值，应跳过原型，使用更简单的联合状态。
