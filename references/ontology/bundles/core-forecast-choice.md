# Core bundle: forecast → finite choice

## 联读目的

把条件前瞻与规范/授权层隔离，保留基线、失败语义、不行动和行动上限。

## 必须一起读取

1. forecast-and-choice-interface.md：前瞻登记、基线、信号、选择桥和行动上限。
2. claim-roles-and-missing-states.md：N/O、证据身份和缺失状态。
3. interfaces-and-gates.md：四次转换、七闸、AI 边界。

## 原文锚点

V82-P2134—V82-P2329；V82-P2350—V82-P2565。

## 禁止孤立推断

- 没有结果前冻结的目标、期限、基线和校准计划，不使用确定前瞻语气。
- 前瞻不能自动生成价值、责任或授权。
- 方案集必须包含行动、延迟、试探、退出和不行动。
- 没有停止、回滚、申诉、补救或有效 J/O 引用，不发布可执行命令。

## 运行接口

先输出条件路径和失败语义，再比较方案的后果、信息价值、保护和不可逆风险；授权状态缺失时只输出要求清单。
