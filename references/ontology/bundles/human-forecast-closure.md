# 事件、三阶与条件前瞻连续联读包

## 触发

问题要求解释事件后果、预测未来、举例反例或三阶推演时，依次联读：

1. `event-and-dynamics.md`：冻结事件类型和联合快照。
2. `three-order-recursion.md`：按一阶直接效果、二阶行动/反馈、三阶制度化/锁定/逆转/溢出展开。
3. `conditional-forecast.md`：冻结目标、期限、基线、校准、早期/反向信号和失败状态。
4. `choice-authorization.md`：若问题问怎么办，补上方案集、no_action、规范冲突和授权。
5. `protection-and-intervention.md`：涉及人类或高影响动作时先过 PF-1—PF-10。

## 闭包检查

- 每阶是否有通道、条件、证据、竞争机制、反例、失败条件和停止理由？
- 二阶失败是否终止该路径而非凑三阶？
- 模拟、假设、计划、报告和观察是否没有静默升级？
- 预测是否优于复杂度匹配的简单基线，且保留未决/目标失效？
- 方案是否含维持现状、延迟、试探、退出/转移和明确不行动？
