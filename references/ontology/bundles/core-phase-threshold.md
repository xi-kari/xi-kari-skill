# Core bundle: load → phase → hysteresis

## 联读目的

把负荷、容量、恢复、相位、阈值、迟滞和路径依赖放在同一时间窗口内，拒绝用“阶段”或总量替代通道与历史条件。

## 必须一起读取

1. `operation-mechanisms.md`：负荷/容量/恢复和相位规则。
2. `universal-primitives.md`：U09—U11 的状态、载体和转变接口。
3. `scale-profiles-and-operators.md`：尺度、误差和适用域。

## 禁止孤立推断

瞬时缺口不自动是累积损伤；相位标签不是成熟度；迟滞/迟恢复必须有历史条件和可观察返回路径。

## 三阶接口

一阶记录同窗同型需求与余量差；二阶记录恢复、替代通道和策略改变；三阶只有慢变量、维护债、制度化或路径锁定/逆转有证据时运行。
