# Core bundle: feedback → learning → writeback

## 联读目的

区分返回信号、有效反馈、可保留学习和制度写回，避免一次受理或一次字段更新被夸大为长期修复。

## 必须一起读取

1. `operation-mechanisms.md`：反馈、学习、维护、负荷与恢复。
2. `event-and-recursive-inference.md`：事件顺序、状态更新和停止。
3. `claim-roles-and-missing-states.md`：证据身份、缺失状态和输出上限。

## 禁止孤立推断

到达、确认、归档或公开承诺不等于后续字段改变；一次改变不等于重复轮次中的历史条件增量；制度文本不等于执行写回。

## 三阶接口

一阶记录返回通道造成的状态差；二阶记录重复轮次、资源/行动集合和策略变化；三阶只有可重复写回、承接再生产或锁定/逆转证据成立时运行。
