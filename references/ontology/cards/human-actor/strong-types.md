# GC / GS / GE / CV / RS / IS / IM / IB

## 权威定义（v8.2）

强类型规定问题和证据分流，不宣称世界事实已经成立（`V82-P1196`-`V82-P1197`）。

- **GC 生成条件**：使生成可能或更可能的资源、技术、制度、关系、创伤、危机或机会窗口；条件没有意图（`V82-P1198`-`V82-P1199`）。
- **GS 生成主体**：能够理解并实施启动、转译或让渡行动的主体；主体须独立核验身份、能力、资源、行动和授权（`V82-P1200`-`V82-P1201`）。
- **GE 生成事件**：何种状态转移在何时形成；可以有主体，也可以无主体涌现（`V82-P1202`-`V82-P1203`）。
- **CV 承接载体**：实际执行、传导、维护、记录、照护或修复的人、岗位、程序、设施或系统；非人载体不承担道德/法律责任（`V82-P1204`-`V82-P1205`）。
- **RS 责任主体**：依据行为、决策、授权、监督、受益或补救基础承担特定责任者；知情、控制、范围、期间、申诉和补救必须分开（`V82-P1206`-`V82-P1207`）。
- **IS 失稳来源**：扰动首次进入或累积的位置；来源不等于恶意、机制或全部责任（`V82-P1208`-`V82-P1209`）。
- **IM 失稳机制**：扰动改变状态、边界、反馈、节奏或指向的因果路径；不能把人或群体直接命名为机制（`V82-P1210`-`V82-P1211`）。
- **IB 失稳行为**：实际观察到的行动、不作为或输出；行为不等于来源、机制、恶意或全部责任（`V82-P1212`-`V82-P1214`）。

## 允许推论

每个类型独立记录时间、尺度、证据、竞争解释和失败条件；同一案例可有多个类型，但一个类型的证据不能替另一个类型结案。

## 禁止跳跃

事件不证明主体，主体不等于全部责任；载体不等于责任；行为不等于来源或机制；条件不带意图。

## 反例与失败条件

- 只有结果、角色名称、可见度或异见者位置，不能补齐缺失类型。
- 未记录中介环节、时间顺序、桥接证据或可失败条件时，IM 只能保留候选。

## 判断与行动上限

强类型只限定“要检验什么”，不授权归责、处置、重分配或保护执行；行动必须另过 N/J/O。

## 申诉与回滚

错误分型应保留原记录、竞争来源和版本链；独立复核后才可撤销下游效力。

## 三阶推演接口

- 一阶：先标记条件、主体、事件、载体、责任、来源、机制、行为的类型差异。
- 二阶：只沿已声明的中介和承接通道更新状态，不能让类型标签成为因果路径。
- 三阶：跨期责任、制度化或跨圈层溢出必须新增证据与授权；无证据时停止。
