# 圈层关系变换@B557

## 原文层

来源：`V90-P00808`

尺度变换与圈层关系变换必须分开。尺度变换回答同一问题在 SP0 与 SP1 之间哪些变量保持、改变或丢失；圈层关系变换回答两个或多个候选圈层在同一或不同尺度上如何并列、包含、重叠、桥接、竞争或临时形成。一个关系变化可能伴随尺度变化，但不能用其中一个词替代另一个合同。

## 解释层

允许边界：尺度变换与圈层关系变换必须分开。尺度变换回答同一问题在 SP0 与 SP1 之间哪些变量保持、改变或丢失；圈层关系变换回答两个或多个候选圈层在同一或不同尺度上如何并列、包含、重叠、桥接、竞争或临时形成。一个关系变化可能伴随尺度变化，但不能用其中一个词替代另一个合同。

禁止边界：关系并列包含重叠桥接竞争临时与尺度转换分开，可伴随不互代。
