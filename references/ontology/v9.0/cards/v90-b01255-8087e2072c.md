# 解释—诊断—规范选择—干涉@V90-B01255

## 原文层

来源：`V90-P02557`

固定转换链是：解释 → 诊断 → 规范选择 → 干涉。

来源：`V90-P02558`

解释回答对象在什么边界、尺度、时间窗和 K 下如何运转。它输出描述性或解释性命题、证据状态、零模型、替代解释和描述性行动上限；不能输出责任裁判、价值优先级或行动命令。

来源：`V90-P02559`

诊断回答在当前证据下，什么问题最值得警惕、有哪些竞争解释、什么证据会推翻判断。它必须通过工具流，强判断还要保留反向条件、修复窗口、证据要求、申诉、反报复、补证、外部复核与撤回；诊断本身不产生授权。

来源：`V90-P02560`

规范选择回答谁在什么管辖、期限和价值前提下，可以从哪些方案中选择什么。形成供审议的评价、推荐和制度草案时，必须显式登记 N 前提与冲突、受影响位置、代价和不行动方案；进入实际采用时，运行 SEL-AGT 或 SEL-GOV，并通过 C12、O1-O3。法律有效、规范正当和 J 轴授权必须分别核验；多数、稳定、存续、效率与模型置信度都不能代替它们。

来源：`V90-P02561`

干涉只消费已经存在的选择与授权，不制造授权。现实行动必须绑定唯一 selected_action，并同时具备：通过的 C12 十项桥接记录、运行时显式 N 前提、O1-O4、完整保护底板、当前有效且经独立复核的 J 原子授权。J 元组必须同时覆盖同一决策主体、同一对象、同一动作、同一地域和完整期限；一条无关但有效的授权不能为拟议行动背书。

来源：`V90-P02562`

现实处置所需任何一环缺失，执行必须停止，相关行动要求只能停在不行动、补证、保全、继续审议或外部转介。把“我们已经解释清楚”“问题很严重”“目标是善意的”写成行动理由，都是越级。

## 解释层

允许边界：固定转换链是：解释 → 诊断 → 规范选择 → 干涉。

禁止边界：四种任务转换链，干涉只消费已有有效选择与权限，不从解释跳执行
