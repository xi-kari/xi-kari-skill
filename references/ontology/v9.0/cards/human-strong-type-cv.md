# human_strong_type:CV

## 原文层

来源：`V90-P00999`

7.2.4　CV（承接载体）

来源：`V90-P01000`

CV 回答“谁或什么实际执行、传导、维护、记录、照护或修复”。人员、岗位、程序、设施和技术系统都可以成为载体。证据来自任务日志、资源与容量流、成本、停止权和载体替换后的功能变化。CV ≠ RS：非人载体可以执行功能，但不承担道德或法律责任。

## 解释层

允许边界：仅在本项原文全部适用条件与分支条件内使用human_strong_type:CV；独立对象材料支持实例，定义和接口只确定意义。

禁止边界：CV不等于RS；条件不是主体，人不是机制。
