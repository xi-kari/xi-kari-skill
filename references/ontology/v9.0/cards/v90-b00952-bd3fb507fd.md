# 事件合同@V90-B00952

## 原文层

来源：`V90-P01771`

动态推演从有证据身份的联合状态出发，分析观察到、被报告、计划中、假设性或模拟事件之后的状态差、传导、反馈和分叉。实际发生的行动无论是否获得授权，都可能改变现实，均须按证据记录；事实发生、规范评价、法律或制度权限与本次执行许可分别判断。推演要说明哪些变化可以直接确认，哪些只是条件后果，哪些信号会支持或削弱相应路径。

来源：`V90-P01795`

事件包括观察到、被报告、计划中、假设性和模拟五类。类型必须进入记录：被报告的事件可以影响相信它的人，但不能自动当作已发生；计划可能改变预期，却不等于执行；假设事件用于条件分析；模拟事件只属于模型运行，不能回写现实事实。

来源：`V90-P01796`

事件记录至少包含：事件 ID、发生时间或窗口、观察时间、来源、受影响行动者、受影响圈层、通道、直接变化、证据状态、争议、竞争解释、可逆性、持续时间和后续观测。
