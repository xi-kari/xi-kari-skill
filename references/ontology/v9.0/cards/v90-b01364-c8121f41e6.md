# 应用模块的动态入口@V90-B01364

## 原文层

来源：`V90-P02666`

九个应用模块在需要动态分析时，都要额外声明主行动者、主圈层、相邻圈层、关系类型、M/Ψ 条件、五类时钟、事件、简单基线和结果回写。关系与家庭模块重点检查角色激活、无法退出和慢/中/快状态；组织与平台模块重点检查指标、桥接、传播与制度写回；公共治理、舆情和超大规模模块重点检查代表、低可见位置、跨层聚合损失与校准漂移；空间与应急模块重点检查物质通道、容量、阈值、时延和紧急授权。

来源：`V90-P02667`

任何模块都不能因“场景紧急”跳过事件事实地位，也不能因“模型只是建议”跳过隐私和受影响者保护。紧急情形允许的只是依外部紧急规则实施最小保护动作，并尽快恢复复核、申诉与回滚。模型生成的情景仍保持 hypothetical 或 simulated，不回写为 observed。

来源：`V90-P02668`

若应用只需要解释，不强制运行多圈层前瞻；若简单基线已经足够，保留更简单的模块记录；若前瞻没有登记或校准，输出停留在路径提示；若授权不完整，现实执行停止，保留行动需求和不产生执行权限的分析推荐、制度与计划草案。复杂流程的存在不能成为现实处置的压力。

## 解释层

允许边界：九个应用模块在需要动态分析时，都要额外声明主行动者、主圈层、相邻圈层、关系类型、M/Ψ 条件、五类时钟、事件、简单基线和结果回写。关系与家庭模块重点检查角色激活、无法退出和慢/中/快状态；组织与平台模块重点检查指标、桥接、传播与制度写回；公共治理、舆情和超大规模模块重点检查代表、低可见位置、跨层聚合损失与校准漂移；空间与应急模块重点检查物质通道、容量、阈值、时延和紧急授权。

禁止边界：仅需要动态才展开；保持事件类型、保护和用途资格，不强制前瞻
