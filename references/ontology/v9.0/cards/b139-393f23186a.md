# 原文规则@B139:支持资格要求把探索与确认、正向结果与零结论、冻结完成与事后偏离分开

## 原文层

来源：`V90-P00172`

支持资格要求把探索与确认、正向结果与零结论、冻结完成与事后偏离分开。只有按证据前冻结合同完成的确认或复制实例，才能提供正向支持；反驳实例只支持预注册的反驳或零模型判断。探索、草案、证据后偏离或未披露偏离只能生成候选、登记偏离或保持未决，不能支撑 C 推论。正向门未通过也不自动支持 N0；等价性或充分性、功效或灵敏度与容差没有预注册并通过时，结论只能是“未获正向支持”或“未决”。因而，“候选对象已登记”“正向 G 未获支持”“零模型获得支持”和“对象获得有限正向支持”必须保持为不同状态。

## 解释层

允许边界：支持资格要求把探索与确认、正向结果与零结论、冻结完成与事后偏离分开。只有按证据前冻结合同完成的确认或复制实例，才能提供正向支持；反驳实例只支持预注册的反驳或零模型判断。探索、草案、证据后偏离或未披露偏离只能生成候选、登记偏离或保持未决，不能支撑 C 推论。正向门未通过也不自动支持 N0；等价性或充分性、功效或灵敏度与容差没有预注册并通过时，结论只能是“未获正向支持”或“未决”。因而，“候选对象已登记”“正向 G 未获支持”“零模型获得支持”和“对象获得有限正向支持”必须保持为不同状态。

禁止边界：探索确认、正向零结论、冻结偏离分开；未过正向不等零支持。
