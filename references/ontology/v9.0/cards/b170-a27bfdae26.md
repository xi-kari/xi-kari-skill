# 原文规则@B170:给某人一个机会、某人实际接受干预、整个制度扩张，是不同的处理

## 原文层

来源：`V90-P00234`

给某人一个机会、某人实际接受干预、整个制度扩张，是不同的处理。总体平均效应、某类依从者的局部效应和每个个体的结果，也不是同一目标。识别假设受损时，只降低依赖它的结论；例如某种工具变量解释不再可靠，并不自动撤销可信随机分配对“获得机会”的影响。
