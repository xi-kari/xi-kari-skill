# 原文规则@B479:“九轴都要登记”不等于“九轴对一切对象都适用”

## 原文层

来源：`V90-P00687`

“九轴都要登记”不等于“九轴对一切对象都适用”。某轴整体确实不适用时，轴状态使用带理由的 not_applicable 对象，而不是删掉该轴。典型例子是没有行动主体和授权概念的自然过程：其 J 轴不适用，不等于“存在一个空授权集合”。源、目标两端经同一适用性判据均不适用时，该轴可在见证中记为 equal；仅一端不适用而另一端适用时，语义域已经改变，应记 incomparable；材料不足仍记 unknown。这样既保持九轴接口稳定，也不把人类制度语义强塞进广义世界。

## 解释层

允许边界：“九轴都要登记”不等于“九轴对一切对象都适用”。某轴整体确实不适用时，轴状态使用带理由的 not_applicable 对象，而不是删掉该轴。典型例子是没有行动主体和授权概念的自然过程：其 J 轴不适用，不等于“存在一个空授权集合”。源、目标两端经同一适用性判据均不适用时，该轴可在见证中记为 equal；仅一端不适用而另一端适用时，语义域已经改变，应记 incomparable；材料不足仍记 unknown。这样既保持九轴接口稳定，也不把人类制度语义强塞进广义世界。

禁止边界：九轴全登记不等全适用；两端同理由不适用可equal，一端不同incomparable，缺证unknown。
