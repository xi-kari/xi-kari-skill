# GOV-23

## 原文层

来源：`V90-P02801`

人格假设属于高误用风险材料。治理必须检查收集目的、授权、隐私等级、允许用途、跨圈层传播、当事人申诉、删除或纠正、模型版本和下游影响。临床诊断、人格本质裁决、歧视性筛选、未经授权的风险评分和以沉默作为证据均为禁止用途。

来源：`V90-P02802`

AI可以提出和比较变量候选与路径、核对材料身份、形成可反驳判断，并在公开的规范前提下给出建议；它不能以自身生成内容认证现实、诊断人格、替他者决定价值或签发权限。任何自动化系统若把candidate升级为observed、把simulated升级为现实事件、把前瞻结果升级为授权，必须阻断运行并留下审计记录。所谓人工复核只有在复核者能看到证据、反例和不确定性，具有相应能力、事前可用时间与可承受工作负荷，并拥有真实的拒绝、修改和暂停能力时才有效；这些信号必须能够及时到达执行器并改变动作，不能只在界面留下一次点击。

来源：`V90-P02803`

人工监督的效果应同时观察正确建议能否被适当采用、错误建议能否被拦下、没有提示的问题能否被发现，以及受影响者能否纠正结果。覆写越多不必越好，完全依从也不证明可靠。对速度超过逐次人工判断能力的窄动作，可以研究机器可检约束和最小权限，但目标选择、约束遗漏、异常接管与补救仍需明确责任，不能把系统性风险全部压给最后点击的人。

## 解释层

允许边界：人格假设属于高误用风险材料。治理必须检查收集目的、授权、隐私等级、允许用途、跨圈层传播、当事人申诉、删除或纠正、模型版本和下游影响。临床诊断、人格本质裁决、歧视性筛选、未经授权的风险评分和以沉默作为证据均为禁止用途。

禁止边界：人格隐私与自动化升级阻断，监督实际及时生效而非点击甩责
