# D0

## 原文层

来源：`V90-P00288`

3.1　D0 结构对象

来源：`V90-P00289`

命题：候选结构对象记为 S*=<B,X,R,I,T,SP,K>；零模型N0只在具体检验实例中冻结。

来源：`V90-P00290`

定义：D0只声明候选对象S*=<B,X,R,I,T,SP,K>：B为边界，X为状态变量，R为关系或转移约束，I为接口，T为时间窗，SP为尺度剖面，K为同一性判据。该声明使对象可被讨论，但不证明对象有效；N0属于具体G-instance的比较合同。

来源：`V90-P00291`

候选对象写作：

来源：`V90-P00292`

S*=<B,X,R,I,T,SP,K>

来源：`V90-P00293`

B 是边界，说明哪些状态与关系被纳入当前对象，哪些留在对象外。

来源：`V90-P00294`

X 是注册状态变量，而不是“对象全部真实状态”的代名词。

来源：`V90-P00295`

R 是关系或状态转移约束，须说明端点、方向、时间与适用条件。

来源：`V90-P00296`

I 是对象与外部发生输入、输出、过滤、传导或转换的接口。

来源：`V90-P00297`

T 是观察、预测、干预或反馈所使用的时间窗。

来源：`V90-P00298`

SP 是九轴尺度剖面，记录对象在聚合、空间、时间、组织、因果、观察分辨率、影响、网络拓扑和管辖授权上的位置。

来源：`V90-P00299`

K 是同一性判据，说明经过哪些变化后仍把它记为同一对象。

来源：`V90-P00300`

D0只声明本次分析的候选对象。N0不写入对象向量，而在具体比较主张中明确。对象字段完整不证明分组增益；命名、聚类、边界绘制和叙事连贯不能代替G1证据。已有记录、观察或其他可靠材料可以支持限定的人、机构、事件及关系事实，须注明来源和同一性条件；这些事实不因尚未检验G1而消失，也不自动证明分组有预测增益、统一主体或共同意愿。

## 解释层

允许边界：七字段完整可登记候选对象；可靠既有事实可另按领域依据成立。

禁止边界：由候选对象字段完整直接推得G1、价值或授权；给D0强加N0。
