# 规范选择@V90-B01179

## 原文层

来源：`V90-P02481`

这两类问题不能混成一类。一个解释可以非常可靠，却仍不足以产生处置权；一个目标可以得到广泛支持，却仍可能越过权利底线、把成本压给低权力位置，或超出决定者的管辖范围。规范选择因此不是诊断的附属段落，而是位于解释和现实行动之间的一层独立合同。

来源：`V90-P02483`

事实命题描述“是什么”，规范前提说明“什么值得追求、保护或禁止”。从“某结构稳定”“某方案效率更高”“某种类型被系统保留”“某风险在上升”，都不能直接推出“所以应当这样做”。这不是否认事实对选择的意义，而是限制它的角色：事实决定方案是否可能、后果可能是什么、风险和不确定性有多大；事实不自行选择价值，也不自行制造授权。

来源：`V90-P02560`

规范选择回答谁在什么管辖、期限和价值前提下，可以从哪些方案中选择什么。形成供审议的评价、推荐和制度草案时，必须显式登记 N 前提与冲突、受影响位置、代价和不行动方案；进入实际采用时，运行 SEL-AGT 或 SEL-GOV，并通过 C12、O1-O3。法律有效、规范正当和 J 轴授权必须分别核验；多数、稳定、存续、效率与模型置信度都不能代替它们。

## 解释层

允许边界：这两类问题不能混成一类。一个解释可以非常可靠，却仍不足以产生处置权；一个目标可以得到广泛支持，却仍可能越过权利底线、把成本压给低权力位置，或超出决定者的管辖范围。规范选择因此不是诊断的附属段落，而是位于解释和现实行动之间的一层独立合同。

禁止边界：事实、价值与权限独立；规范分析可推荐，现实采用另有强门
