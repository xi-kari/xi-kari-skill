# 原文规则@B450:任何根组合都不构成充分条件；附加条件、方法门、桥接证据或适用边界缺失时，只生成检查问题

## 原文层

来源：`V90-P00619`

任何根组合都不构成充分条件；附加条件、方法门、桥接证据或适用边界缺失时，只生成检查问题。“根模板并列不构成充分条件”是每条 C 合同的共同约束，而不是可被经验结果取消的措辞。即使 G1—G4 的某组实例全部通过，也不推出 S0—S6 阶段、方向、价值、责任、选择或授权；这些结论分别需要自己的分类、规范和程序合同。

允许边界：任何根组合都不构成充分条件；附加条件、方法门、桥接证据或适用边界缺失时，只生成检查问题。“根模板并列不构成充分条件”是每条 C 合同的共同约束，而不是可被经验结果取消的措辞。即使 G1—G4 的某组实例全部通过，也不推出 S0—S6 阶段、方向、价值、责任、选择或授权；这些结论分别需要自己的分类、规范和程序合同。
