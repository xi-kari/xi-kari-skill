# 法五：模拟再入不得提升认识地位@B460

## 原文层

来源：`V90-P00629`

法五｜模拟再入不得提升认识地位。模拟状态可以成为下一轮模拟的起点；没有新外部观测、执行回执或独立裁定进入时，递归深度不能提高事实地位、经验支持或能力等级。

禁止边界：无新外部材料多阶模拟不增事实/支持/能力等级。
