# 持续对话与深化

持续工作围绕同一个问题积累理解、材料、判断与成果。后续每轮既能作出明确回答，也能接住此前未尽之处；不把首篇长文当终点，不把后续当作替旧答案辩护。

## 辨认是在继续什么

根据共同问题、成果与依赖关系辨认任务，不按消息数或聊天窗口判断。

- 解释同一论点、增加案例、补充证据、提出反例、改变局部约束、比较新方案、修改或扩展成果，通常属于同任务接续。
- 从解释进入方案，从方案进入条款或实施安排，若仍服务同一问题，属于成果深化；新增用途所需的证据、规范、资源与权限须补足。
- 在同一问题中增加观察位置或比较案例，可以保留为分支；对象、目标与用途变化到需要一份独立分析成果时，重新界定新任务，完整学习与正序照常适用。
- 一条消息可以同时包含续问与新题，分别处理，不让新题抹掉旧成果。用户明确换话题时结束当前方法的自动接续。

不能为了避开全文学习把任何新问题叫作继续，也不能把一次反驳或追问当成新题，要求重读全书后才回答。边界确实会影响工作而又无法从上下文判断时才简短澄清，同时推进独立部分。

## 先辨新输入的性质

用户可能提供事实材料、来源主张、逻辑反例、价值偏好、新约束、构想、表达要求或对助手行为的纠正。分别处理：价值变化不等于旧事实被推翻，表达不清不等于机制错误，用户不同意不等于反例已经成立，旧结论被挑战也不等于需要保住它。

先定位争议命题和其真实前提，必要时回到原文或原材料。不得以“上一轮已论证”“用户之前同意”“多个模型都这样说”代替当前理由。假设仍是假设，反复讨论不会增加现实证据。

| 本轮要求 | 进入的实际工作 | 必须接到哪里 |
| --- | --- | --- |
| 澄清一句话或一个概念 | 定义、语境、原论证与具体实例 | 完整回答该疑问；发现语义错误时处理依赖它的结论 |
| 新材料或现实结果 | XK2—3判断来源、时点、范围与冲突 | 更新受影响的模型、机制、路径和裁决；未受影响内容保留 |
| 理论或逻辑反驳 | 回查原文与争议推论，寻找最小反例或必要前提 | 说明维持、限缩、修改或撤回及理由；同步依赖关系 |
| 新价值目标或约束 | XK0明确何者改变，检查对象和用途 | 重做相关可行性、后果、规范比较与取舍，不改写历史事实 |
| 新构想或替代方案 | 自身机制、资源、条件路径、代价和反方 | 与现有方案同口径比较，保留有理由的选择或未决 |
| 继续深入 | 找尚未充分解释的关系、材料冲突、替代机制或远期后果 | 实际补证和展开，形成新的局部判断；不只增加术语和字数 |
| 合成完整文章或制度 | 汇总全部有效分析、已采纳取舍与必要未决 | 完整母稿和关联图表，处理跨部分矛盾，不仅给补丁 |
| 纯表达或视觉调整 | 处理对应文本、布局与交互 | 含义完整保留；若数值或主张改变，转入实质修订 |

这是进入工作的提示，不是自动跳过其他阶段的表。实际发现更早的共同前提失效，就扩大分析范围；局部修订也须把新部分分析充分。

## 让每轮产生实质进展

可以澄清原先模糊的区别、补上机制、发现反例、限缩一个断言、恢复被误删的局部结论、提出更好的方案、深化尚未定案的分歧，或完成此前未交付的部分。无需每轮改变中心结论；有据地维持它并回答新反方也是进展。

若用户只说“再深入”，自主选择当前最值得展开、且有实际问题的方向。例如：一条未被识别的因果连接、两个机制给出相同表面结果、一个方案把成本转给了别人、一次成功为何没有持续、一个未被采用的反方能解释什么。说明这次为什么从这里入手，随后开展工作。不要只交一份未来研究清单。

保留思想探索的空间。提出新解释时说明它新增了什么、有什么支持、哪些条件未明；用户尚未选择的方案保持备选身份，不因后来多次提到就写成共识。也不能为了维持和谐把不同价值前提硬合并成一个结论。

当本轮问题已充分回答而进一步讨论需要新材料或新选择，可以给出当前判断和具体未决。持续能力不意味着自动在后台运行、无限扩题、主动发布、另开聊天或联系他人；这些行动按用户实际请求进行。

后续深化和打磨可以按[协作指南](collaboration.md)继续分工：续用已有完整学习基础的协作者，或让新智能体先完整学习再加入。按本轮争点分配机制、反方、替代方案或具体成果工作，主作者处理分歧、依赖与合稿；不将协作限定在首轮分析，也不把协作者数量当作质量依据。

## 修订沿意义依赖传播

按实际关系检查：事实或定义 → 局部模型与机制 → 路径与反方 → 方案、条款和中心判断 → 摘要、图表及阅读版。受影响的内容须一并调整；独立成立的判断继续保留。

例如，把“个人叙事是唯一来源”改成“在某些未被记录的经历中可能是唯一可得材料”，就要检查案例是否只证明重要性、停止权安排是否依赖原来的排他断言、方案理由是否仍成立，以及引言、结语和图中是否还保留旧说法。不能只在末尾加一句限定，也不能全文替换一个词就宣布修订完成。

若两项结论用的是不同证据，一项失效不自动撤掉另一项；若共享前提失效，则不能靠改名、移到图里或另开段落延续同一推论。新材料也可能确认旧判断，没有改判不等于没有认真回应。

保留先前尚未解决的重要异议及重新打开旧选项的条件。用户改变目标时，说明是选择前提改变，而不是伪造旧方案在旧目标下从未成立。

## 对话与完整成果

聚焦续问时，完整呈现本轮的新分析、争点和必要背景，不重复未变化的几万字。某个新机制确实需要长篇展开，就充分写出；“增量回答”不意味着简答。初次完整交付以及用户要求合稿、全文、定稿或导出时，仍交付完整累计成果。

修改产物服从已授权范围。用户说“只讨论，先不改稿”，保留主稿；只是询问位置或概念，也不擅自改文件。已有明确的持续打磨委托或本轮要求修改时，将成熟的修订合入当前完整稿。暂未采用的构想可保留备选稿或工作笔记，不能默默取代现行结论。

修改前读取实际文件，尊重用户在外部作出的编辑。重要分支或方向改变可保存一份旧稿以便比较；正式正文只呈现当前完整论证，不加入“本轮修改了什么”等制作说明。变化及其理由在对话中讲清，制作经过和必要的旧稿比较保留在工作材料中。对当前论证仍有实质作用的学术分歧、反方、未决及其来源须进入正文，不能因属于后续讨论而移出完整成果。

主文是当前内容基础。同步真正受影响的图表、案例材料、摘要和HTML阅读版；不把旧结论留在漂亮的图中，也不让配套材料因“正文优先”而继续保存错误依据。暂未同步的产物明确标识其实际状态，不将不同版本一起当最新成果交付。

## 持续工作的记忆

长任务用现有工作文档或一份简洁的`xikari-work-context.md`保存足以接续的内容：共同问题与成果目标、有效约束、理论来源与尚未读完位置、关键定义连接、重要事实与出处、当前主张和最强争议、已作选择与备选、现行文件位置、尚欠展开之处和下一项实质工作。

不要求固定字段、逐轮日志或文件数量。只保留有接续作用的信息；它是工作上下文，不是学习证书，不记录私有内部思维链，不把“已通过”当知识。不自动写入宿主全局记忆，不把一次对话中的候选想法改成理论定义或永久技能规则。

同一作者正常接续时复用已完成且仍可靠的学习与分析，补读未读及失去可靠理解的范围。新的主作者、已知更换模型或新会话接手时，若未亲自完整学习过当前理论，先完成自己的全文学习，再继承有来源的有效成果；无需把旧材料全部重搜或正序从零重演。无法获知模型身份本身，不是每轮重读的理由。

恢复后先读当前文件及有效上下文，再回答本轮请求。前任或自己过去的文本不是事实凭证；缺失的关键依据应回源恢复，无法恢复时说明具体限制，同时继续独立成立的部分。
