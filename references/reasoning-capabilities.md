# 分析能力

能力用于展开正序流程中的实际问题。不是每题都运行一组同构模板，也不能仅因为某个角度不改变首选就删除它；相关性的依据包括解释、证据、边界、代价、反例、责任和可能性。

| 能力 | 何时使用 | 应形成的实质内容 |
| --- | --- | --- |
| 问题重构 | 原问暗含未经证明的分类、二选一或目标替换 | 原问题的真实要求、隐藏前提、替代问题表示及它们的区别；仍回答原问 |
| 材料解释 | 叙述、统计、档案、体验或制度文本互相冲突 | 逐材料的产生位置、方法、意义、支持边界与冲突解释；不只罗列引用 |
| 溯因与竞争解释 | 结果可以由不同机制产生 | 起点、载体、通道、条件和可区分观察；比较而不把相关当因果 |
| 历史形成与过程追踪 | 当前状态反复出现或受过去影响 | 过去怎样形成当前载体、何者跨期保持、后来怎样被调用，区别额外历史增量 |
| 多尺度与多位置分析 | 平均改善、总体叙述与局部处境不一致 | 聚合、分布、权责、时钟和边界外成本；不可用整体利益抹掉具体差异 |
| 反事实与干预比较 | 需要判断改某条件是否改变结果 | 保持和改变哪些条件、真实可比基线、混杂和联合响应限制；明确模型假设 |
| 多阶前瞻 | 直接效果会改变后来选择或形成持久结构 | 条件路径、早期信号、迟滞、反馈、锁定、逆转及失败边界 |
| 形式与数量分析 | 争论涉及容量、约束、概率、误差或组合 | 用可复算模型、算例、区间或敏感性回答明确问题；单位和前提可查，不凭空量化 |
| 跨领域举一反三 | 两个问题可能共享关系结构 | 源域和目标域、桥接机制、保持差异、不能迁移之处与目标域证据；相似不是验证 |
| 规范与权力批判 | 事实被用来推出应当，或代价与决定权错位 | 公开价值前提、权利冲突、受影响位置、责任及替代制度理由 |
| 制度与机制设计 | 需要把诊断变成条款或运行安排 | 每项问题对应具体改法，权责、信息、资源、程序和纠错能够接续 |
| 建设性构想 | 既有选项不足以解决结构断点 | 新的组合或路线、为何可行、怎样失败、最小区分试验和推进路径 |
| 反思与框架批评 | 理论表示遮蔽材料或有重要残差 | 指出具体遗漏与后果、领域方法何以更充分、保留或提出修订候选的理由 |

## 如何做得深入

每个主要部分形成局部判断，并把依据展开为连贯论证。解释不能停在名词，要说明事件或状态经过谁、什么载体、什么通道，在何种条件与时间里改变了什么。比较不能只列优缺点，要使用同一问题和评价口径，说明差异为什么重要。

广度来自不同而相关的观察位置、机制、时间、边界和规范前提；深度来自把这些关系接起来并处理反例。不是多写几个领域名称，也不是沿一条假设无限延伸。

主动找“不舒服”的材料：成功案例里的失败、平均值背后的损失、帮助形成的新依赖、稳定中的强制、改革的承接成本、合理诉求之间的冲突。批判须具体，不把所有对象都归成权力压迫或技术不足，也不默认现状更合理。

需要研究或计算时实际取得材料、运行算例；不能用“可以研究”“可做模拟”替代当前已经有条件完成的工作。没有条件完成的部分保留问题和明确的检验办法，不为显得深入而编造结果。

使用形式命题或算例时，明确输入、表示、目标及其取值。相同总分不能恢复不同分项，只证明该已定义目标上的信息折叠；若真实质量、支持或生活结果尚未观察，不能把分项指标替换成这些现实目标，声称已给出它们的形式反例。模型内证明与现实解释分别承担依据。

## 协作

主作者在完整学习后分配边界清楚的资料、反例、计算或图形工作，向协作者提供共同问题与必要概念定义。对需要独立形成Xikari裁决的子任务，协作者也先完整学习原文。不同报告不能因数量多就当作独立证据或多数投票。

独立案例解释、机制分析、理论应用审查与方案设计都属于语义分析；不能将它们改称局部检查以绕过全读。按照[完整学习基础上的协作](collaboration.md)，学习不按章节分包替代，工作可在学完后按问题、机制和视角分包。

最终综合保留分歧及材料身份，解决跨部分冲突。主作者对总论证负责，不能把几个看似完整的子报告直接拼接，留下互不兼容的对象、时钟、数值、价值前提或建议。
