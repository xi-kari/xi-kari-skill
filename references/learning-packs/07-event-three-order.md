# 学习包 07：事件与三阶推演

## 路由

- 触发：问题询问变化、后果、未来、路径、连锁反应或长期演化。
- 必读：第十一至第十二部分；联读“事件—模拟—前瞻”和“制度化—锁定—逆转—跨圈层溢出”。
- 概念族：事件合同、模拟/前瞻分层、分支路径、递归推演、早期信号与失败状态。
- 联读包：core-event-path、human-three-order-closure。

## 建模与检索

- 局部世界模型字段：冻结联合状态、事件类型、证据截止、通道、直接变化、时钟、阈值、未知、竞争解释和回写窗口。
- 检索方向：当前基线、事件日期与发布日期、支持/反向案例、机制材料、受影响位置；模拟材料不能冒充观察。
- 三阶接口：一阶直接状态差；二阶行动、资源、策略和生成条件改变；三阶制度化、自我复制、锁定、逆转或跨圈层级联，逐节点记录十字段合同。

## 输出与降档

- 闸门：每一阶必须有真实通道和条件；二阶失败就终止该路径；模拟深度不提高事实证据等级。
- 静态事实、翻译、算术、代码和工具问题明确写“三阶推演不适用”。

权威层：v8.3 的三阶不是短期/中期/长期换名，而是由前一阶写回产生的连续状态转移。
