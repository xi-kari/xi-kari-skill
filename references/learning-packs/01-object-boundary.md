# 学习包 01：对象、边界与同一性

## 路由

- 触发：问题中的“这件事/这个人/这个系统”边界不清、对象可能变化或身份判据争议。
- 必读：v8.3 前言、第一至第三部分；再按问题读取第七至第十部分的人类/圈层接口。
- 概念族：D0—D3、U01—U06、对象准入、K、复杂度闸。
- 联读包：来源—材料—观察—主张—证据；对象—边界—K—同一性。

## 建模与检索

- 局部世界模型字段：候选对象、边界 B、状态 X、关系 R、接口 I、时间窗 T、尺度 SP、同一性 K、暂不纳入的背景和残差。
- 检索方向：对象的公开定义/制度边界、身份变化记录、可比的删除或替代基线；不要用名称或统计聚合代替 K。
- 三阶接口：一阶只更新对象字段；二阶检查边界/接口改变的行动集合和反馈；三阶只有 K 跨窗维持并有制度写回、锁定/逆转或跨圈层桥时展开。

## 输出与降档

- 输出：定义/解释分层、非等价锁、适用对象、至少一个边界反例和可观察身份信号。
- 停止：不能稳定说明对象和边界时，先澄清或条件化；K 失效时终止后续阶次，不把新名称升级为正式概念。
- 新变量只写 `XK-PROV-*`，并标 `source_undefined`，不得回写 v8.3 注册表。

权威层：所有定义回到 v8.3 原文，学习包只作路由。
