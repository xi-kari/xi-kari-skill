# 取材的组织

由主作者读取。问题需要现实材料，并且要查多份来源或打算把取材交给协作者时使用；材料就在手边的短问题直接引用，不走这里。取材的协作者按[取材者须知](../agents/collector.md)工作；宿主没有协作能力时，主作者自己照同一份须知取材，并如实保留没有独立上下文的边界。取回的材料有多强的支持仍按 [M1 材料与证据](../modules/evidence/MODULE.md)判断，登记与回查见[材料与证据](evidence-work.md)，追到原作的办法见[实际研究](research-work.md)。

## 取材跟着后面的工作走

只把一个题目交给协作者，取回的多半是这个题目的概述：有什么取什么，后面真正要用的对照、时间、口径和相反的材料往往不在里面。委托按后续工作要用什么来写。常用的方向如下，每个问题只取用得上的：

| 方向 | 取什么 | 后面用在哪里 |
| --- | --- | --- |
| 现状与口径 | 对象现在的规模、范围、组成和关键数量，各自的时点与口径 | M2 的状态变量与边界、M3 要解释的差异、M6 的基线时点 |
| 结构与运作 | 对象由哪些部分组成、彼此怎样连接、日常流程怎样走；要解释的那个环节具体怎样工作，出了问题怎样恢复 | M2 的边界、接口与关系，M3 的通道与机制链，M5 的传播 |
| 经过与事件 | 按时间排列的事件：发生了什么、何时、谁做的；已宣布而未发生的计划、日程和期限 | M5 的事件表与时钟、M3 的先后顺序、M6 的窗口 |
| 人与位置 | 谁参与、谁决定、谁承担、谁受影响；各位置自己的说法，尤其是不易发声或少有记录的位置 | M2 的行动者与关系、M3 与 M7 的受影响位置、M8 的位置互换 |
| 规则与地位 | 章程、合同、法规、授权、资格与流程的文本、版本、生效范围和有权修改者；实际执行的记录另取 | M3 对地位与效果的区分、M7 的权限与保护、R6 的起草 |
| 资源、容量与时间 | 资金、人手、产能、排期、办理时长、等待、阈值和恢复所需的时间 | M2 的负荷与连续时段、M5 的容量与时延、M7 的联合可行性 |
| 对照与基线 | 这件事以前怎样；条件相近的别处或别的时期结果怎样，包括结果不同的；同类事件的发生次数与总数 | M3 的简单基线与比较、M6 的历史频率、M8 的反例 |
| 已有的解释与领域知识 | 各方对原因或走向的说法；这个领域对这类现象已有的发现、方法与用词 | M3 的竞争解释、领域映射、M10 对候选是否已有先例的核对 |
| 相反的材料 | 与通行说法或与任何一种待比较解释相反的数据、案例、批评和失败记录；对立一方最有力的陈述 | M3 的反证、M8 的最强反方 |
| 方案与先例 | 实际可选的做法，包括等待、退出和不做；别处采用同类做法的记录与后果；谁有权决定、须经什么程序 | M7 的方案比较、R6 的起草 |

R2 至少取现状、结构与运作、经过、人与位置、对照、已有的解释和相反的材料；涉及制度的加规则与地位，涉及负荷、排队或产能的加资源与时间。R3 另需日程与资源约束。R4 再加同类事件的历史次数与总数、判定结果所依据的来源，并守住资料截止。R5、R6 在所依据的分析之上加人与位置、规则与地位、方案与先例。R7 的外部比较与 R8 的先例核对取所比较的理论、领域原作和已有说法，写明检索范围。R1 不取外部材料。某个方向与本题无关时不取，不为凑齐去取。按上面的配置该取而决定不取的方向，在问题合同里各用一句写明理由；后面发现它限制了判断，回头补取。

## 分两轮

**第一轮铺底。** 原问、对象、时间范围、资料截止和输入模式一经明确就可以派出，与主作者学习原文同时进行。先取各条路线都用得上的方向：现状、结构与运作、经过、人与位置、对照、已有的解释、相反的材料；路线确定后再补它专有的方向。这些方向都不依赖理论判断：委托里只写要取什么，不写主作者对答案的猜测，也不写希望找到哪一边的材料。

**第二轮定向。** 机制比较写出各解释成立时应看到什么之后，把能区分它们的那几项观察逐项交给协作者；反方提出的具体缺口也在这一轮补。委托写清要找的观察是什么、可能留在哪类记录里，把几种解释并列写出，不标明主作者倾向哪一种。

补到什么时候为止，看取回来会改变什么：说不出它会改变哪条判断、哪个把握程度或哪项保护安排的，不再补，记为未取。有区分价值又取得到的，不以篇幅或轮次为由省去。

## 委托怎样写

一份委托交一个方向或几个相近的方向，写明下列各项；已有的问题合同直接引用：

```markdown
# 取材委托
共同原问（用户原话）：
对象与范围（谁、哪里、哪段时间）：
本份的方向与要取的东西：
已有的材料（不必重取）：
资料截止与输入模式（公开取材，或只用给定材料及其位置）：
不取什么（保护边界、与本题无关的个人信息）：
须读：<技能根目录>/agents/collector.md 及其头部列出的原文小节
存放位置与编号前缀：<任务目录>/取材/；材料编号以 <本份委托的前缀> 开头
回报：按须知“回报”一节，详细内容写文件，消息只放索引
```

委托里可以点名已知的来源作线索，写明不限于这些；只写来源的名称，不写它得出了什么结论。一个方向涉及的领域太多时，由主作者拆成几份委托；协作者不再往下委托。

协作者读不到技能目录时，把须知全文放进委托；不能写文件时，回报全文放在消息里，并写明原件没有保存。同一任务的协作者用同一个存放位置：各自的记录和材料编号以前缀区分，原件目录共用，后来的人直接用已有的原件，几个人标的位置才对得上。

按互相独立的方向或来源领域分派，一位协作者接一到三个相近的方向；“相反的材料”尽量交给没有看过其他取材结果的一位。受影响的位置较多时可以按位置分派，每个位置找出自该位置的材料：当事人自己的陈述、对该群体的调查、代表组织的文件。问题小、来源集中的，由一位协作者或主作者自己完成；协作者的数量不是质量的依据。

只取材和核对的协作者不必读全书。交出去的工作一旦要解释原因、推演、比较方案或作实质反方，就不再是取材，接手的作者按[协作](collaboration.md)的阅读责任亲读原文。

## 接收

取回的是材料，还不是证据基础。主作者：

1. **先看范围和缺口，再看要点。** 每个方向查了哪里、没查到什么、哪些只读到摘要或经工具转述；对照所选的方向查漏。
2. **按上游合并。** 不同协作者带回的转载、同一批数据的再分析、预印本与正式版并成一条；材料的份数不是证据的分量。
3. **分清冲突的性质。** 对象、时期或口径不同造成的差别，与同一对象上的真冲突分开；真冲突留到机制比较里处理，不在接收时按多数裁掉。几位协作者对同一事实说法不一的，回原件定；没有原件的并列保留，记为缺口。
4. **把事件并成一条时间线。** 同一件事合并，类型保持原样；成文时“被报告”“计划中”不写成已经发生。
5. **承重的回原件。** 中心判断直接依赖的数字、原话和事件，主作者打开协作者存下的原件，在所标位置亲自看一遍：不只看数字和句子在不在，还看口径和版本是不是稿子里说的那个，引文带没带原有的限定，数量词和范围有没有比来源强；其余承重的由主作者或一位没有参与取材的协作者核对；再其余的抽查。核不了的照实标明，依赖它的结论相应降低。
6. **补采。** 缺口里会改变判断的，写成新的委托；成稿后的审查或核对指出这样的缺口时也一样。确因宿主的时间或用量限制补不了的，照实写明是这个原因，依赖它的判断相应降低。

协作者没有回报、中途停止或交回的东西不合须知时，把委托缩小后重派一次，或由主作者自己取这一项；仍然取不到的记为缺口，不凭印象补上。协作者写明没有读完须知或原文小节的，它标的材料身份和事件类型只当线索，由主作者对照原件自己定。

协作者的概括和“提示”只是线索：不当作理论判断，不直接写进成稿，也不代替主作者读承重的材料。来源多或要跨轮接续时，把存下的原件登记进材料目录。

## 成稿前核对引用

引用较多、要对外使用或用户要求可追溯的成果，成稿后把引用清单连同原件位置交给一位没有参与取材的协作者，按须知“受托核对引用时”一节逐条核对。主作者据结果改稿：不一致的改正，部分一致的改到与来源相符，无法核对的照实标明或撤下依赖它的说法。引用不多时主作者自己逐条回原件。没有独立上下文的核对者时照实写明。核对回答的是引用准不准，不代替[独立反方](../agents/reviewer.md)对论证的审查。

## 在答案里交代

取材交给过协作者或查过多份来源的，在方法附注的“取材”和“核对与审查”两项里用几句写明（各项顺序见[完整答案与成果](complete-answer.md)）：取了哪些方向、查到哪一天、材料由谁取得和读到的程度、没有取到什么，以及引用核对了多少条、结果怎样。重大缺口同时写进它所限制的结论处。

## 接续与到期

同一任务接续时，新的委托带上上次的资料截止和已有材料的清单，只取其后的新事件、更正和上次留下的缺口。新材料进入新的一版分析，不改写旧的起点；来源或数据被更正时按[持续对话](continuation.md)的更正步骤办。已登记的前瞻到期取结果时，只按登记时写定的判定来源和规则取，取不到记为未决。
