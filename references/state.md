# 状态与恢复

## 默认不审计运行

普通使用不创建阶段工件、读取回执、全源覆盖表、候选总账、验证报告或签名终态。不把“证明自己按技能做过”当作任务。宿主模型负责理解并使用技能，交付质量通过实际答案和结果判断。

不生成学习证明，不代表省略学习。每个新任务仍先完整学习理论全文并沿XK0—XK11完成正序工作。全文学习的概念笔记与断点只用于接续，不作为跨任务免读凭证。

需要持久记录时，只保存能防止丢失工作或改变结论的内容：当前目标与终点、已知事实和出处、已经形成的取舍、正在编辑的文件、未完成工作、已执行但结果未知的操作。用现有项目文件或任务目录即可，不要求固定格式与固定文件数量。

持续研究还须保留有接续作用的当前主张及范围、最强争议、备选方案、用户已作选择、尚未采纳的构想、曾排除解释的理由及重新打开它的条件。旧回答是工作材料，不是其内容成立的证据；讨论次数与用户认可不增加事实支持。可使用一份简洁的`xikari-work-context.md`，避免逐轮制作记录堆积。详见[持续对话与深化](continuation.md)。

前瞻保留事前判断，研究保留需要引用的证据，长任务保留检查点，外部修改保留必要的请求身份与结果。这些记录各有用途，不互相替代；不为了统一仪式补造空文件。

可选的[材料目录](evidence-work.md)、[稿件快照](manuscript-work.md)与[案例资料库](case-library.md)分别服务来源定位、编辑接续与用户选择的经验积累。它们不自动创建，不以记录存在证明内容正确，也不能混成全局学习账本。

## 恢复与变化

恢复时从真实文件与最近有效工作内容继续，先辨明当前稿、备选稿、有效约束和实际争点；文件已被用户修改时，不用旧内存覆盖新内容。理论文本改变时重新全文学习；同一作者继续同一任务时补完未读部分，重读已经理解不可靠的范围，不因轮次或正常压缩自动从头开始。不能只凭“已全读”标记继续。新的独立分析任务重新全读；新主作者或已知更换模型接手时，未亲读者先全文学习，再继承可用成果，不重演全部旧工作。用户修正任务时保留仍有效部分，按新目标继续。

事实、模型假设、模拟状态、形式结果、工具回执分别保存其身份。需要结构化表示时，证据支持程度、缺失原因、工件状态和动作结果分字段，不共用一个status。`unknown`不等于`false`，`withheld_for_protection`不等于不存在，`not_run`不等于失败。

推理依赖与程序依赖、专化和应用关系分开。多个真正独立的支持可以保留替代路线；共同前提失效时则影响全部依赖结论。新证据不能覆盖掉原先预测的失败，新的正常输出不能抹去现实损失。

## Windows工作环境

使用宿主提供的文件与工具能力。PowerShell处理路径时优先LiteralPath，含空格或中文的路径正确引用。Python章节读取器只用标准库；它是可选便利工具，不是模型后端，也不启动其他模型进程。

本技能不配置Linux环境、容器或跨平台安装流程。没有命令行能力时仍可读取原文并完成分析，不以工具缺失取消本来可完成的判断。
