# 有限领域适配包

这些包帮助辨认具体任务中的专业词义、动作、对象、证据和结果终点。每包只覆盖明确的小任务；有来源的领域知识与待检验的理论对应分别使用。文件中的字段、示例和对应表是工作接口，不是专业标准原文，也不构成新的理论定义。

## 选择入口

| 包 | 可以直接处理的任务 | 不能据此宣布覆盖的范围 |
|---|---|---|
| [组织与工作](organization-work.md) | 使用 Scrum 2020 语义的团队，核对职责、完成条件和共享资源安排 | 一般劳动关系、法律授权、全部项目管理或所有组织文化 |
| [教育与学习](education-learning.md) | 短课程成果说明：参与、课程完成、测评、迁移、微证书与认可分别陈述 | 对个人作全面能力诊断，认定职业执照，证明课程因果效果 |
| [技术系统与维护](technical-maintenance.md) | HTTP 服务的观测、任务结果、服务目标和故障恢复核对 | 任意协议、所有云产品、完整安全审计或实际变更许可 |

优先保留用户所在机构、课程或系统的实际用法。只有采用相应规则的任务才套用其词义；同名词在别处可以不同。普通问答只读相关条目，不强制填写整包字段。事实已经有充分领域依据而未申请正式理论实例资格时，仍可直接回答该领域问题。

## 可查询的对应数据

文档与数据包配对使用：[组织与工作 JSON](../../assets/domains/organization-work.json)、[教育与学习 JSON](../../assets/domains/education-learning.json)、[技术系统与维护 JSON](../../assets/domains/technical-maintenance.json)。它们分别包含9、9、10项词义或关系记录，各有一段已写成的领域说明。真实组织、学习者和服务状态均未据这些通用来源判定；`factual` 保持 `unknown`，`formal` 保持 `not_claimed`。专业词义有依据时可保留 `supported`，理论的局部对应仍可为 `partial`，三者不互相代证。

在技能根目录调用；输出写到安装目录外的任务位置：

```bash
python scripts/domain_mapping.py --mapping assets/domains/organization-work.json lookup --term "委派"
python scripts/domain_mapping.py --mapping assets/domains/education-learning.json impact --changed edu-src-transfer
python scripts/domain_mapping.py --mapping assets/domains/technical-maintenance.json render --output /任务目录/技术服务说明.md
```

最后一条命令中的 `/任务目录/技术服务说明.md` 应换成当前环境的实际外部路径。查询仅匹配已登记词形和语境；未命中时不猜义项。变更追踪只列已登记依赖的复核范围，不自动宣告结论错误。渲染使用包内现成文字，不生成未取得的现实材料；来源复核或任务实例化后需更新对应数据与说明。

## 身份与来源怎么读

各包使用以下记录标签；它们是工程标记，不声称来自原文的新分类：

- **来源词义**：所列版本或章节直接规定、解释的含义。它不证明某个现实组织已采用该规则。
- **任务实例**：用户材料证明具体人、岗位、课程、请求或系统符合该用法；尚无材料时保留待核。
- **工作字段／方法**：为了当前问题提出的数据字典、计算或检查步骤。来源没有规定的内容不得转称为来源要求。
- **部分对应／观察接口**：连接原文中的相关区别；不把词面相似当成机制、因果、规范正当或正式实例证明。
- **不对应／不适用／未知**：分别说明词义不同、当前问题不涉及、资料尚不足；不互相替换。

按 §3.4.1 作正式转义时，另列目标侧独立复核状态。下列包不内置“映射已获验证”的结论；尚无该复核的对应保持待检验身份。组织包的定位依据为 §7.3、§7.6、§12.10 与附录 D.16；教育包为 §6.3 与附录 D.25；技术包为 §6.5、§6.13 与附录 D.28。专业资料支持各自的领域用法，不因与这些位置相连就成为理论的独立经验支持。

## 使用过程

1. 固定用户要得到的结果、资料截止和适用版本。先判断是解释术语、核对材料、比较方案，还是要执行真实动作。
2. 只提取会改变答案的词义与关系。记录“谁对什么作何动作、在何时、凭什么材料”；已有词汇不能准确表达时保留专业原词。
3. 应用包内专业方法，核对字段单位、分母、观察窗口和支持条件。缺失保留其原因；未记录不等于未发生。
4. 输出直接使用领域语言，说明已支持到哪个终点、哪些对应尚待检验。方法标签可放附注，不淹没主体结果。
5. 新材料若改变词义、资格、分母、版本或任务终点，从受影响处修订。原来仍有依据的结果继续保留。

分析和方案输出本身不授权发布、排程、授证、重启、切流或修改真实系统。任务已有相应授权时按其范围继续，不因使用本包再造一轮许可要求。

## 来源维护与缩小范围

各包列出实际核过的正文位置、版本和查阅日期。在线文档未公开固定版本时如实标记，使用前只复核影响当前判断的段落，不声称锁定了未知版本。书或指南中的参考文献不自动算作已核原作。

出现以下情况时复核对应：专业来源发布修订；用户机构采用另一套规则；指标或日志定义改变；同词出现新的义项；先前示例不能解释新材料；理论所绑定文本变化。新来源不可访问时标记“本次未核”，保留仍有依据的范围，不用搜索摘要补成已核正文。

如果映射迫使删除领域关键区别、把测量字段当成实际能力或把技术通路当成授权，应缩小或停用该对应。完整字段不证明任务完成；是否值得保留，以任务结果和额外负担判断。
