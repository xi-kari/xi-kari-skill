# 教育与学习：短课程成果与迁移

配套[可查询数据](../../assets/domains/education-learning.json)包含9项记录与一段有来源的领域说明；调用方法见[领域包入口](README.md)。以下教学例不作为数据包的现实实例。

## 适用任务

用于阅读短课程记录或起草有依据的成果说明：分清进入机会、参与、课程完成、测评表现、在新任务中的迁移、证书发放和接收机构认可。涉及欧洲微证书时使用明确列出的2022年建议词义；其他地区或课程优先使用其实际规则，不能只因证书名称相似就套用。

本包不作个人心理或全面能力诊断，不认定职业执照，不证明课程造成了观察到的变化。课程结束时的分数、后续学习速度和就业结果是不同任务终点，应分别取证。

E1 中，微证书记录经明确标准评估的学习成果；它分别列出参与形式、评估类型和授予信息。描述字段齐全本身不表示官方认可；组合微证书也不自动取得学位或资格。[E1](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32022H0627(02))

E2 将迁移用于已学内容在新情境中的运用，指出记忆测试相近的学习经历可能有不同迁移表现；一次即时无提示测试也未必覆盖动态学习与有提示表现。[E2](https://www.nationalacademies.org/read/9853/chapter/6)

## 词义、角色和任务关系

以下工作区分不替课程制定统一达标规则。实际规则未知时保留未知。

| 词语或结果 | 需识别的动作与角色 | 支持该判断的任务材料 | 不能代证的结果 |
|---|---|---|---|
| 进入机会 | 学习者符合条件、获得席位并能实际参加 | 入课条件、通知、费用／时间／无障碍支持等与任务相关的材料 | 已报名即实际能参与 |
| 参与／出勤 | 学习者按当地规则完成某种参与 | 同步出席、异步任务或其他预定口径及记录 | 登录、停留时间或下载即学习达标 |
| 完成／结业 | 课程提供者依据本课程规则判定完成 | 完成规则版本、适用对象和核验结果 | 任意“结业”必含有效测评；课程完成即职业资格 |
| 测评表现 | 评估者按任务、评分标准和支持条件产生结果 | 测评内容、评分规则、原始作答或可核结果、时间与辅助条件 | 单次分数即稳定能力，或变化必由课程造成 |
| 迁移 | 学习者在明示新任务／情境中运用或继续学习 | 原任务与新任务差异、观察时点、提示和工具条件、结果 | 原题熟练即所有情境可迁移；有提示成功即无提示成功 |
| 微证书／证书 | 授予机构作出授予并提供可核记录 | 适用定义、授予者、日期、所载成果及核验方式 | 技术上可验真即学业评价正确或被任何机构认可 |
| 认可／资格 | 接收机构或适用资格主体按其规则作决定 | 规则、用途、有效范围及实际决定 | 发证方称可用即接收方必须接受 |

课程提供者、教师、评估者、授予机构和接收机构可能重合，也可能不同。把它们列出来是为了定位具体动作，不默认存在五个独立部门；同一人承担数项角色时仍保留不同判断依据。

## 字段、单位、分母与时间

下表是按问题选用的工作字段；它不是对 E1 记录标准的完整复制，不能用于声称已经符合该标准。

| 字段 | 用法与口径 |
|---|---|
| `course_id`、`course_version`、`cohort_rule` | 课程及固定人群；进入、退出、重复报名和旁听者处理规则 |
| `learner_code`、`participation_rule`、`participation_evidence` | 用必要的去标识代码关联记录；当地参与口径与直接材料 |
| `completion_rule`、`completed_at` | 完成条件和实际判定时间；未拿到规则不由课程标题猜测 |
| `learning_outcome`、`assessment_task`、`rubric_version` | 声称学到什么、实际测了什么、如何评分；一项成绩只支持其覆盖范围 |
| `score`、`score_scale`、`attempt`、`assessed_at` | 分值范围、首次或重试、时间；不同量表不能直接作差 |
| `support_conditions` | 提示、协作、工具、延时和合理支持分别记录；不要合成未经定义的“独立度”分数 |
| `transfer_task`、`context_difference`、`followup_interval` | 新任务改了什么、何时观察、允许何种学习与支持；与原题复测分开 |
| `assessed_n`、`meeting_criterion_n`、`eligible_cohort_n` | 有效测评者、其中达标者、原定适用人群分别保留；报告率时明示分母 |
| `missing_n`、`missing_reason` | 未参加测评、记录缺失、不适用和保护性不披露分别记录；不自动算零分 |
| `issuer`、`issued_at`、`recognising_body`、`recognition_scope` | 发放与认可分别记录；学习发生、测评、发证与认可时间不能相互替代 |

课时或 ECTS 等工作量不直接兑换为已掌握的技能量。若某课程只规定观看与提交即可完成，可以如实报告该完成事实，同时限定其证据范围。

## 专业方法与处理步骤

先确定成果说明要回答哪一问题，再对齐课程规则与对应证据。检查测评是否覆盖所述目标、评分口径是否一致、辅助条件和重试规则是否改变；不足处提出需要专业评估者核对的具体问题，不凭一个总分认证测量有效。

需要讨论迁移时，明确新任务与学习任务的关系，分别安排即时表现、后续表现或继续学习的观察；是否适用有提示测试应按任务目标决定。记录提示和支持，不为证明“真正能力”擅自撤除必要支持。有支持的完成、无提示完成及后续迁移分别回答，前者不因后者未成立而被抹去。

对课程前后变化，只描述相同口径下观察到的变化；若要判断课程效果，需另做适当研究设计，处理选入、流失、重复练习和同时发生的其他变化。对外报告优先分列人数和终点，不把参与、分数、证书和就业混成一个成功率。

## 与理论的有限对应

| 对应身份 | 可借用的区别 | 对应边界 |
|---|---|---|
| 部分对应，待检验 | §6.3：支持下完成任务、撤除支持后的独立迁移与后续生活结果分别判断；必要支持可以是任务的组成部分 | 领域中的某项测评不是整个学习过程；教学辅助也不能自动称为能力缺陷；迁移主张需相称的独立任务或样本外评价 |
| 观察接口，待检验 | 用测评任务和后续任务分别观察所问结果；比例只回答所述标准、分母与时点 | 记录字段不自行证明测量效度、机制或课程因果效果；累计、在办、名额与实际学习人数不混用 |
| 领域定位 | 附录 D.25：教育目的、可进入的学习、知识技能、测验解释、资格授予与后续机会分开；通知、激活、到会、出勤与知识增长也不同。正式表述转义按 §3.4.1 另核 | 课程既有事实不因尚未形成正式理论实例而被取消；已结业不能用来承诺就业，未结业也不自动取消局部学习 |

E1 的 micro-credential 不是理论中的“学习”同义词；它是一类有特定来源定义的成果记录。E2 中的迁移也不能无条件替换为“无支持独立完成”。

## 输出例与容易混淆的反例

**教学设定，非实际课程结果。** 同一固定班级有40人；25人有有效末测记录，其中20人达到预先标准。另有30人满足课程声明的参与条件，但未提供课程结业规则、迁移任务、授证或认可决定。

可输出：“本次有效测评者中的达标比例为20/25，即80%；固定班级中有记录支持达到该标准的比例为20/40，即50%，其余人员不能一律判定未学会。30人满足参与口径是另一项结果。现有材料不足以确定结业、迁移或资格认可；若要核对课程完成，先取得完成规则即可，不必收集全部个人经历。”

反例：某人有辅助工具时能稳定完成目标任务，但无辅助新任务尚未完成，不能据此否定前一结果。另一个人取得真实证书，但接收机构尚未作认可决定；证书真伪和认可状态需分别回答。课程 A 的“完成”只要求参与，课程 B 的“完成”要求通过测评，同词不能直接合并比较。

## 变更复核与退出

课程目标、测评题、评分规则、辅助条件、样本分母、观察时间、授予或接收机构规则变化时复核相关结论。E1 被修订或适用地区不同，先重新定位其定义与适用性；本包引用的2022年建议不替代当前具体法律规则。需要高风险资格决定、专业测量或个体诊断时交给相应专业方法和有权主体，仍可交付已核实的课程事实。
