# 经验、意义与作品阐释

用户想理解一段经历、文学作品、公共叙事或文化实践时调用，承接 R2 的解释任务，以 M9 交付完整论述。理解可以是终点；不要求先完成机制诊断，也不强制建立无关的结构域、人格或状态表。只问一个词句时简明解释即可。返回[成果模式索引](../output-modes.md)。

## 输入与实际工作

取得完整相关文本或经验材料、叙述者与语境、用户关心的细节以及材料可公开范围。材料不足时交付已有片段支持的读法并指出范围，不补写未读情节。个人经验只收集与问题相关且允许使用的内容。

1. 先说明材料直接表达了什么、怎样表达。细读措辞、重复、停顿、场景、声音和视角；分开作者、叙述者、人物、转述者与现实读者。
2. 追踪语境和经验中的意义条件，按需要接入历史、社会、身体或资源材料。物质困难不能自动变成态度问题，意义也不能被资源总量代替。
3. 形成有中心的解释，展示细节怎样支持它。相邻而可信的读法逐项比较；没有具体替代读法时不为凑数编造。开放性不等于所有读法同样有据。
4. 对文本读法、当事人自述、外部事实和可能机制分别说明依据。某种叙述带来安慰或被本人认同，不因此认证其中的历史事实；人物说法不自动是作者裁定。
5. 写出完整解释长文或适合篇幅的短评，回应原问。若用户只求理解，不强行追加治疗、效率改进或行动清单；需要其他任务时再接续。

## 交付与接续

正文应有明确读法、细节分析、必要语境、竞争解释与有限结论，不能由主题标签和概念对照表替代。引用应能返回真实材料；未知背景集中说明，但不使全部解读停摆。

[领域适配](../../modules/domain-mapping/MODULE.md)可帮助辨认语词和文化语境，保留无法对齐的表达；[研究入口](../../modules/research/MODULE.md)可继续取历史材料或比较读法。方法说明只占需要的篇幅，不让形式上的界定和条件盖过作品本身。

## 边界与验收

不诊断作者或当事人，不补造隐秘动机、创伤记忆或群体本质。沉默有多种原因，不能自动解释为认同、压抑或欺骗。文学、审美、哀悼与游戏的价值不必先表现为长期行为或集体结构变化。

验收看材料贴合、关键细节、语境、声音区分和竞争读法，不把所有解释强制放到预测分数上。若要进一步声称现实读者发生改变或某种安排造成心理后果，再取得相称材料。专业细读已充分时直接采用，不为显示框架而强行加术语。

[完整合成示例：《钥匙》的细读](../../assets/examples/output-modes/meaning-interpretation.md)。移除或改写一个关键意象后，应检查依赖它的解释；无关标点或同义改写不应凭空生成新的人格判断。
