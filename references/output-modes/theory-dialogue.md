# 跨理论对话与争论重建

用户要求比较两种解释、重建思想争论、辨认理论怎样互补或冲突时调用，通常由 R7 承接。只问某个定义时走 R1；仅需两个方案比较时使用有限选择，不先写思想史。返回[成果模式索引](../output-modes.md)。

## 输入与实际工作

取得具体争点、待比较文本及版本、相关语境和所问结果。来源不全时实际寻找获准使用的原作或可靠专业材料；只读摘要的部分保持相应范围。书目提及不能代替原作，资料中未写的观点不能凭作者姓名补出。

1. 先以各方自己的术语写清主要承诺、量词、适用范围和理由；保留它最容易受到挑战的强主张，不先改造成各方都能接受的温和提醒。已经写明的限定同样保留，不把作者写过的限定当作遗漏；原著已有的区分不记为本框架或后来者的贡献，自己的重建不写成原著已有（§2.7.1）。
2. 区分定义、经验解释、形式关系、构成地位和规范主张。对同一词的不同义项按需调用[领域适配](../../modules/domain-mapping/MODULE.md)，保留不可对齐处。
3. 判断哪些论点在回答不同问题、哪些针对同一结果竞争、哪些可局部接续。不同结果不能被一个总体“优劣”覆盖；相同现有预测也不证明理论等价。
4. 对可比较的主张检查材料和最强反方，各方用同一套证据要求和检验，包括用本框架术语写成的一方（§4.8.4）；必要时构造小型反例或区分观察；[有限工具](../finite-tools.md)只处理其适用的模型部分。规范分歧展开理由，不用经验尚未确定的崩溃或收益替某方赢得论证。提出批评时写明所用的标准出自对方自己的前提、评价者另行采用的前提，还是对方主张所涉的事实材料；用另行采用的前提作出的是外部评价，可以成立，但不等于指出了对方论证内部的错误。
5. 逐项形成判断，再写比较专论。可以有理由地偏向某一解释，也可以留下不可区分的机制或不可合并的价值分歧。新综合方案保持本次构想身份，说明新增了什么及如何检验。

## 交付与接续

交付一篇中心明确的完整文章：争点、双方论证、可比与不可比处、材料比较、反方回应、限定结论。读者应看见为什么得出取舍，而非只得到理论介绍或打分表。资料不足不妨碍交付已有依据支持的局部比较。

长任务可附来源位置和争议对应表，并交给[研究入口](../../modules/research/MODULE.md)继续取材；已有主张记录直接引用。要求设计新研究或制度时再接对应任务，不把比较结果直接作为现实处置权。

## 边界与验收

不把所有理论改写成 Xikari 的同义词，不预定框架胜出；也不因专业方法没有本框架编号就取消其知识地位。同源材料不能按理论数量累计成独立支持；没有先例检索不能宣称学术原创。

实际核对：原文中的范围、限定和强承诺是否保留；批评的标准出自哪一方是否写明；是否把不同问题误判为矛盾；现有材料不可区分时是否仍强选赢家；已经可以裁决时是否只说各有道理。不能以统一程度、引用数量或模型共识评价理论是否成立。
