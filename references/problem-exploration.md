# 问题展开与跨部分综合

复杂、混合或涉及多种处境的问题，由主作者在 M0 明确原问后、M2 收窄局部模型前使用；各分析作者承接相关分支，M9 回到原问综合。阅读责任仍依当前模式亲自完成，本指南不替代原文，也不建立全部模块必经的新路线。明确、局部的概念问答可以直接回答。

## 辨认实质相关的范围

依 §1.10，从原问中的真实差异出发。先辨认可能需要解释的关系，再决定局部模型；不能把已有提纲、已选模块或最先想到的解释当作全部问题。相关性的依据包括解释差异、当事人处境、适用边界、代价、反例、责任与可能性，不只看它是否改变主结论。

用 §1.1 的八层责任定位有关概念族，并结合领域知识发现框架没有充分表达的区别：

| 范围 | 要辨认的实质问题 |
| --- | --- |
| U 对象与结构 | 所比较的对象、关系与条件是什么；当前结果怎样形成和维持；历史影响通过什么载体留存 |
| S 尺度与变换 | 聚合、空间、时间、组织、因果、分辨率、影响、网络与授权是否被混同；转换保存或遗漏了什么必要区别 |
| H、A、MC 人类处境、行动者与多圈层 | 谁决定、实施、承接、受益、受损或缺席；物质条件、体验与意义如何影响选择；不同位置和角色是否冲突 |
| P 路径与前瞻 | 哪些事件或条件会改变后续路径；不同时钟怎样接续；哪些反馈、锁定、逆转和停止条件值得展开 |
| I、N 证据接口与规范选择 | 材料支持什么判断；事实到价值或行动之间加入了什么前提；权利、利益、责任和权限如何分别成立 |

这些范围用于发现问题，不要求每题逐项写表、实例化所有概念或建立联合大模型。按 §1.12 区分经验问题、结果使用合同和形式命题；概念名称本身不能增加解释强度。涉及人类处境才使用相应人类概念，自然过程不套用人格、同意或责任。

保留可能被当前表示遗漏的重要分支：总体与不同位置是否分离，当前改善是否转移了后来成本，已进入者之外是否还有缺席者，技术可行是否留下规范冲突，受损或成功经验是否被同一种解释过早排除。普通领域概念与专门定义保持区别，不因为窄合同不适用就取消原问中的学习、意义、帮助或价值。

把确实相关的分支交给相应模块展开。已有工作直接承接；新分支需要取材、计算、机制分析或规范比较时实际完成。范围判断可以随材料修订，不要求用户逐轮点名。新增分支若只有泛泛联想、不能说明与原问的关系，就不继续扩张。

## 使关键连接承担论证

按 §1.11、§1.12 与 §4.17，每项影响主要解释、局部判断或方案取舍的连接，都须按其命题类型说明怎样成立，而非停在标签或一条箭头。对因果、传播或动态连接，展开实际相关的条件：

- 连接哪些对象、状态或结果，材料分别支持到哪里；是否来自相容的对象、比较与时间窗。
- 经什么载体、中介与通道，在什么使能条件、容量、时延和阈值下发生；已有总效应与尚未识别的机制分开。
- 什么竞争解释也允许现有观察，什么反例、反向条件或新材料会使该连接减弱、反转或停止。
- 当前能够形成什么局部判断、为何如此，以及它实际限制后续的哪一部分。

概念比较说明定义、语境、适用条件与非等价区别；形式论证说明前提、推导与反例；证据到判断的连接说明材料的支持范围、推断规则与竞争解释。它们不必虚构载体、时延或反馈来充当因果机制。规范连接公开价值前提与冲突理由：某种效果为何值得追求，谁承担代价，有哪些权利或责任不能由效率代替。不能用因果机制证明“应当”，也不能因支持某种价值就认定相应事实为真。

对相关的历史、多时钟或反馈继续追踪到足以回答原问的位置。按 §10.6、§10.7 区分一次影响、返回信号和返回后真正改变的条件；没有动力依据时保留未知，不靠叙事把一条路径无限延长。推演与前瞻仍按 §12.1 分开，路线的输出身份不限制相关解释与条件论证的充分展开。

## 从局部结果形成共同判断

M9 既保留已开展的实质分析，也检查重要分支是否尚未进入分析或只停留在标题。缺口交回最早受影响模块补足，不能用一句“值得进一步研究”代替当前已有条件完成的工作。各主要部分给出局部判断，使它们有依据地进入中心判断。

依 §10.2、§10.5、§10.6 保留不同位置与通道，依 §10.10 控制联合表示的成本。不同部分之间至少把实际存在的接续说清：共享预算、人员、时间或承接能力是否重复占用；一项措施是否改变另一项措施依赖的条件；反馈会放大还是抵消效果；短期响应是否赶得上长期调整之前的损失；价值目标之间哪些可兼容、哪些需要公开取舍。方案共同实施时按 §12.10.2 核对联合可行性，分别可行不等于可以同时完成。

综合后说明哪些局部结果共同支持中心判断，哪些形成条件分歧，哪些保留独立价值或尚不可区分。解决对象、时间、数值、事实前提和规范前提之间的冲突，不能只合并段落或让建议相互抵消。并列观察没有实际通道时仍可并列，不为制造统一故事强接因果。

按 §12.16 将这些关系写进完整正文，不以覆盖标记、概念清单或模块报告代替论证。已经充分处理的问题不靠重复变长；发现了实质遗漏，也不因已有结论未变就省略展开。
