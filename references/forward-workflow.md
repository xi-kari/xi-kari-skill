# 模块顺序与工作承接

由主作者与协作者读取。使用[七条路由](routing.md)决定本题需要哪些模块，按真实依赖完成具体分析。默认全读，显式 `layered` 实验依[阅读规则](full-source-study.md)进行；阅读不是额外的编号阶段，也不能由模块执行记录替代。

## 内容怎样向后接续

M0 确定原问、对象、用途、截止与成果；M1 建立可回查材料及支持范围；M2 建立对象、状态和尺度；M4 在需要时处理三类变换；M3 比较机制与反方；M5 展开有父子关系的条件路径；M6 为 R4 形成结果前登记；M7 比较六类方案；M8 攻击具体主张和依赖；M9 整合完整成果。不同路线可以跳过无关模块，不能省略实际依赖。

解释、推演、条件前瞻与选择分别承担 §12.1 所列责任。R3 在 M5 内核对传播机制，不因没单列 M3 就允许故事代替通道。R6 如需比较动态后果，补 M5；M7 出现新方案时补它自己的材料、路径与反方。不机械从头重跑。

核心交接内容是问题合同、材料基础、对象状态、冻结快照、路径、前瞻登记与方案比较。除 R4 登记外，只有跨作者、冻结、恢复或成果编辑确有用途时才单独落盘；可直接引用已有文件或前文。模块间传递的不是“完成”标记，而是判断、来源、假设、未知和下一项实质问题。

## 旧工作名称的定位

下表仅帮助理解既有稿件和讨论中的 XK 名称，不提供旧完整正序运行路线。

| 旧名称 | 对应模块与当前责任 |
| --- | --- |
| XK0 问题 | M0：原问、对象、用途、截止与成果 |
| XK1 学习 | 阅读规则：默认全读，显式实验可分层 |
| XK2—XK3 材料与证据 | M1：取得、辨认身份与支持范围 |
| XK4—XK5 概念与局部模型 | M2：对象、依赖、尺度、行动者及圈层；所用机制依赖交 M3 |
| XK6 变换 | M4：尺度、圈层关系、表示与表述转义 |
| XK7 解释 | M3：IT、IG、CM、简单基线与竞争说明 |
| XK8 推演 | M5：状态接续、时钟、分叉与停止 |
| XK9 反方 | M8：具体反驳、敏感性和位置互换 |
| XK10 前瞻与选择 | M6：登记前瞻；M7：规范比较与有限选择 |
| XK11 成文 | M9：完整论证、取舍与成果总装 |

IG 七闸、IT 四次转换与 DF 九闸继续按原文用途约束判断，不被上述模块名替换。它们不成为学习证书或模型自我认证程序。普通局部理解不展开不相关的强判断与治理合同；正式分类、强判断或高影响用途也不能通过改名逃避其合同。

## 直接完成工作

材料与计算能完成时直接做，明确判断有依据时直接给出。深度与广度由问题需要决定，不为速度删去重要机制、反例、位置差异和替代路径。工具结果只支持其实际检查或计算的对象；完成登记不证明预测有效，完整文章不证明方法优越。

同任务接续从最早受影响处进入：新证据先到 M1，对象身份变化先到 M2，用途或价值变化先到 M0/M7，现实结果进入 M6 回写与相关机制更新。保留有独立依据的旧结果，同步受影响的主张、路径、方案、条文和图表，见[持续对话](continuation.md)。
