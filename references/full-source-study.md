# 阅读与学习

由每位承担理论判断的作者读取。阅读使作者取得并理解正在使用的定义、条件、排除项、非等价、例子反例及跨章连接；索引、卡片和报告都不替代原文。

## 默认全读

`reading_mode=full` 是默认。新的独立 Xikari 分析任务，主作者与每位独立作判断的作者亲自顺序完整学习书前、十六部分、附录 A—D 和参考文献，再进行具体理论应用。可以先明确要求和取得文件，不能先形成实质结论再只找支持原文。

R7、全书一致性、体系迁移与未知路由始终全读。标题、正文、表格、例子、反例和表内关系均在阅读范围。包内有全文、脚本打开过文件、搜索命中或散列一致都不表示模型已经看过。

## 显式分层阅读实验

`reading_mode=layered` 仅在用户或明确实验安排已授权时使用，依据 §1.5.3。授权实验不等于默认切换，不能在未完成 A/B 比较、预设容差尚未确定时声称与全读等效。

先读[共同核心清单](reading-core.json)中 `reading` 的全部范围，包括 G1—G4 与 E1—E5 的完整合同；然后读所选模块头部 `reading` 的全部范围，最后补足实际用到的概念、规则卡与跨章依赖。共同核心只在该清单定义。

`front` 为首个 `part_1` 锚点之前的完整书前内容；`part:18` 为附录 B。其余 `part:N` 对应原文分部锚点，数字或字母章节 ID 对应读取器索引。使用相关人类变量时补读第七部分和附录 A 的对应完整接口，不能把 U 直接当 HV。

每张卡使用前先读它锚点指向的完整小节。遇到概念依赖、例外、竞争解释、排除项或跨尺度转换，继续读取关联完整小节，不能只读检索命中的句子。父小节是否包含子节以真实标题层级和读取器索引为准；独立列出的后续小节要另读。

在任务上下文简要保留模式、实际范围与未读依赖，供接续与实验比较；不制作逐节打卡、证明读过的回执或覆盖证书。无法确定依赖范围时扩为连续部分或全书。原文不可取得或本模式必读未完成时明确具体缺口，继续取得，不冒称范围完整。

## 理解作者概念

分开定义、经验问题族、条件形式命题、机制合同、人类特化、规范与授权。形式成立不等于现实满足前提；方法门不冒充经验原因。反馈、制度写回、学习与净收益不能互相代证，S0—S6 不构成成熟阶梯，X0 不是 S7，历史形成、当前载体与 G3 条件增量分别成立。

把相关文本读成相互约束的体系。局部模式只支持所读范围内的应用，不自动支持全书评价；全文模式也不能把阅读量当现实证据或免除领域材料。

## 分块与完整小节读取

以实际技能根目录设置 `$skillRoot`，可从任意工作目录调用：

```powershell
python "$skillRoot/scripts/read_source.py" --chunks
python "$skillRoot/scripts/read_source.py" --chunk 1
python "$skillRoot/scripts/read_source.py" --chunk 2
python "$skillRoot/scripts/read_source.py" --section 12.2
python "$skillRoot/scripts/read_source.py" --part 11
```

`full` 先取得总块数，再按 1 至末块顺序读取，真正进入作者可读的工具结果。默认每块 6000 字符；宿主输出较小时减小 `--chunk-size`，用同一块长继续或按实际位置重接。工具输出截断须补读，不把全部块塞进一次会截断的调用。`--part 1` 至 `--part 21` 不含书前，不能单独充当全书读取方法。

`layered` 用分块取得书前，用 `--part` 和 `--section` 读取清单。`--list`、`--search` 只定位；定位后读完整语境。`--check` 是维护身份检查，不证明学习完成。没有 Python 时使用宿主按连续行段读取。

## 恢复与协作

同任务、同作者可以接续已完成且仍可靠的学习，复读理解不可靠的相关连续范围。保留下一阅读位置和少量概念连接笔记，不能仅凭“已读完”继续。无法确定缺失范围时重新全读，不因普通压缩机械从第一页循环重启。

新的独立任务重新按当前模式学习；理论文本变更时，`full` 重新全读，`layered` 重读共同核心和改变小节的依赖闭包，范围不能确定则全读。新主作者或新协作者亲自完成其角色和模式要求的阅读，不继承前任资格；已有可回源材料和成果可以继承，无需重搜一切。

默认协作的判断角色均全读；分层实验可以让生产角色按核心与模块读，研读者和独立反方审查者仍全读。后者的报告不能代替生产者自己的必要阅读，见[协作](collaboration.md)。

## 不自证

不生成学习评分、逐卷回执、签名或通过证书，不调用另一个模型盖“已理解”章。实际运用、来源核对、反例与可检查计算服务问题本身；外部方法评测在开发环境进行，不加入每次分析的仪式。
