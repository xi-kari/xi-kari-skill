# 全文学习

## 学习先于应用

每个新的Xikari分析任务，主分析作者先完整读取`source/Xikari-条件结构与转化论.md`，理解相邻章节的承接，再处理具体问题。可以先辨明用户要求和取得必要文件，不能先形成实质判断再只找支持它的原文。

顺序为书前说明、第一至第十六部分、附录A至D、参考文献。标题、正文、表格、例子、反例和表内关系均属于原文。理论全文在包内存在，不等于已被读取；索引、内核指引、旧答案、旧阅读经历、搜索命中和其他模型的摘要都不能顶替本次学习。

## 怎样学习作者的概念

阅读每个概念时把握它所指的对象、定义、适用条件、明确排除、与其他概念的关系，以及它允许和禁止哪些推论。注意同名概念与一般用法的差异；用案例与反例理解边界，不能只记一句定义。

区分定义、经验问题族、条件形式命题、机制合同、人类特化、规范与授权。程序要求不是经验原因，形式成立不等于现实满足前提。U与HV不一一等价，状态原型不等于价值或成熟阶梯；历史形成、当前载体作用与G3条件增量分别成立；反馈、学习、修复和净改善不互相代证。

将全文理解为有关联的体系：前部的对象与证据要求怎样约束后部机制，尺度与表示怎样限制推演，人类变量如何接入圈层和规范，附录怎样补足主文。阅读后的导航用于调动已学内容，不取代原文。

## 连续分块读取

可选章节读取器提供完整分页，不需要安装模型后端。以下PowerShell命令使用`$skillRoot`表示当前`SKILL.md`所在安装目录，可从任意当前目录调用；路径设置见[宿主接入](host-setup.md)。理论由读取器从随包`source`目录取得：

```powershell
python "$skillRoot/scripts/read_source.py" --chunks
python "$skillRoot/scripts/read_source.py" --chunk 1
python "$skillRoot/scripts/read_source.py" --chunk 2
```

先取得总块数，再按1至末块顺序读取，每块真正进入作者可读的工具结果。默认块长为6000个字符；若宿主输出上限较低，使用更小的`--chunk-size`，并始终以同一块长继续，或按对应位置重新接续。不要把所有块塞进一次会截断的调用。

分块保留原文连续内容，包括书前和末尾；一段或表格跨块时连续读完后再理解其整体关系。`--part 1`至`--part 21`不包含首个分部锚点之前的书前内容，不能单独作为全书读取方法。`--section`用于学完后的定位复读。

工具输出发生截断时补取未见部分，不能把工具读到了磁盘文件当作模型已经看完。`--chunks`只报告位置，`--check`只作维护身份核对，二者都不是学习完成证明。没有Python也可用宿主按连续行段读取整个文件。

## 长文本和上下文恢复

为跨段和跨上下文保持学习连续性，可以留下简洁学习笔记：概念定义差异、章节连接、关键例子和反例、尚未理解之处、下一阅读位置。笔记服务记忆与续读，不是回执或能力证书，不免除任何未读原文，也不直接交付给用户冒充分析。

同一任务恢复时接续未读部分，并复读理解已经不可靠的相关连续章节。若无法可靠确定阅读位置或定义关系的缺失范围，重新完整阅读。不要用压缩后的“已全读”三个字代替仍可用的理解，也不因正常分块就反复从第一页重启、造成无法完成的循环。

主作者不能把各部分分给子智能体后只看报告。辅助者可以查材料、复算、定位反例或说明难点，主作者仍亲自学习完整原文。独立承担Xikari分析并给裁决的子智能体也承担相同学习要求。

同一任务的持续对话不因消息轮次而自动重读全书；新的独立任务仍重新学习。已知更换主作者或模型时，新作者未亲自完整学习过当前原文的，须先完成自己的全文学习，再接续已有工作；继承的是有来源的材料与成果，不能继承一张“已读完”的资格。见[持续对话](continuation.md)与[协作](collaboration.md)。

## 不制作自我证明

不生成逐卷回执、通过标记、学习评分或签名，不调用另一个模型给“已理解”盖章。分析中准确使用定义、揭示关系、处理反例并给出有据结论，才是读者可以观察的表现；不把这种表现扩大为普遍正确性证明。
