# 问题路由与原文依赖

由主作者在入口及用途变化时读取。路由依据 §1.1、§12.1 的输出边界；阅读范围另按[阅读规则](full-source-study.md)确定。路线短不意味着可以跳过所需原文，全文学习也不意味着每题要运行全部模块。

## 七条路线

| 路由 | 识别问题 | 顺序 | 输出与停止位置 |
| --- | --- | --- | --- |
| R1 原文与概念 | 是什么、有什么区别、校对原句 | 读完整定义、语境及其依赖后直接回答 | 定义、条件、区别；不自动展开工具合同 |
| R2 解释与诊断 | 已发生的事为什么如此 | M0 → M1 → M2 → M4（按需）→ M3 → M8 → M9 | 有边界的机制说明；不自行预测 |
| R3 推演 | 若某条件或事件发生会怎样 | M0 → M1 → M2 → M5 → M8 → M9 | 冻结起点、条件路径与区分信号 |
| R4 条件前瞻 | 可判目标在期限内会怎样 | M0 → M1 → M2 → M3 → M5 → M6 → M8 → M9 | 结果前登记、可失败的判断 |
| R5 有限选择 | 该怎么办、选哪个 | R3 或 R4 可用结果 → M7 → M8 → M9 | 分析推荐；真实执行另需有效授权 |
| R6 制度与计划起草 | 写章程、规则或计划 | M0 → M1 → M2 → M3 → M7 → M8 → M9 | 可审议草案；需要时补 M4、M5 |
| R7 理论评估 | 全书一致性、体系比较或迁移 | 全读 → M3 → M8 → M9 | 有全书覆盖的限定评价 |

“会怎样”只有模糊目标或没有可相接的期限时默认 R3，说明已有条件后果与补成 R4 的必要项，不偷偷变成已登记预测。“为什么以及怎么办”先 R2 后 R5；已有解释直接继承，补足后果、规范、比较与授权边界。

未知路由先全读，再依据原问界定输出；不为兼容旧行为增加完整正序路线。R5 可以只接 R3：依 §12.10.1，有限选择不普遍要求先识别全部状态或拥有准确预测。研究、补证与构想服务当前路线，形成新方案时补齐自己的后果与反方。

## 阅读与依赖

默认 `full`，`layered` 仅在明确授权的阅读实验使用。共同核心为 `front`、`part:1`、`part:2`、`part:3`、`4.17`、`12.1`、`13.1`、`13.2`、`13.3`、`part:18`、`C.1`、`C.2`、`C.3`。这些是 `read_source.py` 的章节或分部标识；`front` 指首个分部锚点之前的全部书前内容。模块 `reading` 在共同核心之外增加相应完整小节或分部。

每个实际使用概念要联读定义、适用范围、依赖、排除项与反例；每张规则卡先读其锚点完整小节。附录 A 的所选支持路线整体使用，不拼不同路线的有利条件。新增跨章依赖继续补读；无法界定范围时升级连续部分或全书。

| 应用内容 | 原文入口与补读责任 |
| --- | --- |
| 对象、状态与九轴 | §3.1、§3.2、§3.6、§5.2；涉及人类变量补第七部分和附录 A 的对应完整接口 |
| 机制与竞争说明 | 第二部分、相关 CM 完整合同、§6.11、§6.14、§13.1、§13.3 |
| 变换与转义 | §3.4、§4.18、§4.19、第五部分、附录 C 对应合同 |
| 人类集体原型 | §8.2 与所用 §8.3 完整卡；X0 读 §8.5；所用路径读 §8.4 |
| 行动者与多圈层 | 第九、十部分；不是每题都需要联合对象 |
| 推演与前瞻 | 第十一、十二部分、§13.10、§13.11、§16.4、§16.22 |
| 法律、制度和高影响采用 | 第十四、十五部分与附录 D 对应领域；现实权责和领域规范另取证 |

正式 G/H 实例、C 结果、CM 机制、描述状态和领域独立结论各有自己的支持合同，不能统一添加同一种 G-instance。当前载体持续作用先核 §4.5，仅在额外主张当前表示之外的历史增量时再检 G3。

## 接续与范围改变

同问题补材从最早受影响模块进入。对象或用途改变时先改 M0，再补真正新增依赖；不能拿此前解释直接取得前瞻或执行资格。用户只问一个局部概念时直接回答该区别，发现重要错误则同步说明它影响哪些原结论。

工具索引 `read_source.py --list` 用于定位；`--section` 读取完整小节，`--search` 命中后必须回完整语境。散列与锚点检查是维护工具，不是理解证明。详见[工作承接](forward-workflow.md)、[模块接口](task-routes.md)。
