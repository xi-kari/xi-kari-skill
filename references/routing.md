# 全文学习后的重点复查与方法适用

## 先完成全文学习

先按[全文学习](full-source-study.md)完整阅读并理解全书。本文件只在全文学习之后帮助回查重点和选择适用方法，不能作为首次阅读的删选表。共同方法的复查入口为§1.1、§1.4—1.5、§1.11、§4.17、§13.11.1—13.11.2与附录C.3；[理论操作导航](theory-core.md)只辅助调动已经完整学习的内容。

每次新的独立Xikari分析任务重新完整学习；同一任务中的补充、进度询问和继续工作可以接续。上下文压缩后补完未读部分并复读理解不可靠的内容，不能拿摘要或旧回执顶替未读原文。理论文本改变时重新全读。

`read_source.py --chunks`与`--chunk N`支持从书前至末尾连续读取；`--section`用于学完后的完整小节复读。工具不判断理解、经验真伪或任务完成。直接连续读取原文也可以。维护时可用`--check`核对身份；普通调用不制作源锁、读取回执或学习证书。

## 按任务复查与展开

| 任务或触发 | 原文入口 | 工作指南与必要边界 |
| --- | --- | --- |
| 定义、原文校对、低影响澄清 | 相关完整定义、直接引用的条件与排除项；§1.5—1.6、§13导言 | 给出所问答案，不自动展开全部工具合同 |
| 结构解释、比较机制 | §2相关证据方法；D0与§3.6；所用G/C/CM合同；§5.2、§13.1—13.9 | [analysis.md](analysis.md)；保持相应实质边界，不默认生成流程表 |
| 表示压缩、摘要、交接、跨尺度或组合流程 | §3.4、§4.18—4.19、§5相关算子与变换记录、附录C.6—C.8及C.12 | 分开F1/F4静态恢复、F2动力、F5误差、F6任务族；三种组合不能互证 |
| 人类或集体状态 | 第七至九部分相关接口；附录A对应完整卡；§16相关保护 | U与HV不是一一等价；S0—S6只用于适用集体，不作为普遍成熟度 |
| 多圈层或事件推演 | 第十、十一部分相关小节及§13.10 | [dynamics.md](dynamics.md)；只有必要才采用联合状态；无关接口不硬套 |
| 条件前瞻 | 第十二部分中§12.1—12.7、§12.12、§12.15—12.16及§13.10 | 结果前登记，材料不够就保留情景身份 |
| 方案比较与普通计划 | §12.8—12.11、§12.14—12.15中的相关小节及所用机制 | [choice-execution.md](choice-execution.md)；资源排程不因此自动运行全部干涉与治理程序 |

| 普通已授权文件或工具工作 | §4.17、§13.11.1—13.11.2；涉及结构性判断时补相应判断合同 | 核对身份、参数和任务终点；不凭工具可用产生权限，也不人为增设组织审批 |
| 领域应用 | 附录D对应完整条目及其关联定义、合同与领域资料 | 保留领域原生方法、框架新增区别、反例、成本和退出条件 |
| 全书评估、体系迁移、理论冲突 | 整体相关原文；全书一致性结论需要全书覆盖 | 禁止用局部路线声称完成全书审查 |

## 依赖闭合

全文学习和XK4概念族全面扫描后，对本题适用的概念进一步核对定义、适用范围、必需实例、排除项和支持条件。附录A选中的conditional_support_route整体使用，不拼接不同路线的有利条件；推理硬依赖、程序依赖、专化和应用关系分别处理。新术语未定义或来源冲突时保留差异；不把旧版同名卡当作新定义。方法不适用可以不运行，不能据此省略首次全文学习。

首次学习须读完全文，不按已形成的主结论提前停止。完成之后，补充检索和复读按尚未解释的实质问题展开；解释机制、局部结果、边界和代价均有价值，不能只以是否改变首选决定取舍。没有新的实质问题时可以停止重复检索；材料不可得时限定对应判断，不取消独立成立的分析。

正式实例与领域解释分开。申请G或H中相应经验条款的正式实例支持时，核验该条款所需的预冻结、输入、比较、判据和结果。C核结果使用条件，CM核具体机制路线，HV描述、类型和状态路线按各自条件成立；不能统一追加同一种G-instance。描述领域机制仍需领域证据，但不伪造正式资格。

持续再生产、学习、反身影响、累积损伤或相位持续涉及当前载体时，按问题定位HV05-R4、HV07-R3、HV08-R3、HV09-R3、HV10-R5及§4.5。只有额外主张历史在当前表示之外有条件增量时，再核G3。
