# 研究与解释边界报告

这是按需组合 M0—M10 的任务入口，不是第九条判断路由。用户要求系统研究一项内容、充分写出成果，或同时指出当前解释不了和存在问题的部分时使用。先按所求判断选 R1—R8，再组织实际研究与双成果。短概念问答不自动展开研究项目。

## 输入与调用

承接原问题、对象和用途、已有材料、当前结论及争议。用户只给题目时自主取得适当资料并界定本轮能完成的范围；用户限定材料范围时遵守。解释用 R2，条件推演用 R3，现实前瞻仍由 M6 登记，理论评估用 R7，候选用 R8。需要行动建议或规则才接 R5/R6，理解本身可以是终点。

可直接说：“用 Xikari Skill 研究这些材料，交付完整报告，并单列未解释项和可能的问题。”研究方法可以是文本细读、史料比较、经验分析、形式推导或规范论证；不统一变成因果实验。需要专门作品时选[七种成果模式](../../references/output-modes.md)。

## 实际工作

1. **明确争点与范围。** 从需要解释的差异出发，辨认重要分支。保留已有局部结论，说明本轮新增问题；不先猜答案再只找支持它的材料。
2. **适配领域材料。** 按需调用[领域映射](../domain-mapping/MODULE.md)。辨认词义、对象、关系、任务终点、测量口径和专业方法；未对应的领域知识仍按自身依据使用。
3. **完成可开展的研究。** 实际读取、比较、计算或细读。按[研究工作](../../references/research-work.md)处理来源形成、反向材料、时间和识别条件。缺失不补零；未知机制不取消独立成立的描述或由相称方法识别的总效应，相关变化也不能自行成为因果效果。
4. **形成论证。** 每个主要判断说明材料怎样支持、方法能回答到哪里、最强替代解释是什么、哪些观察仍不能区分。保留可并存的机制和真实规范分歧，给出有理由的局部与总体判断。公开材料、计算和推导，不输出私有内部思维链。
5. **从实际工作提取问题。** 先指出具体未解释项，再判问题身份。无实际断点时不为填表制造漏洞；确实触及理论承诺时也不能一律归咎于材料。
6. **同步双成果。** 交付完整主体研究报告及单独汇总的解释边界与问题。它们是两项内容功能，可以同文分节、作为附篇或分成文件；问题少时用集中自然段即可，用户指定分开文件时遵守。影响中心结论的限制须同时写在摘要与相关判断处，附篇不能藏住它。正文使用领域语言，理论合同与领域证据各自标明出处。

## 两项成果

**主体报告**应使读者连续理解问题、材料、方法、结果、解释竞争、反方、裁决及成立条件。关键部分给出具体论证和案例，不能以来源列表、状态表或目录代替全文。复杂研究各部分先有局部判断，再说明彼此是支持、制约还是独立关系。

**问题报告**集中写出：受影响的具体主张；已经尝试的材料或方法；仍不能解释什么及其依据；改变判断的哪一部分；下一项有区分力的材料、方法或修订。以下是工程分工，允许一项多类，不是新的理论分类。

| 身份 | 必须定位的内容 | 后续工作 |
| --- | --- | --- |
| 材料不足 | 缺什么记录、影响哪个范围 | 取得相称材料，保留独立结论 |
| 方法与识别限度 | 哪些解释仍兼容同一观察 | 改比较或测量，或保留并列解释 |
| 领域方法需求 | 哪个专业问题超出当前方法 | 由相应专业方法接管 |
| 映射或概念不足 | 丢了哪个区别或混淆何种义项 | 修订对应、原词或表达 |
| 理论问题候选 | 实际原命题、前提、范围与反例命中位置 | 走 R7；修订构想另保留候选身份 |
| 规范分歧 | 冲突的价值、权利、目标或责任理由 | 展开论证与有限取舍 |
| Skill 实现缺口 | 已有要求与实际漏做、错做的环节 | 修复流程、工具或成果 |

没有发现实质问题时，交代实际评估范围和未发现的含义即可，不填充虚构问题，也不宣布全理论无误。已回复、已归档和已讨论均不能代替已解决。

## 证据改变与持续研究

来源、前提或映射变化时，沿依赖定位受影响判断，判断维持、限缩、修订、撤回或未决，并给实质理由。下游不能通过改名绕过共享缺口；独立结论保留。更新正文、摘要、问题附篇及实际依赖它们的表格，保留旧稿以供回查。目标重开按 §2.14 保留原问题与旧结果。

多主张或跨轮研究可用[研究工具格式](../../references/research-format.md)和 `research.py` 验证引用、生成双成果、列出变更影响；已有证据与主张账本直接引用，不复制同义台账。工具排版作者完成的研究内容，不代替取材、判断，也不认证语义完整。少量问题用自然段即可，无须强制 JSON。

## 完成与交接

完成标准是当前可做研究已实际完成、正文充分、问题定位准确且两项成果一致，不以文件数量判断。需要未来材料的部分保留具体问题和取得办法；未安排的后台研究不许诺。更简单的领域方法已足以解决时直接采用，新增入口只增加负担时缩小或停用。

示例与可运行命令见[研究格式](../../references/research-format.md)。有限模型计算见[有限工具](../../references/finite-tools.md)，具体操作选择见[能力操作](../../references/capability-operations.md)。
