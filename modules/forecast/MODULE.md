# M6 条件前瞻

由预测者和主作者读取，用于 R4。它把条件路径转为结果前登记、可失败的当前判断。登记保证原问题能够回查，不证明预测准确；技能整体的前瞻能力仍需外部比较。

## 用途与输入

输入为 M0 问题合同、M1 材料、M2 对象状态、M3 机制比较及 M5 路径。已有有效内容直接承接，F1—F7 核对和补足实际缺口，不把上游重新做一遍。只问假设后果走 R3；目标与对象无法冻结时不能靠语气升级。

`contract.md`、`snapshot.md`、`state.md`、`paths.md` 是内容接口的约定名称，只有协作、复核或恢复确有用途时才单独落盘。R4 的结果前登记必须保存到技能目录外的 `forecasts.json`，或等价的可保留登记；工具不可用不免除最低登记字段。若无法保留登记，降为 R3。

## F5 的查卡顺序

1. 依据对象类型、尺度、窗口与所求输出过滤；人类有意图集体、行动者、技术系统、自然过程与混合对象不能互套。
2. 从状态记录与相应退出条件提出候选路径；X0 只作适用人类集体的独立退场路径。
3. 以已观察状态差、通道、容量和时钟在 `rules/index.json` 的 `triggers` 中检索机制、级联、时钟与信号。
4. 入选前阅读其锚点完整小节，逐项核使能条件、排除项与最低证据。原文定义和眼前对象证据分别成立。
5. 一并比较 `competes_with`，保留简单基线与未区分分支；检索先后不代表概率先后。

`draft` 卡可以作为派生候选帮助提问与推演，使用时明示身份并列出所用草稿卡，不据此声称理论已经规定现实机制。抽样审查按 §16.20.1 保留样本与未逐项审阅范围；授权抽样不自动变更卡片为 `author-confirmed`。

## 登记模板

下列是 `forecast-record.json` 的待填结构；尖括号内容须替换成真实值，非适用项写明理由，不能直接提交。`theory_sha256` 取当前 manifest，版本与模型身份取实际运行。每条登记只含一个 `order`；二、三阶另建 ID，并加入状态延续、直接远期判断、浅阶加延续三种基线。

```json
{
  "id": "<唯一ID>",
  "created_at": "<含时区ISO时间>",
  "theory_sha256": "<当前原文SHA256>",
  "skill_version": "<实际版本>",
  "host_model": "<实际模型或诚实标明未知>",
  "evidence_kind": "live",
  "order": 1,
  "question": "<原问>",
  "target": "<可判定目标>",
  "resolution_rule": "<判定来源、方法与未决规则>",
  "window": {"start": "<开始时间>", "end": "<结束时间>"},
  "input_cutoff": "<输入截止>",
  "baseline_time": "<基线时点>",
  "scope": {"object": "<对象>", "circles": ["<圈层或不适用理由>"], "affected_positions": ["<位置>"]},
  "baselines": [{"id": "baseline-1", "type": "state_continuation", "expression": {"type": "direction", "value": "<方向>", "basis": "<独立依据>"}}],
  "mechanisms": [{"rule_id": "CM-LOAD", "anchors": ["6.6"]}],
  "paths": [{"id": "path-1", "parent": null, "order": 1, "conditions": ["<条件>"], "description": "<状态路径>", "early_signals": ["<先行变化>"], "reverse_signals": ["<反向变化>"], "stop_conditions": ["<停止条件>"]}],
  "expression": {"type": "direction", "value": "<有依据的方向>", "basis": "<识别依据>"},
  "calibration_plan": {"metrics": ["<适用指标>"], "description": "<如何取得结果并比较>"},
  "decision_threshold": {"applicable": false, "reason": "本登记不直接用于行动决定"},
  "pause_conditions": ["<暂停条件>"],
  "retire_conditions": ["<退役条件>"],
  "evidence_refs": ["<可解析材料引用>"]
}
```

`evidence_kind` 取 `live`、`backtest`、`teaching` 或 `synthetic`；按实际来源选择，教学和合成记录不计经验能力。数值区间表达使用 `type: interval`、`lower`、`upper`、`unit`、`basis`，不用 `value`；排序使用字符串列表 `value`，方向使用字符串，`none` 使用 `value: null`。概率置信区间不能当成数值目标区间与二元标签计算覆盖。

`decision_threshold` 指本次现实决策阈值，与技能开发评测的合入阈值不同。后者尚待确定，不能在查看评测结果后补设标准，也不能据建议阈值宣告过关。若连续实际使用另需自动能力降级，可事前在 `calibration_plan.degradation_policy` 指定指标、每月最小样本数与连续月数；没有预定门槛时工具保持能力未证实，不能从结果反推一条有利标准。

F8 使用已有注册表时读取 `report` 的 `degradation_decisions`。逐项匹配理论、技能、宿主模型、阶次、表达类型、证据类型和评价合同；匹配组为 `scenario_only` 时，该复杂模型只保留情景表达，或采用具有独立依据的简单基线重新登记。不能仅凭报告顶层摘要把其他对象或版本一并降级，也不能因一次新预测而自动恢复已降级能力。注册表尚无可比结果时保留未证实状态；现有证据已经显示校准或分配错误时，仍按 §16.22 处理，不等待凑足自动阈值。

结果输入含 `forecast_id`、`resolved_at`、`outcome_source`、`observed`、`status`、`path_match`、`model_updates`。`observed` 保存数值或空的 `value`、含时区时间或空的 `event_time`，可附 `details` 文字。状态仅用 `supported`、`not_supported`、`undetermined`、`target_invalid`、`not_evaluable`，后三者须写 `reason`。数值标签缺失保持空，不填零；`scores` 与 `baseline_scores` 由工具按冻结表达及指标计算，不接受预制成绩。

当前工具的计算指标是 `brier`、`log_loss`、`interval_coverage`、`window_coverage`，只计算预登记且输入适用的部分。排序与方向可以登记，但当前保留文字结果、不生成伪分数；需要其外部评价时先确定对应判据和独立评价实现。

## 工具

在外部任务目录准备记录，命令以技能根目录为起点；实际使用可按宿主规则改成脚本绝对路径：

```powershell
python scripts/forecast.py --registry <外部目录/forecasts.json> register --record <外部目录/forecast-record.json>
python scripts/forecast.py --registry <外部目录/forecasts.json> list
python scripts/forecast.py --registry <外部目录/forecasts.json> show <前瞻ID>
python scripts/forecast.py --registry <外部目录/forecasts.json> resolve --record <外部目录/outcome.json>
python scripts/forecast.py --registry <外部目录/forecasts.json> report
python scripts/forecast.py --registry <外部目录/forecasts.json> check
```

`check` 检查记录结构与一致性，不认证分析正确；`report` 只报告已登记和已取得的结果，不从教学例取得现实能力。完整跨阶评价分别报告，不合成总命中率。适用时用 `claims.py` 引用前瞻 ID，用 `condition_lab.py` 计算明确模型。

## 停止与能力边界

三个主要出口：F0 无可判目标则 R3；F5—F8 缺机制、路径或表达依据时保留条件推演或未知；F9 无有效登记则不发布条件前瞻。各出口只压低依赖它的输出，不取消独立的事实判断、条件后果或方案分析。

按 §16.22，长期校准恶化、跨群体误差集中、复杂模型不再优于基线或持续依赖事后变量时，缩小适用范围、暂停相关前瞻声明或退役；保留推演用途，F8 优先简单基线。尚无比较证据时称“前瞻增益未证实”，不能以功能已实现或登记完整替代能力证明。

## 教学例，不作经验证据

明示虚构概率模型中登记某二元事件概率 0.8、简单基线 0.2；到期完整标签为 0。F12 的逐案 Brier 损失分别是 0.64 与 0.04，复杂模型本案较差。若标签因监测离线缺失，则记未决或无法评价，不计算这两个损失。这个算例只说明工具与失败语义，不证明现实概率可估。完整流程见[公开离职教学例](../../cases/forecast-public-resignation.md)。

## 常见误用与相关指南

把几条路径全部算命中；事后移动期限或对象；混合不同阶次算总准确率；把未发生当保护成功；把预测排序当方案排序；把生成完登记当已经验证能力。见[条件前瞻指南](../../references/forecasting.md)、[推演模块](../dynamics/MODULE.md)、[有限选择](../choice/MODULE.md)、[规则库](../../rules/README.md)。
