# M2 对象与状态

由建立局部表示的分析者读取，供 M3、M4、M5 与 M7 使用。它确定当前究竟在比较什么；命名和填齐七个要素既不提供对象事实的依据，也不证明分组增益，两项分别取证。

## 用途与输入

输入为问题合同及 M1 的事实、争议、证据截止。复杂问题先用[问题展开](../../references/problem-exploration.md)核对重要分支与必要区别，再建立能回答各项实质问题的局部模型。局部表示限制无关细节，不删去原问中的分配、体验、历史、责任或规范问题。多圈层、行动者变量及七种状态原型仅在其对象与用途适用时调用，技术系统和自然过程不硬套人类集体原型。

## 步骤与判断

1. 按 §3.1 声明候选结构对象的七个要素（边界、状态变量、关系或转移约束、接口、时间窗、尺度剖面、同一性判据），另列任务目标与比较基线。区分已有对象事实与分组增益主张：前者据文书、观察、关系等领域材料，后者据与任务相称的比较。申请分组增益的正式支持时按 §4.3 检验，只取得限定任务、尺度、时间窗和同一性判据内的分组增益及其对已测试边界扰动的稳健性；缺少分组增益的支持不抹去机构、关系或人的已有事实，也不把独立对象事实改称增益支持。
2. 按 §5.2 保留九轴尺度及理由明确的不适用项。组织上位、影响扩大、观察更细都不等于管辖授权增加。事先定下的同一性判据是追踪对象用的判据，不要求现实成员与边界不发生变化。
3. 使用 §3.2、§3.6 分开变化、存续、演化、解体与修复。未知、不可观察、保护性不公开与不适用分别保留；先前材料缺失不补成“正常”。
4. 对行动者按 §9.2、§9.9 区分快、中、慢变量，记录来源、时点和反证。只有受到新事件触达或有可靠动力依据的变量才更新；一次情绪不填成人格。
5. 需要联合表示时按 §10.1、§10.2 记录圈层、角色映射、关系、物质与体验—意义条件、通道及同一性判据。依 §10.5、§10.6 保留真正相关的多重位置、资源转化与意义变化，不能由总量补出个人处境。只有共同背景时并列观察，不补画直接因果边，也不生成一个更高主体。
6. 对适用的人类集体，联读 §8.2 与对应完整原型，逐项核对入口、退出、可观察量、反例和证伪。缺关键证据保持“未知”；“混合”“并行”必须有各自的正向证据。普通工作笔记只记录状态候选；若声称正式原型分类，须完成 §8.2.1 各项齐备的分类记录，不以本模板替代。有序退场与良性消亡依 §8.5 是独立退场路径，不是第八种状态。
7. 依据 §8.6、§10.7 检查不同位置、承接与时钟的差异，形成当前局部判断及其停止范围。所问任务依赖连续时段时，按 §7.3.9 另记整段可用时间的长度与可预期性，检查默认联系人、待命及临时补缺是否切断时段；不折算成额外时数，也不与已占用钟表时间相加。难以替换的承担者可提示 §7.6.1 的配置—能力候选，交 M3 与其他原因比较，不能从依赖现象直接判定该机制。
8. 按 §1.11、§10.10 检查局部模型是否遗漏了已辨认的重要分支，以及不同模型能否接续。把共享资源、跨边界通道、反馈、异步条件与相互冲突的目标交给 M3、M5 或 M7 继续展开；不能以“分别分析过”认定联合关系成立。增加对象或关系须说明它保存的必要区别；不相关的概念族不强行套用，未决依赖不补成已成立机制。

## 交接物

短任务直接交接实质内容；多作者或长任务可用 `state.md`：

```markdown

资料截止与观察位置：
对象事实、候选分组及比较基线：
本表示回答的分支、保留的必要区别与尚待展开的关系：
行动者、角色、圈层及成员关系：
变量 / 当前值或状态 / 来源与时点 / 适用时钟 / 反证：
相关物质条件与体验—意义条件；无关项理由：
状态候选、支持范围、入口与退出证据、未知：
与前一状态的差异及对象同一性：
可继续的判断、需要停止的依赖与区分观察：
```

## 停止与降级

无法凭同一性判据追踪对象时先做对象同一性判断；不把不同同一性判据下的记录直接拼成一条路径。联合对象缺少实际关系时退回单焦点或并列对象。有来源的局部事实可继续使用，未证实的原型不升为正式分类。

## 教学例，不作经验证据

输入：一个团队用户数增加一倍，但只有总量，未取得角色、接口、负荷与承接变化。对象的界定可记录该团队与用户量的变化，首次扩展与承接分化原型（§8.3.3）仍为未获支持的候选；不能由人数直接判定这一原型。输出给 M5 的是用户量变化、承接未知以及取得位置化负荷与角色材料的具体需求。

## 常见误用

基本结构概念与人类变量一一对应；把七种状态原型当成熟阶梯；把无知写成混合；把状态候选当人格诊断；把恢复输出当内部余量全恢复；把存续当价值。
