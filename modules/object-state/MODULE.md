# M2 对象与状态

由建立局部表示的分析者读取，供 M3、M4、M5 与 M7 使用。它确定当前究竟在比较什么，不把命名和完整字段当作对象有效性的证明。

## 用途与输入

输入为问题合同及 M1 的事实、争议、证据截止。只建能回答当前问题的局部模型；多圈层、行动者变量及 S0—S6 仅在其对象与用途适用时调用，技术系统和自然过程不硬套人类集体原型。

## 步骤与判断

1. 按 §3.1 声明 D0 候选对象的 B、X、R、I、T、SP、K，另列任务目标与比较基线。区分已有对象事实与分组增益主张；后者仍需相称比较，不以缺少 G1 抹去机构或人的已有事实。
2. 按 §5.2 保留九轴尺度及理由明确的不适用项。组织上位、影响扩大、观察更细都不等于管辖授权增加。K 冻结的是追踪判据，不要求现实成员与边界不发生变化。
3. 使用 §3.2、§3.6 分开变化、存续、演化、解体与修复。未知、不可观察、保护性不公开与不适用分别保留；先前材料缺失不补成“正常”。
4. 对行动者按 §9.2、§9.9 区分快、中、慢变量，记录来源、时点和反证。只有受到新事件触达或有可靠动力依据的变量才更新；一次情绪不填成人格。
5. 需要联合表示时按 §10.1、§10.2 记录圈层、角色映射、关系、物质与体验—意义条件、通道及 K。只有共同背景时并列观察，不补画直接因果边，也不生成一个更高主体。
6. 对适用的人类集体，联读 §8.2 与对应完整原型，逐项核对入口、退出、可观察量、反例和证伪。缺关键证据保持 `unknown`；`mixed`、`parallel` 必须有各自的正向证据。普通工作笔记只记录状态候选；若声称正式原型分类，须完成 §8.2.1 的完整合同，不以本模板替代。X0 依 §8.5 是独立退场路径，不是 S7。
7. 依据 §8.6、§10.7 检查不同位置、承接与时钟的差异，形成当前局部判断及其停止范围。

## 交接物

短任务直接交接实质内容；多作者或长任务可用 `state.md`：

```markdown
# 对象与状态
对象 ID、用途、B/X/R/I/T/SP/K：
资料截止与观察位置：
对象事实、候选分组及比较基线：
行动者、角色、圈层及成员关系：
变量 / 当前值或状态 / 来源与时点 / 适用时钟 / 反证：
相关物质条件与体验—意义条件；无关项理由：
状态候选、支持范围、入口与退出证据、未知：
与前一状态的差异及对象同一性：
可继续的判断、需要停止的依赖与区分观察：
```

## 停止与降级

K 不可追踪时先做对象同一性判断；不把不同 K 的记录直接拼成一条路径。联合对象缺少实际关系时退回单焦点或并列对象。有来源的局部事实可继续使用，未证实的原型不升为正式分类。

## 教学例，不作经验证据

输入：一个团队用户数增加一倍，但只有总量，未取得角色、接口、负荷与承接变化。对象合同可记录该团队与用户量的变化，S2 仍为未获支持的候选；不能由人数直接判“扩展与承接分化”。输出给 M5 的是用户量变化、承接未知以及取得位置化负荷与角色材料的具体需求。

## 常见误用

U 与 HV 一一对应；把 S0—S6 当成熟阶梯；把无知写成混合；把状态候选当人格诊断；把恢复输出当内部余量全恢复；把存续当价值。
