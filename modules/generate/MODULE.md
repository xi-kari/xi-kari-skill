# M10 生成

由生成作者读取，从已经成立或已明示的理解出发，沿原文的定义、变换与组合关系推出还没有人提出的命题、问题和构想，交给 M8 攻击、M9 成文。R8 到这里形成的是带出处和检验办法的候选，不是已成立的事实、预测或授权。其余路线在用户要求继续深入、另找角度或既有选项不足时也可以调用。

## 用途与输入

输入是一组起点：M1 的材料、M2 的对象与状态、M3 的机制比较、M5 的路径、M7 的方案，或用户给出的文本和前提。每个起点保留自己的身份：观察、已有支持的判断、条件结论、所用定义、明示假设、未核的陈述。起点不因为被用来推出别的东西而升级。

没有起点就没有推出，只有联想。起点不足时先完成最少的 M1—M3 工作，到能逐项写出起点的身份与出处为止，不要求为此另建文件；用户只要求自由联想时照做，并把结果标为联想。

## 步骤与判断

1. **定起点。** 给起点编号，写明身份和出处。同一事实的两种说法合并，互相冲突的起点并列保留，不先替它们裁决。
2. **选走法。** 把已有理解看成原文关系中的一个位置，每次只改动一项，按该项的合同问“原判断到了这里变成什么、丢了什么、还要求什么”。从下表选对当前起点最可能有产出的几种，不逐项走完；每种走法的做法、适用情形与空转方式见[生成指南](../../references/generation.md)。走法名称只是操作称呼，所调用的合同以所列原文为准。

   | 类 | 走法 | 问的是什么 | 原文合同 |
   | --- | --- | --- | --- |
   | 推必然 | 展开承诺 | 这个判断用了有专门合同的词，合同还要求什么、排除什么 | §2.2、§2.8 及所用定义 |
   | 推必然 | 核对组合 | 几项分别成立的判断，能否由同一批对象承接、共用同一份资源、得到同一终点 | §2.4、§4.18、§12.10、附录 C.12 |
   | 推必然 | 改换任务 | 目标、允许操作或期限变了，哪些被合并的区别必须重新分开 | §3.4、§4.18、§4.19 |
   | 挪位置 | 换尺度 | 沿九轴之一移动后，哪些保持、改变、丢失 | §3.4、§5.2—§5.5、§4.8 |
   | 挪位置 | 换关系 | 这些圈层若是重叠、桥接或竞争而非原先认定的关系，谁的角色与通道随之改变 | §5.10、§10.3、§10.5 |
   | 挪位置 | 换表示 | 判断写进指标、条文或另一群人的语言后，哪些区别被折叠，对象会怎样回应这种观测 | §3.4、§5.10、§4.8 |
   | 挪位置 | 换位置 | 从承担者、缺席者或无法退出者处看，同一安排是什么 | §4.8、§14.4、§16.6 |
   | 挪位置 | 换时钟 | 快的变化遇到慢的约束，何时真正生效，谁先到期 | §6.12、§10.7 |
   | 挪位置 | 反过来问 | 条件不成立、方向相反或对象退出时，会留下什么不同的痕迹 | §11.9 |
   | 接外部 | 追残差 | 现有变量解释不了的差异，可能由哪几个互相竞争的候选造成 | §2.13、§4.8、§5.10、§11.8 |
   | 接外部 | 跨域借问 | 另一领域的同构关系提示这里还该查哪条通道、哪个边界 | §2.6、§5.5、§16.14 |

3. **走一步，记一步。** 每项结果写明父项、走法和陈述。变换类走法按 M4 记录保持、改变与丢失，不预设无损；推必然的走法写出模型、前提和可复核的推导或反例，并实际复算；跨域借问写全源域、目标域、共享结构、关键差异、不可迁移条件、变量映射和区分检验。
4. **定身份。** 模型内推论在给定模型中必然，现实是否满足模型另取证；定义要求是父项若成立就须满足的条件，不是世界事实；经验候选写明对象、目标、条件、比较与失败方式；变量候选来自残差，记录模型候选身份、最小检验和禁止用途；启发性类比只提示目标域该查什么；新问题不表示原问题已解决；构想不产生权限。身份由依据决定，不由措辞的把握程度决定。
5. **四问筛选。** 从哪里来：没有父项的只称联想，单列。新在哪里：分别对照原问与材料、起点、领域已有说法；写明查过的范围，“未见”只相对该范围；领域已有的说法给出处并称已有，凭回忆认为早有而没有核对的称可能已有，都不算作新的。怎样会错：给出能把它与竞争项分开的观察和否决条件，给不出的只留作表达。成立了改变什么：指出受影响的解释、路径、前瞻、方案或适用范围，什么都不改变的不列为主要结果。重述不算新候选。
6. **配竞争项与检验。** 经验候选与变量候选至少并列一个竞争项，各有区分观察；设计风险可接受的最小检验，写明升级与否决条件。候选涉及隐私、健康、安全、法律地位或低权力位置时，先审查取得的必要性、用途和伤害；信息价值盖不过风险就保留未知。
7. **续推与停止。** 候选可以作新的父项；子项继承父项全部未决条件，陈述中写明“若父项成立”。代次不增加支持。对象或尺度同一性失效、关键假设不能继承、给不出区分观察、分支爆炸、新一代相对上一代没有增量、触及权利或授权边界，或已到第三代时停止，写清还能说什么。
8. **排序与交接。** 按成立后改变多大、检验多近多省排序，不按数量；产出少就如实说少。对最强的几项按 M8 实际攻击一次：父项是否真成立，推导有没有漏掉的情形，竞争项是否更省，检验是否真能把两边分开；据此修订、降级或删去，再由 M9 成文。要升级的各走各的合同：补证用 `study_design.py`，取得材料后回 M3，可判且有期限的交 M6 登记，构想交 M7 与不行动同口径比较，新问题交相应路线。

## 交接物与模板

少量候选直接写在回答里。候选较多、有多代关系或需要跨轮追踪检验时，用 `candidates.py` 保存候选账本；账本不是正文。攻击之后要改的候选，在进入检验前用 `revise` 修订并写明理由。

```markdown
# 候选记录
起点：编号 / 陈述 / 身份 / 出处
候选：编号 / 父项 / 走法 / 陈述 / 身份
保持、改变、丢失，或模型、前提与推导：
新在哪里：层级 / 查过的范围 / 已有说法
竞争项与区分观察；最小检验、风险与禁止用途：
升级条件 / 否决条件 / 成立后改变什么：
当前状态：提出、检验中、得到支持的候选、拒绝、退役
```

## 停止与降级

父项被否决或退役时，依赖它的子项一并复核。结果已经出来之后才提出的候选可以改进下一轮，不能回头支撑原判断。候选得到支持后仍须进入相应对象、变量或机制合同，不能直接写成人格结论、有效圈层或因果机制。生成数量、代次和语气都不提高判断强度。

## 教学例，不作经验证据

起点：甲、乙两仓共用一支 6 人装卸队（明示）；两仓日均各需 2.5 人、峰值各需 4 人（假设为已观察）；既有判断“人手总体够用”。核对组合：均值合计 5 不超过 6，峰值若同日出现则需 8，缺 2 人——模型内推论：“够用”只在峰值错开时成立。换时钟：峰值由到货节律决定，若两仓由同一承运商同日送货，同步是常态而非偶然——经验候选；竞争项是两仓峰值互不相关；区分观察是过去 30 天两仓峰值日的重合次数。成立后改变：除了加人，还出现错开到货日这一构想，交 M7 与不行动比较。三项身份各异，哪一项都不能写成“缺口已经发生”。

## 常见误用

把换个说法当新发现；逐项走完全部走法凑数；把类比写成机制；把模型内推论当现实事实；用一个神秘变量吸收全部残差；候选没有竞争项和否决条件；子项丢掉父项的条件；以代次或数量显示深度；把构想写成建议执行。
