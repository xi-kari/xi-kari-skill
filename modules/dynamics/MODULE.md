# M5 推演

由推演作者读取，形成可接续的条件路径与区分信号，交给 M6、M7 或 M9。R3 到这里可以形成答案，不须登记前瞻，也不能使用前瞻语气。

## 用途与输入

输入为 M0 合同、M1 材料、M2 状态及已知或明示假设的机制。R3 没有单列 M3，不意味着免除机制责任：本模块在传播前仍须读所用 CM 合同并比较竞争机制。所需桥接先调用 M4。

## 九步与判断

1. **冻结状态。** 按 §11.1、§11.4.1 固定证据截止、对象、变量、未知、争议、机制参数和版本。截止后信息进入新版本，不能倒灌起点。对应 DF1。
2. **识别对象。** 按 §11.4.2 接受 M2 已成立的行动者、圈层与 K，缺支持的分组保持候选；联合对象不成立就退回单焦点。对应 DF2。
3. **分离双通道。** 依 §11.4.3 记录相关物质及体验—意义条件和跨通道桥；无关项说明不适用，缺失只暂停依赖它的传播。
4. **声明时钟。** 依 §11.4.4、§6.12、§10.7 记录更新时钟、通道容量、时延、阈值、损耗和恢复窗口。即时变化不代表制度写回。第三、四步对应 DF3。
5. **注入事件。** 按 §11.2、§11.4.5 区分观察到、被报告、计划中、假设性、模拟五类，保存事件发生、取得资料与进入模型的时间。已发生的越权行为仍如实记录，授权状态另记。
6. **沿通道传播。** 按 §11.4.6、§11.5、§11.6 先直接状态差，再返回、间接与级联；区分信号到达与有效变化。调用规则卡前读完整锚点，并列竞争卡；无使能证据只能作条件候选。对应 DF4。
7. **生成分叉。** 按 §11.7 分清事实、机制、选择、扰动四类不确定，保留互斥、并行和不可比较路径。动态复杂题依 §11.9.1 检查一至三阶独立问题；每阶继承父节点的未知、损失和残差，不把模拟起点变现实。按 §11.9.3 事前声明合并剪枝规则。顶层路径只放同一对象、同一窗口里互斥的走向；可并存的机制作为路径内部条件或组合说明。对其他对象的外溢挂在触发它的路径下面，写明触发条件。每条顶层路径都配早期信号、反向信号和能区分它的下一份材料。对应 DF5。
8. **登记信号与残差。** 按 §11.4.8、§12.6 为每条重要路径写早期、反向、复核与停止信号；早期信号应先于结果且来自机制。保留帮助读者判断的绝对缺口与相对负荷算式：原承担占比为 p（0≤p<1）的位置退出后，若全部工作转给原先承担其余工作的成员，其工作量相对原工作量增加 p/(1−p)；这是所需增量，实际可用容量另查。解释不了的状态差保留残差，不自动补成新现实变量。
9. **接续真实结果。** 结果实际到来后依 §11.4.9 追加路径支持与偏离，保留旧运行。当前交付不等待未来，也不在没有用户安排时承诺自动跟踪。

## 交接物与模板

快照和路径是后续内容接口；短问题可以直接体现在回答中，只有接续、复核或跨作者需要时才保存。

```markdown
# 冻结快照 snapshot.md
运行版本、原文版本、技能与宿主模型：
资料截止、基线时点、对象与 K、任务：
已观察变量、推断、情景值、未知与争议：
行动者、圈层、关系、双通道条件：
事件表：ID / 类型 / 发生时点 / 取得时点 / 来源 / 触达 / 直接变化 / 争议
机制、参数范围、时钟、传播与停止政策：
```

```markdown
# 路径图 paths.md

条件集 / 触发事件 / 状态差 / 通道与时钟：

```

## 停止与降级

按 §11.9.4，K 或尺度同一性失效、关键假设不能继承、机制越域、界面不闭合、分支爆炸且无区分信号、结论全面敏感、残差超用途门槛、更深一阶无增量、超校准时间窗或达到三阶上限时停止或降级。触及权利或授权边界时，停止相应越界操作或用途；不能据此删除已发生事实或否定独立成立的条件后果。可执行指令与实际工具行动仍须满足适用的规范和有效授权。停止时写清还能说什么。低概率不能单独删除高后果路径；不知道概率也不造百分比。

## 教学例，不作经验证据

输入：明示假设下，剩余 60 件、持续合格产能每日 10 件、生产完成后串行检验 2 天。冻结这些假设后，一阶得到生产 6 天，接检验至少 8 天；7 天目标在当前流程下不可达。二阶候选是生产提高到每日 12 件或改变串行关系，各自需容量与质量依据；没有这些依据就保留条件分支。三阶没有独立问题时停止，不编“制度将因此成熟”。

## 常见误用

把短中长期当三阶；假设事件当事实；平均局部边直接相乘；收到旧资料当现实刚变化；用最顺畅故事填未知；因未登记仍宣布现实将会发生。
