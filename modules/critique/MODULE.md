# M8 反方与压力测试

由主作者或独立反方审查者读取，检查已形成的具体命题、路径或推荐，并寻找原问所需但尚未展开的重要分支与实质反例。它不判定另一个模型“已经学会”，不评分、盖章或认证整篇答案。

## 用途与输入

输入为问题合同、相关证据、状态与快照、路径、前瞻登记、方案比较和所用卡片。可以单作者完成；宿主支持时可按[审查者职责](../../agents/reviewer.md)提供独立上下文。独立审查者只取得必要交接内容与来源，不取得生产者私有推理过程。

来源准确性核查回答出处、引文、原段支持与事实根据；本模块还检查论证是否成立、重要内容是否遗漏以及不同部分能否接续。只做资料核查不需承担独立理论判断的阅读范围；承担实质反方时按[协作](../../references/collaboration.md)履行阅读责任，不能以核查名义省略。

## 步骤与判断

1. 选出承担结论的具体命题与依赖，回到完整原文与对象材料，分开定义忠实、事实支持、推断有效、价值前提和授权。不能以记录齐全代替成立。
2. 重建最强竞争解释，而非最容易回应的反方。依据 §6.11、§12.3 比较简单基线、混合解释、共同输入、选择效应、测量改变和残差；静态任务不硬套动态因果。不要仅在现有报告中挑错，主动寻找与原问实际相关、但尚未提出的重要解释、处境和反例，说明其依据及对答案的影响。
3. 对关键参数、边界、K、时间窗和条件做相称的敏感性检查。依 §11.9.3 保留有依据的高后果路径；依 §11.9.4 判断是否应停止更深递归。
4. 换到不同受影响位置检查理由：中心收益是否来自边缘隐性成本，沉默是否与观测通道受阻有关，是否混淆负荷承担与责任主体。
5. 前瞻检查登记早于结果、同截止基线、分阶记录、表达依据、反向信号与失败语义；选择检查规范前提、六类方案、不行动与联合可行性。跨方案检查共享资源、承接者、先后时限、权责与互斥条件，不能用分别合理掩盖整体冲突。发现真实缺口就限定依赖输出。
6. 给出可处理的问题：涉及哪条主张、依据是什么、会怎样改变判断、最小修正或区分观察。主作者据理由维持、限缩、修订、撤回或保留具体未决，不按模型票数裁决。

## 交接物

输出具体问题及其对结论的影响，必要时附反例构造或复算。遗漏分支不必已有稿内位置，但须说明与原问的联系、已有依据或构造假设、缺失的影响和可补足的论证或观察。主作者处理跨部分关系与不同取舍，将成立内容纳入整体论证，不直接拼接审查报告。没有实质问题就简明说明实际审查范围，不生成“全部合格”证书。发现问题后只补真实缺口，不固定循环轮次。

## 停止与降级

共同事实或对象前提失效时暂停依赖结论；来源不可得时不能自报已核实。相关分支能补足解释、边界或代价时，不因主结论未变而删去；与任务无实质联系或没有新的具体问题时，不继续扩题或重复自审。外部评测另在仓库之外进行，不把运行内意见当能力证明。

## 教学例，不作经验证据

输入主张：“两篇研究分别证明 A→B 与 B→C，所以 A 对 C 的效应等于两段平均效应之积。”反方按 §2.4 与 §11.6 指出前后响应群体可能不同，构造一组只对前段响应、另一组只对后段响应的情况。输出是撤回整链数值，保留两段各自的有限证据，并要求联合响应与接续支持；不能连带抹去独立识别的总效应。

## 常见误用

只找语病或数据错误；来源准确冒充论证完整；只回应已列异议而忽略重要遗漏；用一般常识覆盖理论定义；反方数目充当质量；将同模型共识当独立证据；发现一处失败便撤销所有局部结论；要求循环互审到自称完美。
