# 原界定的非计划断裂

派生使用卡。读取者：M2 状态判断、M5 推演、M6 条件前瞻与反方审查者；调用前读完 anchors 所列完整原文小节。

## 适用对象

- 用于原同一性判据不再成立且功能、承接、关系或边界出现非计划断裂；保留仍成立的局部功能。〔派生，待确认〕

## 触发观察

- 核查原文判据「要与“有序退场与良性消亡”、功能转移、保护性休眠和对象重组分开」。〔原文 §8.4〕

## 生成的路径

- 比较暂时失能、保护性休眠、有计划结束、可识别新对象重组与真实崩解；逐项指出同一性判据的哪一条失效。〔派生，待确认〕

## 时钟与时延

- 记下原同一性判据最后可确认的时刻、断裂范围及后续救援窗口，不用未知未来等待维持旧身份。〔派生，待确认〕

## 早期信号

- 关键接续点连续失效、无法补位的人员退出、职责或资源通道无法继续完成必要功能。〔派生，待确认〕

## 反向信号

- 最低限度的同一性判据持续成立，或有可执行的再激活与保护安排时，保留失能事实而撤回整体崩解。〔派生，待确认〕

## 竞争解释

- “有序退场与良性消亡”有明确处理责任，转移有接收方，分裂有新的同一性判据；不能凭组织名称消失把这些统称崩溃。〔派生，待确认〕

## 不能推出的结论

- 不能从资源释放推出伤害正当，不能把所有成员和功能一概判为失败。〔派生，待确认〕
