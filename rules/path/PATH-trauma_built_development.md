# 伤害条件下形成的结构

## 适用对象

- 适用于有材料显示边界、规则或承接方式在伤害与威胁下形成的集体；不对成员作临床或人格判断。〔派生，待确认〕

## 触发观察

- 核查原文判据「保护与复制原始伤害须分别检验。」。〔原文 §8.4〕

## 生成的路径

- 并列保护功能保留、原伤害被复制、环境改变后规则失配及无可识别持续效应；每条分别取证。〔派生，待确认〕

## 时钟与时延

- 分清形成史、当前载体与后续调用；仅有过去事件叙述不足以登记当前表示之外的历史增量。〔派生，待确认〕

## 早期信号

- 现行权限、岗位记忆或训练内容可追到当时形成，并在相似情境中再次被调用。〔派生，待确认〕

## 反向信号

- 当前规则无法追到该事件、效应由当前威胁充分解释，或替代载体比较不支持持续影响时收窄主张。〔派生，待确认〕

## 竞争解释

- 学习、差异保留和强制重写可能形成相似规则；保留当事人解释但不用叙事替代机制比较。〔派生，待确认〕

## 不能推出的结论

- 不能推出伤害必要、受害者应感激、未来必然复制伤害或需要以新伤害促发展。〔派生，待确认〕
