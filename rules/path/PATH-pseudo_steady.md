# 表面稳定与实际耗竭

派生使用卡。读取者：M2 状态判断、M5 推演、M6 条件前瞻与反方审查者；调用前读完 anchors 所列完整原文小节。

## 适用对象

- 用于表面稳定与实际承接、恢复或写回背离；分别记录公开输出及末端成本，避免用一个均值判定。〔派生，待确认〕

## 触发观察

- 核查原文判据「建立表面/实际双账本」。〔原文 §8.4〕

## 生成的路径

- 比较真实稳定、支持下真实功能修复、成本转嫁维持表象和信息遮蔽；每项功能可有不同结论。〔派生，待确认〕

## 时钟与时延

- 覆盖当前运行、维护欠账和支持到期窗；仍在支持下运转不等于假恢复。〔派生，待确认〕

## 早期信号

- 输出不变但加班、借调、延迟休整和积压上升；投诉减少同时退出受阻或匿名渠道失效。〔派生，待确认〕

## 反向信号

- 独立末端记录显示维护、余量、退出和恢复持续有效，且不存在转嫁时撤回虚稳态候选。〔派生，待确认〕

## 竞争解释

- 与 S5/S6 的替代承接与持续写回比较；把必要支持、主动降载及口径变化列为竞争解释。〔派生，待确认〕

## 不能推出的结论

- 不能仅凭低波动或依赖支持推定欺骗，不能用未来新失败抹去此前准确限定的成果。〔派生，待确认〕
