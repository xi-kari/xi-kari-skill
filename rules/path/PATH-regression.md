# 相对自身基线的功能回退

派生使用卡。读取者：M2 状态判断、M5 推演、M6 条件前瞻与反方审查者；调用前读完 anchors 所列完整原文小节。

## 适用对象

- 保持同一个同一性判据、目标功能及人群口径，与对象自己事先定下的基线比较；不同对象排名不作为回退证据。〔派生，待确认〕

## 触发观察

- 核查原文判据「主动降载、“有序退场与良性消亡”（§8.5）或功能转移，都不是回退。」。〔原文 §8.4〕

## 生成的路径

- 分开突发、渐进、临界和级联回退；同时保留主动减载换取恢复及功能转移的竞争路径。〔派生，待确认〕

## 时钟与时延

- 比较相同负荷和恢复阶段；将短时停机维护与跨窗功能衰退分开。〔派生，待确认〕

## 早期信号

- 在可比扰动下，返工、等待或恢复时间开始增加，且维护缺口逐步触及已写明的功能。〔派生，待确认〕

## 反向信号

- 输出下降来自主动降载、有序退场或功能转移（功能已在新承接方连续运转）时，这些情形本身不是回退，撤回回退路径；是否确属这些情形按材料核对（如降载之后质量、休整和余量的变化），另有功能相对自身基线退化的材料时，退化的部分照记。〔派生，待确认〕

## 竞争解释

- 资源流失、测量口径变化和用户构成变化都可制造回退外观；不从结果差异直接选择原因。〔派生，待确认〕

## 不能推出的结论

- 不能推出成员道德堕落、必须扩张，或以恢复为名要求额外牺牲。〔派生，待确认〕
