# 不同位置的并行状态

派生使用卡。读取者：M2 状态判断、M5 推演、M6 条件前瞻与反方审查者；调用前读完 anchors 所列完整原文小节。

## 适用对象

- 只在位置差异可稳定映射、各子系统可独立追踪时用；同时留联合对象与子对象边界。〔派生，待确认〕

## 触发观察

- 核查原文判据「各子系统分别留 K、证据和退出条件。」。〔原文 §8.4〕

## 生成的路径

- 生成差异保持、跨位置传播、局部重构及真正分裂；每个位置可有不同退出条件。〔派生，待确认〕

## 时钟与时延

- 各子系统按自己的时钟更新；中心当周变化不刷新末端尚未观察的状态。〔派生，待确认〕

## 早期信号

- 中心与边缘在相同口径下反复出现不同承接、恢复和写回表现。〔派生，待确认〕

## 反向信号

- 拆分边界轻微移动就使差异消失，或差异全由采样时间不同造成时收窄并行判断。〔派生，待确认〕

## 竞争解释

- 混合可能位于同一子系统内部；split 需新 K，行政分组并不足够。〔派生，待确认〕

## 不能推出的结论

- 不能将某一个子系统的成功或授权外推给整个集体。〔派生，待确认〕
