# 局部世界模型协议

局部世界模型是针对当前问题的最小充分表示，不是把整个世界或所有 v8.3 术语装进答案。它可以在内存中完成，也可以在用户明确要求审计时按 schema 导出。

## 建模顺序

### 1. 对象与同一性

写出候选对象、暂定边界、内外接口、状态变量和同一性条件 `K`。说明对象是用户命名、观察构造、制度角色还是待验证的集合。名称、标签和统计聚合不能单独证明对象真实存在。

### 2. 行动者与圈层

分别记录可识别行动者、受影响位置、观察者和可能的圈层。对每个圈层写成员标准、角色、关系方向、代表/委托证据、时间窗口、桥接通道和未解释残差。正式成员、实际参与和代表授权不能互相替代；群体名不自动产生共同意志。

### 3. 尺度剖面

只保留实际增加解释力的尺度：个体、互动、组织、制度、网络、长期或其它明确层次。对每次跨尺度转换写保持项、改变项、丢失项、误差、载体和权限边界。观察范围扩大、影响范围扩大或中心性增加都不自动扩大授权。

### 4. 状态与通道

把可观察状态、物质/资源通道、信息/意义通道、反馈接收者、延迟、容量、损耗和恢复分开。事件只更新被真实通道触达的字段；没有桥、执行或写回证据时，不把相关性写成跨层因果。

### 5. 时钟与窗口

至少检查即时、互动、组织、制度和长期时钟中实际相关的部分。为每个重要变量记录观察窗口、滞后、持久性和回收条件。短期反应不等于长期特征，制度文本也不等于本地执行。

### 6. 证据与未知

逐项区分：已观察、用户材料、外部来源、来源主张、模型推断、不可观察、未收集、受保护不披露和冲突。`unknown`、`not_observable`、`withheld_for_protection` 不能被当成“没有发生”或“同意”。

### 7. 残差与复杂度闸

列出当前简单基线解释不了的残差、竞争解释和证据缺口。只有新增圈层、变量、尺度或算子能通过可观察通道减少残差或区分预测时才保留；否则回退简单模型并标记未决。

### 8. 上限

在模型末尾冻结本轮能作出的事实判断、前瞻判断、规范判断和行动/授权上限。模型越丰富不代表结论越强；任何上限变化必须由新证据、有效授权或用户明确任务改变。

## 最小内部记录

```yaml
task_kind: explain | compare | forecast | choose | express | static
object_candidate: {name, boundary, interfaces, identity_criterion}
actors: []

scale_profile: []
clocks: []
event_window: {start, end, timezone, evidence_cutoff}
evidence_items: []
unknowns: []
residuals: []
action_limits: []

```

## 质量闸

未冻结对象、身份、时间窗、证据截止点或受影响位置，不进入中心判断。若模型无法比简单基线多解释任何可观察残差，直接回答或说明不可判断，不制造多圈层结构。
