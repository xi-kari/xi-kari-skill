# D.04 Systems, Control, Feedback, Resilience, and Time Lags {#section-d-04}

In the main text, see §3.3, §4.5–4.6, §5.5, §6, and §12.6. Research entries cover 04.01–04.12.

A system representation is valuable when it links stocks, flows, feedback, delays, constraints, and boundaries to a specific object. Feedback requires only that a return affect a subsequent state. It does not guarantee accurate information, a timely response, or a beneficial outcome. An organization learning a practice, an emergent pattern in a system, insufficiency of the current representation, and cross-scale causation are four judgments that require separate evidence.

Observability and controllability must be assessed relative to the task. In a linear example, let O be the observation operator and Lx the target quantity. To identify the target, it suffices that unobservable directions leave the target unchanged, meaning every direction in ker(O) lies in ker(L). Reconstructing the full state need not be necessary. The rank of a control matrix can describe reachability in an ideal model. It does not guarantee execution under actual time limits, input bounds, resources, and permissions.

The same network diagram can give different propagation patterns under different response rules. Delays can stop a process with deadlines, forgetting, or resource depletion. In the special case of unlimited waiting, monotonic accumulation, and no forgetting, delay need not change the final reach. Resilience describes the maintenance of a particular relation or function. It does not automatically establish that the institution maintained is normatively justified, or make a return to the previous state the only goal for people’s lives.

A teaching model of stocks helps distinguish a temporary balance of flows from sustainable capacity. A shrinking backlog still calls for checking whether it reflects lower demand, greater processing capability, a change in the statistical boundary, or outsourcing of tasks. A short-term overshoot does not identify all time lags from the curve alone. General adaptation and learning can still occur when the current state captures the relevant history. Feedback-mediated learning through a carrier and learning with a historical increment are judged separately.

The capability to act also requires checking joint feasibility. Two tasks that each require one unit of capacity and have deadlines in the same period can each be feasible on their own, yet cannot both be completed with total capacity of one in that period. Adding capacity or legitimately staggering the deadlines changes feasibility. When one observation corresponds to several states, the existence of a correct action for each state does not guarantee a common available action when those states cannot be distinguished. Investigation, scheduling, and feedback should serve strategies that can actually be carried out.
