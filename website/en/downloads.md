# Downloads and citation

**Xikari: On Conditions, Structure, and Transformation**, by Xikari, theory v2, November 2026. The English reference edition translates the Chinese v2 text of 16 November 2026 and preserves its numbered sections and part anchors. The Chinese text has since been reworded, with the same structure and section numbers. The Chinese governs where the two differ.

This translation and the reading notes follow the Chinese v2 text of 16 November 2026. The current Chinese text changes only the wording: its sentences are plainer, and each code now stands at the end of the heading that defines it and in a table in Appendix B. Its parts, sections and section numbers are those of v2.

The Word file is an earlier v1 artifact, **not a v2 Word edition**. Use the Markdown files or the current [English reading pages](/en/theory/) for the revised theory.

The English reading edition normalizes the supplied translation for navigation and preserves its translator’s notes. Those notes are identified as translation notes, not additional statements by the author. The original supplied file is separately available for comparison.

## Cite a source section

Include the author, title, theory version, section number, language/edition, and the section link. For example:

> Xikari, *On Conditions, Structure, and Transformation*, theory v2 (November 2026), §3.3, English reference edition.

The link to [§3.3](/en/theory/part-03#section-3-3) opens the same numbered section as the [Chinese source](/theory/part-03#section-3-3). For a case’s factual claim, cite the report or study linked from the case page. The site’s guides are derived reading aids and should not be quoted as the author’s original definitions.
