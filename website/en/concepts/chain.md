# Two effective links can still fail as a whole

An intervention changes an intermediate variable. Changing that variable also affects an outcome. It is tempting to multiply those two average effects. The missing question is whether **the same units respond along both links under compatible conditions**.

## The book’s finite counterexample

Let two equally weighted types be s = 0 and s = 1. Set the mediator to m(a) = a(1 − s) and the outcome to y(a,m) = sm. In type 0, treatment changes the mediator but the outcome does not respond to it. In type 1, the outcome responds to the mediator, but treatment does not change the mediator.

The treatment-to-mediator average effect is 1/2. The mediator-to-outcome average effect is also 1/2. Yet the treatment’s effect through the whole chain is zero for both types. Multiplying the averages gives 1/4 and loses the response correspondence.

This is a mathematical counterexample under specified functions, not a measured population effect. It rejects unconditional multiplication. It does not cancel a total effect independently identified by a suitable study, nor require every total-effect study to identify every microscopic mechanism.

## Three different composition questions

| Question | What must be checked |
| --- | --- |
| Do successive representations preserve the same final answer? | The distinctions needed for that final query, across the actual reachable representations. |
| Do causal links support the effect of the chain as a whole? | Same-case correspondence, joint responses, common support, timing, capacity, and the endpoint. |
| Can individually feasible tasks be executed together? | Shared resources, locations, deadlines, and valid permissions. |

The [Mars Climate Orbiter case](../cases/mars-climate-orbiter) concerns a documented unit-interface failure. It is not an empirical instance of the two-type causal counterexample: NASA’s report did not estimate the two average effects above.

A person can really acquire skills while the local labor market offers no relevant job. Preserving the learning result helps identify the missing employment connection; neither the successful first step nor the unsuccessful endpoint should erase the other.
