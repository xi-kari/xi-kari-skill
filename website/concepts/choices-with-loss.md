# 所有方案都有损失，怎样给出建议

公开采用的规则、未满足的要求和责任；等待有代价也不产生权限。

有时行动、等待和维持现状都会留下不可逆损失。此时只列问题、把暂停当成无代价去处，仍然遗漏了一项选择。[§14.9.1](../theory/part-14#section-14-9-1)要求在证据和明示规范前提允许范围内，给出供审议的有限判断。

推荐应写清所选方案及其依据的规范前提、决策规则及提出者与采用者、谁承担损失、哪些要求仍正当、谁继续减害和补救，以及何时因新证据、资源或权限重评。规则有争议时，并列给出不同规则下的判断；公开规则并不使它自动合格。

教学情景：一名夜班护理员同时面对两位需要协助、延误均有风险的住户。依“危险更迫近者先处理”的公开规则，可以形成当前推荐；另一人的需要不会消失，机构仍需说明损失和补救，并审查为何只配一名护理员。有限场景不直接认定护理员失职。

“别无选择”必须接受反问：稀缺由谁控制？是否来自可质疑的先前决定？是否因为决定者不愿承担成本而删除了方案？权限不足时是否已提交有权限者？这些理由可以申诉，并交独立于决定者的复核。

不可豁免的法律和保护事项不会因所有方案都有损失而失效。若主张连这些事项也无法同时保全，须写明相互冲突的是哪几项、已经排除了哪些方案及其依据，由独立于决定者的复核认定；认定不成立时，回到不越过这些事项的方案；认定成立时，框架仍不以“获准”为任何方案背书，仍可保全的保护继续适用。现实决定须依独立的法定或紧急权限，受最窄范围、到期和事后复核约束。

作出选择不消除受损者要求。这里的有限，是结论的条件清楚、责任继续存在，而不是把建议缩成含糊的提醒。
