# 每件事都做得到，为什么放在一起就做不到

两项任务各自可行，排成同一份计划会发生什么？

**方案共享时段和容量，单独可做不等于能够共同完成。**

## 从具体情景看区别

原文给出两项单位任务：每项都要占用一个完整时段，而且都必须在第一期结束前完成；第一期的容量却只有1。拿出任何一项单独看，资源都足够，两项同时进入计划，就没有满足原截止时间的排程。将同期容量增加到2可以改变结果；若允许把一项截止时间合法改到第二期，并且第二期有容量1，也可以得到另一种可行安排。

但保留原来的两个截止时间、只在第二期增加容量，并不能补回已经错过的第一期。这一例子帮助读者把“总资源看起来够”和“资源在要求的位置、时间可用”区分开。它也提醒我们，改变期限是改变条件，不能在事后悄悄换成新的成功标准。

## 总时数之外，还要看可用整段

v2的[§7.3.9](../theory/part-07#section-7-3-9)补充了一个可行性条件：若任务需要连续时段，总空闲时间相同的人仍可能有不同机会。默认联系人、待命和临时补缺责任，会把可用时间切碎；即使实际呼叫很少，也可能无法安排一段可预期的学习或休息。

教学情景：一项练习必须连续两小时完成。一人有固定的两小时，另一人总计也有两小时却只有不可预知的短间隙。总量相同不使方案同样可行。分别记录整段长度和可预期性，不把连续性再折成时数与已经记录的工时相加。

## 另一个问题：信息不全时，有没有对各种可能都合格的动作

[附录C.12](/theory/appendix-c#section-c-12)的共同可行动作命题（F3）讲的是相关但不同的问题。设观察之后还剩两个可能的状态：一个状态下合格的动作只有{左}，另一个只有{右}。两个状态各自都有办法，合格集合的交集却是空的，仅凭这次观察选出的任何一个动作，都不能对两个状态都合格。

如果两个状态都允许一个已经获得授权的保全动作，交集就可以非空，而状态仍然没有被完全识别。追加观察也可能有帮助，但它的代价、及时性、风险和能否取得都要另行评估；继续调查不会自动免费，也不一定有用。

| 主张 | 须核对 |
| --- | --- |
| 每项任务单独可做 | 各项任务自身的约束 |
| 全部任务可以一起做 | 联合起来的资源与截止约束 |
| 信息不全时仍有一个动作可行 | 所列各个相容状态有没有共同的合格动作 |

命题里的合格集合，必须已经把任务所要求的资源、保护和有效权限算进去；在数学上写出一个动作，不能代替这些现实条件。

## 这处区别能说明到哪里

这是由给定约束成立的原文教学例，不认证现实需求或容量。现实中的加资源、改截止时间和执行安排，还须有相应事实依据与权限。
