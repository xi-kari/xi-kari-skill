# 受影响的位置要找到哪里

必须列全的位置与更远影响的相称追踪分开，未知仍可能阻断采用。

间接和代际影响可以不断延伸。说“已经考虑所有人”而不说明界线，既无法核查，也让被遗漏者无从质疑。原文[§14.4.1](../theory/part-14#section-14-4-1)给出两层识别责任。

**必须全部列出**直接受影响位置、已知或经他人指出的低权力位置，以及应用模块要求单列的位置。其余位置沿已经说明的通道和九个尺度轴追踪；损害越重、越不可逆、人数越多、越可能累积，位置权力越低，追踪就应越远。

继续追踪已不能合理改变判断、方案比较或保护安排时，可以停止，并公开界线、查过的通道、问过的位置和未知。他人指出新通道时，纳入或说明不采纳理由。不能让受益于较窄界线的一方独自定界：依据要事前公布，可以申诉；高影响或存在利益冲突时须独立复核。

| 未知类型 | 对采用的影响 |
| --- | --- |
| 有合理依据可能暴露保护失败或改变比较 | 阻断相应采用部分，补证、缩小方案或提供另有依据的保护 |
| 其余未知 | 如实记下，并设定观察和重新识别的条件 |

教学情景：服务调整影响现有使用者，也已有人指出无证件者可能被漏掉。不能把后一位置丢进“间接影响太远”的箱子。遥远后果可按风险追踪，但不行动造成的既有损失也必须进入同一审查。

后来识别到的人拥有同等申诉、纠正和补救入口，不需先证明自己本来可被预见。识别范围的界线不会减轻已识别者的保护，也不能成为拖延已知伤害保护的理由。
