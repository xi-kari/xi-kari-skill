# 为什么越来越依赖同一个人

配置塑造能力、能力再影响配置是一条候选链，需要至少两轮材料。

关键任务每次都交给熟手，眼前完成率提高；别人始终缺少练习，后来更难接手。也可能先限制某些人的机会，再用形成的能力差距解释下一次排除。[§7.6.1](../theory/part-07#section-7-6-1)提出的是可反驳的候选机制。

链条为：**配置任务与机会 → 实际练习 → 能力形成 → 下一轮配置**。主张本案成立，至少检查两轮、可定位的配置决定、能力确实依赖实践形成、实践主要经由该配置取得、后一轮是否实际依据能力，以及差距或集中程度是否比起点扩大。能力的形成、保留与调用按§4.5取证；申请正式的机制支持时，另按结论规则“人类承接与跨期再生产”（§4.13.3）的载体路线取证。

竞争解释包括原有差距、报酬、权限、长训练周期、外部认证、选择或流失、一般稀缺，以及借能力话语掩饰偏好或利益。不能只因分配理由写着“能力”就当作因果证据。

教学情景：乙获得相称培训后达到与甲相当的能力，任务仍全部给甲。这可能提示其他排除机制，却削弱了“后续配置确因能力不同”这一段。应修订命中的链段，不能把反例改名为机制更强。

训练资源和交接条件应事前写明、可独立检查，观察窗口须匹配形成能力所需时间；资源同样紧张而配置规则不同的单位，可以提供进一步比较。得到不利结果后才说条件“不真实”，不能挽救旧主张。

机制即使成立，也不证明恶意、不可逆或先前成果无效。怎样调整配置、谁负担培训与冗余成本，仍是规范与权限问题。
