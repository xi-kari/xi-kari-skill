# 问题已经固定，还能重新提问吗

旧结果保留，新问题有理由地另立；把问题固定下来，不取消受影响者对定题的质疑。

预先说好怎样算成功，才能诚实评价结果。问题是：原先没被算进来的人，是否从此不能质疑目标、成员边界或损失定义？

原文[§2.14](../theory/part-02#section-2-14)同时保留问题的固定与重开。重开可以因为现有表示不足以回答原问，也可以因为原问题本身遗漏利益、成员、损失或把可改变的约束当成给定。

教学情景：一项排班只以服务数量为目标，数量达标后，有人指出连续待命切断了照护与休息时间。原服务数量结果仍然成立；新的负担问题需要另立并核对材料。不能为维护旧目标而抹去负担，也不能因此把已达标的数量改写成没有发生。

重开应保留提出者、理由、处理依据和旧结果，说明新旧问题是替代、并列还是细化。即使请求被拒绝，也要留下理由和可质疑的入口。分析者可以并列回答；属于制度内部的指标、资格、议程或资源配置，是否修改仍由有相应权限的程序决定。

如果只是因为失败而把截止日期延后，就不能称旧计划成功。结果可以暴露真正的遗漏，却不能自动成为任意换题的许可证。新任务成功与旧任务完成是两项结论。
