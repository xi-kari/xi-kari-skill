## 8.1　本部分解释什么 {#section-8-1}

七种状态原型（§8.3）只适用于人类有意图集体：人们围绕可以表达的共同问题、承诺、目标或意义安排而形成，并通过角色、资源、规则、关系和反馈持续运作的团队、组织、机构、运动、共同体或治理安排。它们不是普遍适用的定律，不能直接套到个体人格、纯物理系统、物种演化或整个宇宙上。即使在适用的范围之内，七种状态原型也不是成熟度的阶梯，不是历史必经的序列，更不是价值的排名。

原型的编号只用来区分原型、方便检索。它允许我们问：“这个对象、这个子系统、这个时间窗，现在主要呈现什么结构构型？”它不允许我们说：“编号更大，所以人更好、制度更正当、文明更先进。”一个大型集体，可以中心是高效协调与弹性扩展原型，边缘是连通约束下的发展原型，技术单元是自适应动态平衡原型，而代际承接仍是生成核心奠基原型；同一项功能也可以同时呈现两种原型。遇到这种情况，应当记为“并行”或“混合”，而不是把复杂的情况压成一个“整体阶段”。

状态原型只产生描述性的、可以撤回的分类，不产生行动授权。任何现实的干预，都必须另外给出规范前提，通过结论规则“规范桥接”（§4.14.1），比较包括不行动在内的各个方案，取得逐项授权（§14.6），也就是同一项授权同时覆盖具体的主体、对象、动作、地域和期限，并接受操作程序、申诉和恢复原状的约束。状态的标签不能替这些要求中的任何一项作证。

## 8.2　状态判断的最低要求 {#section-8-2}

每一次判断，都先把这几样定下来：判断的是哪个对象，它的同一性判据，它在九个尺度轴上的尺度剖面（§5.2），时间窗，以及子系统的范围。然后分别记下入口条件、退出条件、可观察量、反例、证伪的结果和缺失的情况。分类模式只有四种：单一主导、混合、并行、未知。这里事先定下的，是本次分析用来追踪对象的判据，并不要求被观察的成员构成、实际边界、角色、承诺或自我认同已经稳定。如果需要改变同一性判据的定义，应当另立一份记录，保留原来的判据、材料和判断，使修改留有历史，并重新核对对象的同一性；核对完成之前，不把不同判据之下的记录直接接成同一个对象跨时间窗的路径。

| 项目 | 必须回答的问题 | 停止位置 |
| --- | --- | --- |
| 对象与同一性判据 | 我们追踪的是同一个人类集体，还是名称相同而对象已经变了？ | 同一性判据没有事先定下、无法凭它追踪对象，或同一性尚未核清时，先作对象与同一性的判断，不指定原型；成员或实际边界有变化，不自动等于同一性判据变了 |
| 尺度与时间 | 看到了哪些单位、空间、时间窗、层级、受影响的位置和网络？ | 观察范围扩大，授权范围并不随之扩大 |
| 入口与退出 | 什么材料使某个原型成为候选，什么材料使它不再主导？ | “像”一个原型，不等于已经进入或必然退出 |
| 可观察量 | 哪些行为、记录、通道、成本、恢复和写回能够被复核？ | 只有一句口号、一个总量或官方的自述，是不够的 |
| 反例与证伪 | 还有什么会造成同样的表象？什么结果会使判断撤回？ | 不主动寻找反证的标签，只能算印象 |
| 证据覆盖 | 哪些外部材料支持关于入口、观察和反证的判断？所引的证据能否对应到真实材料，并且覆盖当前的对象？ | 内部的定义、编号和框架自身的叙述，都不能代替关于对象的证据 |
| 缺失 | 是尚未收集、不可观察、不适用、来源冲突，还是未知？ | 不得把缺失补成“正常”“没有”或零值 |
| 规范与行动 | 这一分类是否给出了价值、义务或处置权？ | 所有状态都只是描述，不授权任何行动 |

五种缺失状态必须分开。“尚未收集”是指可以取得但还没有收集。“不可观察”是指在当前的权限、安全或测量条件下无法观察；不能为了填表而要求弱势的一方暴露自己。“不适用”必须经过适用性检查才能认定。“来源冲突”是指合格的来源互相冲突。“未知”是指已经尝试过，仍然不能区分。关键的入口、反证或尺度项目缺失，这件事本身只支持记为“未知”，或暂停相关的分类。记为“混合”或“并行”，都须有多个原型及其各自对应位置的正向证据；不得把无知改个名字叫作“混合”。已经成立的局部材料，仍按原来的范围保留。

### 8.2.1　每次判断的分类记录 {#section-8-2-1}

§8.3在每个原型之下列有一张诊断卡。诊断卡只有用在一次具体的判断上、写成一份各项齐备的记录，才构成可以复核的分类。这份记录必须把下面各项一并定下来：对象与同一性判据，九轴尺度，时间窗，子系统范围，分类模式，候选的原型，候选的路径，五类条件（入口、退出、观察、反例、证伪）的结果，缺失的数据，关于对象的证据，不确定性，独立复核，申诉，恢复原状，以及不授权行动这条边界。入口、退出、观察、反例和证伪的每一条结果，都按同一种方式写：针对哪个原型的哪一条，结果如何，依据哪些证据，理由是什么。结果必须逐条覆盖每一个候选原型，不能用一段总评代替。

四种分类模式各有要求。“单一主导”只有一个候选原型。“混合”与“并行”各自至少有两个候选原型，并且要明确写出对应的路径（§8.4）。“未知”不指定任何已获支持的原型，而必须说明哪些关键材料仍然不足以区分。已经成立的局部事实和对组件的观察，仍然保留在关于对象的证据里，不能因为总体上的原型未知就删去。记为“未知”时，如果候选原型名下没有地方放这些起支持作用的材料，应当把它们留在关于对象的证据和理由里，不为了安放它们而伪造一个完整的原型。

任何一个候选原型，至少要在入口和观察两方面有关于对象的证据。一旦某一条证伪条件成立，这个候选就被排除，不能靠把话说软继续留着。每次核对，都必须另外拿出记录之外的证据材料清单；记录里每一层引用的证据，既要对得上本记录所列的关于对象的证据，也要一层一层对得上这份外部清单里的真实材料。拿不出清单，只在总的结论处自称有据，或者引用了查无其物的材料，都不能通过。内部的编号、定义和自称的判断，不能代替关于对象的证据。

复核的记录要写明：由谁复核，是否独立，何时复核，依据的是哪一版材料，结论如何。复核者必须独立于被评价的对象；给对象换一个名字，不能使它成为自己的独立复核者。申诉和恢复原状，各自要对应到一个实际的程序，并写明这个程序当前的状态。这几项都不能只写一句“已复核”“可申诉”了事。无论复核的结果如何，分类始终只是描述，不授权任何行动。撤回或改写状态标签时，原来的证据、异议和修改的历史都应当保留。

本部分还引用另外四类内容，它们的作用各不相同。十一个基本结构概念（§3.5）提供描述对象、状态、通道、负荷和相位的概念。六项人类领域条款（§7.1）提供人类世界里关于意义、承接、制度写回、权力和历史载体的适配。四类经验问题（第四部分）指明什么时候必须用一次独立而合格的正式检验，才能把一种模式提升为经验上的机制。十二条结论规则（§4.10）限定推论在哪里停下。它们列在各张诊断卡的“相关概念”一行里，只是指向相关概念的链接，不是关于眼前这个对象的证据。

用七种状态原型描述配置，不以“相位与阈值转换”机制（§6.7）的多区间模式为前提。一个对象在已经观察的时间窗里始终满足某一个原型的必要条件，也可以得到相应的有限分类；这并不证明它曾经发生过相位转移。进一步主张多个区间、阈值或相位转移的机制时，再按“相位与阈值转换”机制和相应的正式检验来检查。反过来，两个区间的形式模式成立，也不直接证明对象符合某一个人类集体的原型。

### 8.3.1　锚点凝聚原型（S0） {#section-8-3-1}

锚点凝聚原型描述的是“候选集体正在形成”，不是“低级组织”。共同问题、候选目标或意义表达，开始把注意、关系、时间和少量资源聚拢起来；但成员构成、实际边界、角色、承诺的方式和共同身份的表达，都还在形成或变化之中。分析时仍须使用本次事先定下、可以据以追踪对象的同一性判据；形成过程中的状态变化，不能代替同一性的判断。至少有一个候选的生成行动者在反复地翻译、召集、试探，或承担真实的成本；独立的承接层还没有形成。候选集体可以在这里消散、休眠、并入别的安排，或转向新的目标。各条路径发生的比例，须有相应的机会总体和观察资料才能说，不能从原型的定义推定。过程结束本身，不构成失败的判决。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是在本次事先定下、可以据以追踪对象的同一性判据之下，共同问题或意义安排造成了看得见的局部聚集，但成员、实际边界或承诺方式尚未稳定；二是候选的生成行动反复出现，承接还很薄。 |
| 退出 | 一是在同一个同一性判据仍然适用、对象的同一性可以追踪的时间窗内，锚点、实际边界和生成角色跨时间窗稳定下来，并出现可以追踪的承诺和初步的承接，这时可以检验生成核心奠基原型；二是聚集消散、分裂、被吸收或进入休眠，不必经过生成核心奠基原型。原来的同一性判据不再适用时，另作对象转换或终止的判断。 |
| 可观察 | 互相竞争的表述仍在协商；资源的聚集伴随着频繁的进出；生成行动者承担翻译、召集或试错；失败的试探和备选的历史仍被保留。 |
| 反例 | 热点或平台的推荐能造成短期的同步；行政上的命名能造出形式上的团队。要观察奖励、曝光或命令撤除之后，承诺和对象的边界是否仍然持续。 |
| 证伪 | 与相匹配的临时聚集相比，共同方向、行动的聚集和生成角色都没有区别，就撤回这一分类。如果稳定的角色、承接和重复的运转早已存在，锚点凝聚原型也不是主导状态。 |
| 尺度 | 必须分清生成者、早期参与者、潜在的退出者和外部命名者；不能把个体的人格聚合成集体的状态。 |
| 证据升级 | 主张意义安排造成了资源、行动或协调上的差异，须有一次“意义与协调”检验（§4.2）；主张指定通道促成了形成，须有一次通道效应检验（§4.4）；历史留痕按“历史留痕载体”这项假设（§7.1）检验，当前载体今后的作用按§4.5取证；只有主张当前表示之外的历史增量，才追加历史增量检验。 |
| 相关概念 | 基本结构概念：候选对象；边界与接口；状态与可观察量；条件与环境；负荷、容量与恢复余量；相位、转移与解体。人类领域条款：意义与协调；行动承接与责任分型；历史留痕载体。经验问题：分组增益；通道效应；历史增量。结论规则：分组增益及其边界扰动稳健性；承载与通道约束；历史作用、路径差异与修复窗口；负荷、容量与恢复；人类承接与跨期再生产；规范桥接。 |

这个原型允许得出的结论，只是在特定的对象、尺度和时间窗内，情况与锚点凝聚原型相容。它不能证明参与者缺乏能力、价值或意愿，也不能授权扶持、解散、筛选或排除。

### 8.3.2　生成核心奠基原型（S1） {#section-8-3-2}

在生成核心奠基原型中，候选锚点、对象的边界和至少一个生成角色，已经能够跨越多次决策被重复识别；基本的规则、语言、资源通道和最早的记忆载体开始奠基。主要的翻译、决策、资源动员、冲突处理或关系修复，仍然集中在一个或少数几个生成角色身上，独立的承接者很少。这种中心性是结构上的依赖，不是领导正当性的证明。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是同一性判据、锚点和生成角色可以重复识别；二是关键功能持续依赖生成核心，而不是一次紧急情况下的集中。 |
| 退出 | 一是新进入者形成了持续的承接、责任和边界接口，这时可以检验首次扩展与承接分化原型；二是生成核心分裂、退出、被接管、休眠，或对象消散，转入相应的路径。 |
| 可观察 | 锚点和边界初步稳定；关键决策依赖生成核心；规则和记忆载体开始重复出现；外部的进入有限而且定向。 |
| 反例 | 成熟的组织可能仍由创始人公开宣布决定，而实际的承接层已经很庞大；行政上新设的部门，也可能只是上级对象里的一个角色单元。要追踪实际的执行、停止权、反馈，以及核心暂时离场之后的运转。 |
| 证伪 | 生成核心介入程度低时，多中心的承接仍然稳定运转，核心依赖就被反驳了。如果锚点不稳定，但同一个同一性判据仍然适用、对象可以追踪，可以重新检验锚点凝聚原型；如果原来的同一性判据不再适用，或对象的同一性不明，应当先检查对象转换或终止，或者保持“未知”，再对可以识别的对象分类。 |
| 尺度 | 事先定下谁是生成角色、早期承接者、上级命名者和外部支持者；组织图与实际通道相冲突时，记为“来源冲突”。 |
| 证据升级 | 锚点的结果效应需要一次“意义与协调”检验（§4.2），生成核心的结果效应需要一次通道效应检验；早期制度或创伤经由载体产生的效应按§4.5取证，留痕按“历史留痕载体”这项假设（§7.1）检验，历史条件残差另作历史增量检验。 |
| 相关概念 | 基本结构概念：候选对象；边界与接口；状态与可观察量；组件、载体与基质；流、通道与传导；反馈与状态更新；负荷、容量与恢复余量；相位、转移与解体。人类领域条款：意义与协调；行动承接与责任分型；制度写回；权力、中介与反身性。经验问题：分组增益；通道效应；历史增量。结论规则：分组增益及其边界扰动稳健性；承载与通道约束；有效反馈与反馈介导学习；负荷、容量与恢复；观测通道与反身响应；人类承接与跨期再生产；制度写回；规范桥接。 |

这个原型不能被读成“幼稚”“落后”或“应被整合”。它也不能赋予生成者永久领导、扩大权力、强制建制或替换他人的资格。

### 8.3.3　首次扩展与承接分化原型（S2） {#section-8-3-3}

首次扩展与承接分化原型描述的是边界、成员、服务对象、地域、平台接口或协作网络的持续扩展。新进入者带来不同的理解、技能、资源和风险；在生成核心之外，开始形成承接的位置、退出的位置、保留异议的位置和尚未决定如何参与的位置。扩张既可能提高协调能力，也会增加翻译、反馈、恢复和权力方面的问题。有分歧本身不是失稳；只有可以观察的机制持续阻断承接、反馈或恢复，才谈得上结构问题。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是至少有一类边界在持续扩展，并且改变了关系；二是在生成核心之外，出现了可以区分的承接位置、成本位置、退出位置和未决位置。 |
| 退出 | 一是反复出现的负荷和压力形成了连通的约束，持续分割通道，这时可以检验连通约束下的发展原型；二是扩展停止、回撤、跳跃、分裂、合并、接管、休眠或崩解。 |
| 可观察 | 进入、退出和接口的构成发生变化；角色与责任分化；反馈量、翻译成本、时滞和恢复需求发生变化；认同、异议、退出和安全被分别记录。 |
| 反例 | 人数或用户数增长，不一定改变结构；冲突公开，也可能是表达安全得到改善，使旧问题终于看得见。 |
| 证伪 | 统计口径固定之后，增长不能持续，并且没有改变边界、角色、责任、接口或负荷，就撤回这一分类。所谓的分化如果只来自中心单方面贴的标签，也应撤回。 |
| 尺度 | 整体、中心、新承接者、退出者和被外部化的成本必须同时纳入；观察范围扩大，对新成员的授权范围并不因此扩大。 |
| 证据升级 | 主张扩展或通道造成了结果上的差异，须有一次通道效应检验，并满足因果主张的条件（§2.4）；跨尺度的判断另外要写出尺度变换（§3.4），并通过认识论约束“跨尺度迁移检验”（§4.8.5）；主张闭合或转换的，另作尺度闭合检验（§4.6）；锚点的协调作用须有一次“意义与协调”检验（§4.2）；表达、公开和权力方面的观测效应须有一次“权力、中介与反身性”检验；历史留痕须有一次“历史留痕载体”检验，载体的传递按§4.5取证，历史条件残差另作历史增量检验。 |
| 相关概念 | 基本结构概念：候选对象；边界与接口；状态与可观察量；组件、载体与基质；流、通道与传导；反馈与状态更新；条件与环境；负荷、容量与恢复余量；相位、转移与解体。人类领域条款：意义与协调；行动承接与责任分型；制度写回；权力、中介与反身性；历史留痕载体。经验问题：分组增益；通道效应；历史增量；尺度闭合。结论规则：分组增益及其边界扰动稳健性；承载与通道约束；有效反馈与反馈介导学习；历史作用、路径差异与修复窗口；负荷、容量与恢复；尺度闭合与对象转换；局部改善与跨边界溢出；观测通道与反身响应；人类承接与跨期再生产；制度写回；规范桥接。 |

这个原型不允许把不认同者、退出者或模糊参与者本身称作负向主体，也不允许用“扩维需要”来授权统一思想、限制退出或清退异议。

### 8.3.4　连通约束下的发展原型（S3） {#section-8-3-4}

在连通约束下的发展原型中，集体仍在运转或发展，但多个反复出现的约束已经彼此连通：审批、资源、信任、责任、信息、平台或外部依赖，形成互相放大的瓶颈，持续分割反馈、承接、恢复或成本的回流。这里的关键不是“问题很多”，而是这些问题能否形成一个可以复核的连通结构；也不是把某个人叫作壁垒。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是至少有两类约束相互强化，并且跨时间窗影响通道；二是运转仍在继续，但末端的承接、反馈、资源或恢复持续承担额外的负荷。 |
| 退出 | 一是关键的关系、权限、资源或接口开始实际重构，这时可以检验结构重构窗口原型；二是转入回退、虚稳态、休眠、接管、强制重写、迁移或崩解。 |
| 可观察 | 约束的网络和瓶颈；仍有输出，而损耗、返工和隐性劳动在增加；修复反复启动却不写回；中心与边缘、指标与承接、名义与实际持续分裂。 |
| 反例 | 高风险环境里保护性的分层和冗余，可能提高可靠性；主动降载来重构，也可能暂时放慢产出。必须检查这些限制是否阻断了必要的反馈，或者是否提供了错误隔离和替代路径。 |
| 证伪 | 排除了共同输入、测量偏差和短期峰值之后，约束之间没有连通关系；或者承接末端的替代通道、写回和恢复持续有效。出现其中一种情况，这个原型就不是主导。 |
| 尺度 | 必须把中心、边缘、功能单元、承接末端和外部受影响的位置拆开来看，允许记为“并行”。弱信号消失了，不能当作问题消失了。 |
| 证据升级 | 主张权力或中介造成了遮蔽，须有一次“权力、中介与反身性”检验（§4.2）；主张指定通道及其相互强化，须有一次通道效应检验；由历史形成的当前约束按§4.5取证，额外的历史残差作历史增量检验；主张跨尺度的闭合失败，须有一次尺度闭合检验。 |
| 相关概念 | 基本结构概念：边界与接口；状态与可观察量；关系与约束；流、通道与传导；反馈与状态更新；条件与环境；负荷、容量与恢复余量；留痕、记忆与路径；相位、转移与解体。人类领域条款：意义与协调；行动承接与责任分型；制度写回；权力、中介与反身性；历史留痕载体。经验问题：通道效应；历史增量；尺度闭合。结论规则：承载与通道约束；有效反馈与反馈介导学习；历史作用、路径差异与修复窗口；负荷、容量与恢复；尺度闭合与对象转换；局部改善与跨边界溢出；观测通道与反身响应；人类承接与跨期再生产；制度写回；规范桥接。 |

归入这个原型，不能授权“打壁垒”、清洗、接管、强制改革，或把过渡的成本交给弱势位置。它只说明，应当继续区分约束网络和竞争解释。

### 8.3.5　结构重构窗口原型（S4） {#section-8-3-5}

结构重构窗口原型说的不是“改革已经正确”，而是关键结构确实处在重构的窗口：旧的关系、权限、资源通道、反馈写回或边界接口，正在被拆解、替换或绕开；新旧安排并存；随之而来的是转换成本、重复劳动、知识迁移、短期产出下降，以及恢复需求的上升。结果仍然是开放的，可能改善，也可能停滞、异化、强制重写或崩解。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是至少有一个关键要素实际发生了改变，不只是改名或宣传；二是新旧安排并存，过渡成本可以追踪，同一性判据持续得到核对。 |
| 退出 | 一是通道、反馈、承接和恢复跨时间窗得到改善，并且没有隐藏的外包，这时可以检验高效协调与弹性扩展原型；二是新结构不可用，转入休眠、回退、接管、强制重写、虚稳态或崩解。 |
| 可观察 | 权限、资源、角色、责任和停止条件得到真实的写回；双重系统和转换成本；缓冲、冗余、冷却、停止和恢复原状；多个位置上的结果进入真实的反馈。 |
| 反例 | 大规模的改名、换人或重画流程图，可能只是象征性的改革；拆旧、过载和产出下降，也可能是破坏性的清洗或资源抽离。 |
| 证伪 | 实际的关系、权限、资源和执行都没有改变，就撤回这一分类。没有可用的新结构、功能又持续断裂时，也不能把这个过程包装成改善性的重构。 |
| 尺度 | 变更之前的基线、过渡、冷却、恢复原状和恢复这几个时间窗都要覆盖到；改革的发起者、执行者、承接者和成本承担者要分开。 |
| 证据升级 | 主张重构导致了改善或伤害，须有一次通道效应检验，并满足因果主张的条件（§2.4）；主张对象转换或干预转换，须有一次尺度闭合检验；失败的尝试是否经由当前载体影响未来，按§4.5取证，额外的历史残差另作历史增量检验，不能用“隧穿”的类比代替。 |
| 相关概念 | 基本结构概念：状态与可观察量；关系与约束；流、通道与传导；反馈与状态更新；负荷、容量与恢复余量；留痕、记忆与路径；相位、转移与解体。人类领域条款：意义与协调；行动承接与责任分型；制度写回；权力、中介与反身性；历史留痕载体。经验问题：通道效应；历史增量；尺度闭合。结论规则：承载与通道约束；有效反馈与反馈介导学习；历史作用、路径差异与修复窗口；负荷、容量与恢复；尺度闭合与对象转换；局部改善与跨边界溢出；观测通道与反身响应；人类承接与跨期再生产；制度写回；规范桥接。 |

“过渡谷地”最多是一个有待检验的描述，不能为无限的代价、不可逆的伤害、取消申诉或牺牲低权力位置提供正当性。这个原型不产生拆除、清洗或强制迁移的行动授权。

### 8.3.6　高效协调与弹性扩展原型（S5） {#section-8-3-6}

高效协调与弹性扩展原型描述的是：在当前的环境和时间窗内，资源、信息、反馈、责任、承接和恢复这几条通道能够以较低的损耗协同；局部的扰动通常不能形成持续的连通壁垒；边界的扩展与收缩比较有弹性。这种状态仍然可能是由资源红利、成本外包、沉默、指标漂白或制度漏洞伪造出来的。所以，高产出不是充分的证据，长期存续也不是正当性的证明。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是关键通道跨时间窗保持低损耗、可以替代、可以写回；二是扩展、存护与消解相互协同，并且不靠封闭反馈或压制异议。 |
| 退出 | 一是分布式的承接、自我更新、恢复和新的生成跨扰动成立，这时可以检验自适应动态平衡原型；二是漏洞、异化、虚稳态、回退、功能转移、“有序退场与良性消亡”（§8.5）、接管或崩解，使它不再主导。 |
| 可观察 | 替代的承接和通道真实可用；产出、反馈、恢复和维护同时保持；边界的开放、保护和退出可以执行，成本回流；对漏洞的核查能够写回。 |
| 反例 | 资源繁荣、选择性的指标、投诉渠道失效、出于恐惧的服从，或把维护债推到未来，都能造出“成功”的外观。 |
| 证伪 | 把维护、恢复、退出和外部成本纳入之后，效率优势消失；或者中心介入程度低时，局部故障迅速级联。出现其中一种情况，就撤回这一分类。 |
| 尺度 | 管理层的总量必须拆到维护者、低权力的承接者、退出者和外部受影响的位置；时间上要覆盖高负荷与低负荷、扰动、恢复和维护的时间窗。 |
| 证据升级 | 高效协调的成因和漏洞的效应，须有通道效应检验，以及“权力、中介与反身性”检验（§4.2）；历史留痕、载体的持续作用和额外的残差，分别按“历史留痕载体”这项假设（§7.1）、§4.5和历史增量检验处理；跨尺度的复制，须有尺度变换的映射（§3.4），通过认识论约束“跨尺度迁移检验”（§4.8.5），并有目标一方的独立证据；主张闭合或转换的，另作尺度闭合检验。 |
| 相关概念 | 全部十一个基本结构概念。人类领域条款：意义与协调；行动承接与责任分型；制度写回；权力、中介与反身性；历史留痕载体。全部四类经验问题。全部十二条结论规则。 |

这个原型不是“善”“成熟”或“可以输出模式”的标签。存续、增长和筛选不等于正当，也不能授权扩张、复制、接管，或要求成员增加承担。

### 8.3.7　自适应动态平衡原型（S6） {#section-8-3-7}

自适应动态平衡原型描述的是：集体具有分布式的承接、有效的反馈，以及恢复、更新和新生成的能力。常规的波动不会长期锁定方向；自治单元能够在局部自行稳定、横向协同，并得到上级的兜底；候补梯队、岗位记忆、授权和交接，使后来者能够真正进入并修改旧的安排。它靠持续的校准来维持功能，而不是消灭波动。

| 检查面 | 内容 |
| --- | --- |
| 入口 | 一是中心介入程度低时，多个位置仍然能够感知、纠错、恢复和写回；二是新的承接者、规则和边界可以持续更新，不依赖同一批不可替代的个人。 |
| 退出 | 一是恢复变慢、波动放大、写回失效、依赖中心或承接断裂，转入回退等路径；二是使命结束、功能转移、分裂、合并、范式替换，或“有序退场与良性消亡”（§8.5），改变了对象的界定。 |
| 可观察 | 扰动之后的恢复和二次失稳；多中心的协同与兜底；新承接者从受训到真正接手；反馈、核查、申诉和规则修订持续闭环。 |
| 反例 | 强控制、弱信号消失、资源保护或中心暗中救火，都能造成低波动；频繁换人和改组，也可能只是把人员当作耗材。 |
| 证伪 | 在可比的扰动之下恢复持续变慢，局部故障级联，纠错依赖单点，或者继任者得不到知识、权限和保护，就撤回这一分类。 |
| 尺度 | 需要横跨扰动、恢复、继任和慢变量的长时间窗；整体的平均不能掩盖边缘的伤害。自治、横向协同、上级兜底和实际授权各指什么，要事先定下。 |
| 证据升级 | 调节、反馈和多中心安排的效果，须有一次通道效应检验，并满足因果主张的条件（§2.4）；学习、制度记忆和代际承接，先核对载体的保留和实际的接续；留痕按“历史留痕载体”这项假设（§7.1）检验，额外的历史增量作历史增量检验；跨尺度的外推，须写出尺度变换（§3.4），通过认识论约束“跨尺度迁移检验”（§4.8.5），并有目标一方的独立证据；主张闭合或转换的，另作尺度闭合检验。 |
| 相关概念 | 全部十一个基本结构概念。人类领域条款：意义与协调；行动承接与责任分型；制度写回；权力、中介与反身性；历史留痕载体。全部四类经验问题。全部十二条结论规则。 |

这个原型不是绝对的终态，不是没有冲突的社会，也不是历史的终点。它可以回退、分裂、被接管、转移功能、进入“有序退场与良性消亡”，或者崩解；它也不能替任何对象取得对他者的决策权。

## 8.4　非线性路径库 {#section-8-4}

状态原型只有和路径库一起使用，才不会退回到阶段论。路径描述的是“状态配置或对象的界定怎样变化”，不是“更好的人怎样升级”。同一个时间窗内可以有多条候选路径；证据不足时，保持“未知”。

| 路径 | 含义 | 关键区分 |
| --- | --- | --- |
| 混合 | 在同一对象、同一尺度和同一时间窗中，两种以上原型的必要特征共同出现。 | 如果差异能够稳定地对应到各自独立的子系统，应记为“并行”。 |
| 并行 | 不同的地域、层级、功能，或中心与边缘，同时处于不同的状态。 | 不能压成一个“整体阶段”；各子系统分别保留自己的同一性判据、证据和退出条件。 |
| 跳跃 | 在相邻的观察窗之间，从一个配置转到不相邻的配置，中间的原型没有可以辨认的持续时间窗。 | 先排除采样过稀和资料缺失；记下被跳过的功能、代价和未知的部分。 |
| 回退 | 与同一对象自身的基线相比，一项或多项功能退化。 | 分突发、渐进、临界跳变和级联几种；主动降载、“有序退场与良性消亡”（§8.5）或功能转移，都不是回退。 |
| 分裂 | 原对象分成两个以上、同一性判据各不相同的候选对象。 | 临时的项目分组和模块化，未必改变对象；每个新对象都要重新界定。 |
| 合并 | 多个对象形成一个新对象，或被其中一方吸收。 | 联盟不一定是合并；弱势一方的边界、记忆、退出和遗留责任必须单独列出。 |
| 休眠 | 看得见的活动减少，但记忆、关系、符号、能力或重新激活的条件仍然保存着。 | 要分清保护性的撤离、耗竭造成的停滞、资料的消失和真实的崩解。 |
| 接管 | 外部主体取得了对关键资源、权限或接口的控制。 | 外部的支持或监管，如果保留了真实的自主和停止权，不一定是接管。 |
| 功能转移 | 核心功能转到另一个对象；功能可以连续，而原来的身份、关系或记忆消失。 | 把单项任务外包出去，不等于功能转移；功能连续，不证明责任和记忆也连续。 |
| 范式替换 | 旧对象没有被修复，而是被一个同一性判据、接口或规则不同的新对象绕过。 | 同一对象内部的升级，或品牌改名，不一定是范式替换；遗留的义务仍然存在。 |
| 创伤建成的发展 | 边界、身份、规则或承接方式，是在伤害、剥夺、失败或威胁之下形成的。 | 关于创伤的叙事，不自动证明未来的效应；保护作用和对原始伤害的复制，须分别检验。 |
| 虚稳态 | 表面的指标稳定，实际上承接耗竭、弱信号消失、反馈不写回，或债务上升。 | 建立表面与实际两本账，回到成本、恢复、停止权和末端的反馈。 |
| 强制重写 | 高权力的主体在缺少可以纠错的同意、退出和记忆保护的情况下重写对象。 | 要与有授权、可撤回、可申诉的协商修订分开；检查有没有不可逆的身份抹除。 |
| 外部载体迁移 | 修复的路被封闭时，把人员、能力、资源、关系、证据或记忆移到更安全的承接系统。 | 没有接收能力，把离开浪漫化，或把伤害私有化，都不构成安全的迁移。 |
| 崩解 | 原来的同一性判据不再成立，功能、承接、关系或边界发生非计划的断裂。 | 要与“有序退场与良性消亡”、功能转移、保护性休眠和对象重组分开；资源得到释放，不使伤害变得正当。 |

路径的名称也不产生价值或责任。例如，“回退”不是道德上的堕落，“分裂”不必然是失败，“合并”不必然是进步，“接管”不是自动非法，“外部载体迁移”也不是要求个人自行逃离。路径只是让竞争解释进入记录；机制、正当性和行动，仍然各有各的条件要满足。

</div>

<div v-pre class="theory-source">


## 8.5　有序退场与良性消亡（X0） {#section-8-5}

“有序退场与良性消亡”不是第八种状态，它的编号不接在七种状态原型之后，也不算作第八个阶段。它是人类集体生命周期中一条独立的路径：当继续维持原对象已经不再服务于已写明的锚点，核心功能可以完成、终止或由更安全的一方承接，并且人员、关系、资源、记忆、债务和申诉都能得到明确处理时，用它来记录对象怎样收束使命、转移功能、释放资源、保存记忆、结清责任，并保留受限的弱连接。

这条路径不要求先达到高效协调与弹性扩展原型或自适应动态平衡原型。处于锚点凝聚原型的临时倡议，发现问题已经由别处承接时，可以有序关闭；处于首次扩展与承接分化原型的扩展项目，在继续扩张只会制造伤害时，可以收束；处于连通约束下的发展原型的受困机构，在修复不可行而外部承接充分时，也可能进入退场。反过来，处于自适应动态平衡原型的集体，也不能凭着“高阶”的标签宣布自己有资格解散。阶段能力、规范上的正当性和操作条件是三件事；任何状态编号都不能成为主动退场的资格前提。

这条界线是定死的：从任何一个已经写明的出发位置都可以进入这条路径，不设最低的状态前提，不要求先处于哪一种原型，更不以高效协调与弹性扩展原型或自适应动态平衡原型为前提。它的入口条件和完成条件，都不得把七种状态原型中的任何一种当作资格；原型的编号只能说明出发的位置，不能变成退场的门槛。

</div>

<div v-pre class="theory-source">


### 8.5.1　有序退场的候选入口 {#section-8-5-1}

第一，锚点已经完成、已经失去适用性、已由更安全的对象承接，或者继续维持已经主要是在为组织自身的存续服务。这个判断必须能够被独立复核，不能靠中心改写目标之后自己证明已经完成。第二，人员、功能、资源、关系、记录、债务和不可替代的价值已经列成清单，并且有可以核验的接收方或保护安排。短期的挫折、资金紧张、领导疲倦或逃避责任，都可能造成相似的表象；所以只在叙述上满足，不能进入“良性完成”。

</div>

<div v-pre class="theory-source">


### 8.5.2　有序退场的完成条件 {#section-8-5-2}

| 完成面 | 必须保存的内容 | 失败信号 |
| --- | --- | --- |
| 锚点与对象 | 完成、终止或失效经过独立验证；同一性判据的结束时间和尚未结案的事项 | 改写目标；删除失败的事项；中心单方面宣布完成 |
| 核心功能 | 每一项功能标明是完成、终止、转移还是未决；接收方的能力、权限、资源和恢复原状的安排 | 只有宣告，没有维护者或使用者的连续性 |
| 人员与关系 | 安全、基本权益、停止权、不受报复，以及照护关系和依赖关系的承接 | 把组织的义务私有化，变成成员自行承担 |
| 资源 | 资源的对象、边界、顺序、时间和去向都可以追踪，防止高权力位置截留 | 先在内部瓜分，再把损失留给低权力位置 |
| 记忆与证据 | 成功、失败、修复和岗位记忆都得到保存；访问、隐私、纠错和反报复的安排明确 | 只保留胜利的历史，删除或暴露弱势一方的材料 |
| 债务与责任 | 合同、劳动、数据、维护、环境、申诉和未来风险，都有持续负责的责任主体 | 对象一注销，责任、复核和维护同时消失 |
| 弱连接 | 只提供咨询、经验和缓冲，边界和期限明确 | 未经新的授权，就复活原来的权力结构 |

这条路径的结果，至少应当分清“候选”“进行中”“部分完成”“完成”和“未知”。只要受影响的群体、遗留的义务、接收的能力、申诉或记忆的安全仍为“未知”，就不能写“良性完成”。功能转了出去，记忆和责任却没有连续下来，可能只是“功能转移”；外部权力单方面关闭对象并改写它的身份，可能是“接管”或“强制重写”；没有承接的断裂则是“崩解”，不能用“有序退场”来美化。

归入“有序退场与良性消亡”，不产生解散、裁撤、转移资产、公开档案、放弃债务或代表成员同意的授权。它只能告诉我们：要判断一次退场是否有序，必须把哪些对象、义务、证据、保护和未知放到同一本账上。

</div>

## 8.6　调节、预警与承接如何进入状态判断 {#section-8-6}

状态不是靠一张静态的截图来判定的。调节层要求观察目标、感知、比较、执行、反馈和时滞；预警层要求比较恢复变慢、波动放大、同类扰动的后果加重和局部闪烁这几种迹象是否成簇；偿付层要求追踪谁承诺、谁承担、谁回流、谁被推迟到未来。高效协调与弹性扩展原型或自适应动态平衡原型的表面稳定，如果建立在账外的劳动、沉默和未来的债务之上，应当转为“虚稳态”（§8.4）的候选。

由同一个序列或共同的变化通道产生的多条线索，不因为成簇出现，就成了多份独立的证据。相互依赖的线索仍然可以联合使用；它们的预警价值，须在相符的动力、噪声、采样和观察时间窗之下，按固定的目标、期限、实时基线和反向信号来评价（Scheffer等，2009；参见D.31、§12.6）。

成簇不是预警通用的准入条件。单独一个业务信号，也可能足以支持有限的判断；缺少临界减速或第二条信号，既不证明安全，也不取消已有的专业预测。联合使用几条线索的规则，需要联合分布或相应的验证；它的阳性预测值上升，还不保证在给定的误报、漏报和行动成本之下总损失下降。

承接也不能只看“有没有接班人”。要看候补梯队、影子岗位、岗位记忆、授权路径、交接窗口、合法性的转译和保护条件是否实际存在。生成者退得干净而承接者进不了场，会形成权威真空；频繁换人而关键的知识和权限仍然锁在原来的中心，也不是自适应的更新。这里要用到四项人类领域条款（§7.1）：用“行动承接与责任分型”区分承接载体、成本承担者、受益者、停止权和责任主体；用“制度写回”判断反馈是否真的改动了相应的内容并得到执行；用“权力、中介与反身性”检查权力和观测通道；用“历史留痕载体”核对留痕。载体是否实际接续，按§4.5检验；如果另外主张当前表示之外的历史增量，再作历史增量检验。这一类依赖跨轮强化的候选机制，见§7.6.1。

</div>

## 8.7　当前原型边界与排除项 {#section-8-7}

七种状态原型是一组可以反驳、可以缺失、可以并行、可以撤回的人类集体状态原型。每个候选都必须逐项检查入口、退出、观察、反例、证伪、尺度、证据、缺失和不授权行动这条边界；缺了这些条件，只能留作印象或“未知”。编号不表示一条从 0 到 6 的普遍演化路线；状态之间允许回退、并行、混合、跳跃、休眠、分裂、合并、接管、功能转移和崩解。

“有序退场与良性消亡”（§8.5）是一条独立的生命周期路径，不以高效协调与弹性扩展原型、自适应动态平衡原型或任何最低状态为前提。阶段能力、规范上的正当性和退场的操作条件，必须分别判断；与任何原型相符，都不能自行产生解散、推进、淘汰或强制转换的授权。

缺少形式映射、量纲、可以证伪的预测和类比终止条件的物理隐喻，不进入正式的机制库。例如，“量子隧穿”不能解释人类集体为什么会跳跃式地转换；在本框架里，把失败的尝试认定为当前已写明的状态之外的历史条件增量，仍须由相应的一次历史增量检验来支持（参见§4.5）。生物的死亡与社会的更新之间、爱与传承之间，也不预设必然的协作；代际承接只按角色、记忆、授权和交接这几方面来记录。

七种原型并不声称穷尽了人类集体的全部状态。一个案例如果持续落在原型之外，应当先把未解释的残差保留下来，再依据独立的材料检验是否需要新增、合并或拆分原型，而不是把案例硬塞进某个编号。

与原型相符、观察者之间的一致性、跨时间窗的稳定性，以及比起直接使用变量多出来的增益，是几个不同的问题。清楚的诊断卡可以提高可复核性，却不证明分类已经可靠，或比专业的描述更有效。没有取得实际的比较时，不报告准确率、预测收益或节省了多少阅读；如果任务只需要直接描述成员、通道和负荷，可以跳过原型。

## 8.8　与行动者状态和多圈层推演的边界 {#section-8-8}

七种状态原型描述的是有意图集体在指定的对象界定之下的候选状态，不描述个人的人格、心理成熟度或道德等级。行动者的慢、中、快变量由第九部分处理；多个集体之间的平行、嵌套、重叠、桥接、竞争和临时关系由第十部分处理。一个人所属的圈层被归入首次扩展与承接分化原型，不表示这个人的人格也处在这一原型；一个人表现出稳定的能力，也不表示他所在的圈层处于高效协调与弹性扩展原型或自适应动态平衡原型。

多圈层的推演可以让不同的圈层同时处于不同的原型，也可以让同一个圈层在不同的尺度轴上呈现混合状态。状态的变化必须落到具体的事件、通道和时间窗上；外层的制度变了，不能自动更新内层的关系；个体退出，也不自动造成集体解体。如果原型分类比起直接使用变量没有增量价值，应当跳过原型，使用更简单的联合状态。
