# A.7　HV07 反馈写回（完整接口卡） {#section-a-7}

A. 身份、命题与适用范围

| 字段 | 登记内容 |
| --- | --- |
| 接口 ID（id） | HV07 |
| 限定 ID（qualified&#95;id） | human&#95;variable:HV07 |
| 名称（name） | 反馈写回 |
| 主张类型（claim&#95;type） | H |
| 合同角色（contract&#95;role） | human&#95;variable&#95;interface |
| 命题（proposition） | 申诉、审计和反馈只有改变记录、规则、资源、角色、责任、记忆或停止条件，且相应改变已实际执行时，才构成人类制度写回。 |
| 适用范围（scope） | 具有反馈、申诉、审计或治理程序的人类结构 |
| 暂停条件（pause&#95;condition） | 只有接收回执、表态或发布而无状态更新，或字段改变尚未实际执行时，暂停制度性写回成立断言；已提交、已受理、字段改变等有限状态仍按R0分类。 |

| 反例（counterexamples） | 1. 申诉获得接收回执但记录、规则、资源和停止条件均未改变<br>2. 审计报告被发布却没有责任人、时限或后续状态更新 |
| 申诉（appeal） | 依appeal&#95;and&#95;rollback&#95;rule，反馈提交者可经安全可达、反报复通道要求状态、时限、责任人与写回结果，并触发与原受理、写回或决策链独立的复核 |
| 回滚（rollback） | 依appeal&#95;and&#95;rollback&#95;rule，获准回滚时，由指定责任人在规定时限内撤销错误更新，实际恢复先前记录、规则、资源、角色或停止条件状态，保留版本与完成验证 |
