# A.4　HV04 生成节点（完整接口卡） {#section-a-4}

A. 身份、命题与适用范围

| 字段 | 登记内容 |
| --- | --- |
| 接口 ID（id） | HV04 |
| 限定 ID（qualified&#95;id） | human&#95;variable:HV04 |
| 名称（name） | 生成节点 |
| 主张类型（claim&#95;type） | H |
| 合同角色（contract&#95;role） | human&#95;variable&#95;interface |
| 命题（proposition） | 生成必须分流为生成条件GC、生成主体GS与生成事件GE，允许无可识别主体的涌现型生成。 |
| 适用范围（scope） | 人类结构中新行动、组织、制度或状态转移的形成 |
| 暂停条件（pause&#95;condition） | 条件被人格化、事件被当作主体或主体资格未经依据确认时，暂停相应主体或分型断言；R0仍可分别登记候选GC、GS、GE及未识别主体状态，不把未识别当作已证明无主体。 |
