# A.3　HV03 指向锚点（完整接口卡） {#section-a-3}

A. 身份、命题与适用范围

| 字段 | 登记内容 |
| --- | --- |
| 接口 ID（id） | HV03 |
| 限定 ID（qualified&#95;id） | human&#95;variable:HV03 |
| 名称（name） | 指向锚点 |
| 主张类型（claim&#95;type） | H |
| 合同角色（contract&#95;role） | human&#95;variable&#95;interface |
| 命题（proposition） | 目标、身份、记忆、承诺、恐惧或共同问题可以先登记为候选意义材料；只有H1-instance支持预先选定的资源配置、行动选择或协调结果，才在该实例范围登记条件性有效指向锚点。 |
| 适用范围（scope） | 具有意向、协调或共同问题的人类结构 |
| 暂停条件（pause&#95;condition） | 只有口号、解释者投射或被强制的一致表达时，不登记R1条件性有效指向锚点；有来源的表达材料、异质表达与强制风险仍可按R0登记，不据此推出共同意志。 |

B. 正式依赖与结论边界

| 字段 | 登记内容 |
| --- | --- |
| 推理依赖（inferential&#95;requires） | 1. human&#95;variable:HV01 |
| 协议依赖（protocol&#95;requires） | 1. E2<br>2. EVIDENCE<br>3. SOURCE |
| 限定／特化（specializes） | 无（空集合） |
| 适用对象引用（applies&#95;to） | 无（空集合） |
| 条件支持路由（conditional&#95;support&#95;routes） | 1. route&#95;id=HV03-R0-candidate-anchor；<br>claim&#95;level=candidate&#95;description；<br>when=目标、身份、记忆、承诺、恐惧或共同问题有可追踪表达与承载形式，但尚无符合资格的H1-instance。；<br>additional&#95;inferential&#95;requires=无（空集合）；<br>additional&#95;protocol&#95;requires=无（空集合）；<br>allowed&#95;conclusion=登记候选意义材料、异质表达、代表性争议与H1补证需求。；<br>result&#95;ceiling=仅称候选意义表达；不得称有效指向锚点或共同意志。<br>2. route&#95;id=HV03-R1-effective-anchor；<br>claim&#95;level=conditional&#95;effect；<br>when=预注册H1-instance在资源配置、行动选择或协调结果中唯一预选的判据取得supported。；<br>additional&#95;inferential&#95;requires=H1-instance；<br>additional&#95;protocol&#95;requires=CAUSAL、E4；<br>allowed&#95;conclusion=登记该实例、结果家族、尺度与窗口内的条件性有效指向锚点。；<br>result&#95;ceiling=不外推到未选资源、行动或协调结果，也不推出真实同意、统一内心或强制统一意义。 |
| 允许推论（allowed&#95;inference） | 1. 条件性的协调方向与冲突锚点 |
| 禁止跳跃（prohibited&#95;leap） | 1. 群体具有统一内心<br>2. 共同语言等于真实同意<br>3. 目标正当 |

C. 九轴尺度与对象合同

| 字段 | 登记内容 |
| --- | --- |
| 九轴尺度画像（scale&#95;profile） | SP=&lt;A,X,T,O,C,R,I,N,J&gt;；A=聚合层次：单次表达或行动、主体个案、候选参与总体、立场分布及聚合规则；X=空间范围：关系现场、组织空间、数字公共空间与跨域传播范围；T=时间跨度：表达—行动窗口、承诺周期、漂移与解耦时滞；O=组织层级：行动角色、团队、组织、制度至公共治理生态；C=因果层次：表达事件、意义—行动互动机制、中观协调结构、制度安排与系统条件；R=观察分辨率：原始表达与行动、事件序列、个案、立场分布、协调指标与摘要，并登记压缩损失；I=影响范围：直接参与者、异议者、间接受影响者、二阶协调后果、跨域与代际影响；N=网络拓扑范围：表达传播、协调连接、异质簇群与桥接节点；J=管辖与授权范围：锚点命名、代表性采用、协调或统一要求分别登记授权；必须保留异质锚点 |
| 有效对象（effective&#95;object） | 可能改变资源配置、行动选择或协调结果的目标、身份、记忆、承诺、恐惧或共同问题 |
| 跨尺度保持项（scale&#95;invariants） | 1. 意义到预选资源配置、行动选择或协调结果的桥接 |
| 升格必补项（required&#95;scale&#95;additions） | 1. 代表规则<br>2. 异质性<br>3. 成本收益分布<br>4. J轴 |
| 随尺度改变项（changing&#95;semantics） | 1. 锚点内容、强度和承载主体可改变 |
| 不适用对象（non&#95;applicable&#95;objects） | 1. 无意向、意义或承诺能力的非人系统 |
| 禁止升格（forbidden&#95;elevation） | 1. 局部表达直接升级为共同意志 |

D. 状态、证据与变量流

| 字段 | 登记内容 |
| --- | --- |
| 状态集合（state） | 1. 分散<br>2. 凝聚<br>3. 竞争<br>4. 固化<br>5. 解耦 |
| 可观测项（observables） | 1. 预注册意义表达出现前后的资源配置差异<br>2. 行动选择、协作完成率或冲突模式变化<br>3. 不同位置对锚点的接受、拒绝与替代表述<br>4. 比较条件下结果差异是否超过预定阈值 |
| 证据要求（evidence） | 1. 资源调整<br>2. 行动序列<br>3. 承诺与退出记录<br>4. 冲突证据 |
| 输入依赖与接口内容（input&#95;dependencies） | 1. 参与位置2. 表达安全3. 资源与行动数据 |

| 局部排除区（local&#95;exclusion&#95;zone） | 低安全位置的不同目标不得被聚合抹去 |
| 受影响位置（affected&#95;positions） | 1. 认同者<br>2. 异议者<br>3. 被代表者<br>4. 成本承担者 |

E. 承接、责任、规范、上限与纠错

| 字段 | 登记内容 |
| --- | --- |
| 承接载体（carrier） | 1. 叙事<br>2. 承诺<br>3. 共同记忆<br>4. 制度目标<br>5. 问题定义 |
| 责任主体（responsible&#95;subject） | 1. 提出代表性主张者2. 据此配置资源者 |
| 规范地位（normative&#95;status） | 锚点存在不证明其正当 |
| 判断上限（judgment&#95;ceiling） | 按R0/R1分别限制：R0仅描述候选意义表达；相应H1-instance支持所选结果效应时，R1可作限定范围的条件性锚点解释，不外推未选结果 |
| 行动上限（action&#95;ceiling） | 本变量只生成候选锚点、异质表达、比较结果与补证需求描述，不授权统一意义、代表意愿或协调行动；任何现实调整须另过C12、运行时显式N前提、J授权与O程序 |
| 反例（counterexamples） | 1. 反复出现的口号没有改变任何资源配置或行动<br>2. 高压场景中的一致表达掩盖相互冲突的真实目标 |
| 申诉（appeal） | 依appeal&#95;and&#95;rollback&#95;rule，成员可经安全可达、反报复通道否认代表性、提交异质目标或拒绝被锚定，并触发与原锚点判断链独立的复核 |
| 回滚（rollback） | 依appeal&#95;and&#95;rollback&#95;rule，获准回滚时，由指定责任人在规定时限内实际撤销锚点命名、移除其代表性与下游协调效力并恢复异质表达状态，保留版本与完成验证 |
