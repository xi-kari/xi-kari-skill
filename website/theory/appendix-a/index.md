# 附录A　人类变量详表 {#part-title-17}

本附录逐项说明第七部分的十一项人类变量。每一项分五组：命题与适用范围；依据与结论边界；尺度与对象；状态、证据与变量之间的关系；承接、责任、上限与纠错。

各项说明的是一个变量的结构，具体证据要按所选的支持路线和任务的需要去取得。不适用、未知、尚未收集和为保护而不公开，分别记下。把每一项都填满，不是提供日常帮助或形成理解的前提条件。某一类依据写“无”，只表示这一类没有列出内容，不表示证据充分或经验上成立。支持路线必须逐条作为整体来读，不能把不同路线里有利的条件事后拼在一起。
