# A.11　开放性承担行动（HV11） {#section-a-11}

一、命题与适用范围

命题：开放性承担只观察真实成本、自愿性、方向、替代解释和结构后果，不诊断某人有没有爱。

适用范围：人类关系、组织、制度与公共行动中的承担。

暂停条件：无法安全地确认自愿、拒绝或退出时，暂停路线二的“开放性承担”命名；仍然可以按路线一记下候选行动、成本、强制风险、停止权缺口和保护需要。对人格与爱的诊断始终禁止。

二、依据与结论边界

推理前提：无。

方法要求：规范前提“不征用爱与承担”（§14.3）；证据的条件（§2.5）；来源的条件（§2.7）。

领域限定：人类领域条款“开放性承担”（§7.1）；人类领域条款“行动承接与责任分型”（§7.1）。

适用对象：无。

支持路线：

路线一，行动与成本记录。结论档位：规范边界。条件：行动和相关的成本有依据，方向、受益和后果可以按已知或未知的状态记下，但自愿性、拒绝或退出还没有得到充分的支持。另需的推理前提：无。另需的方法要求：无。可以得出：描述候选的承担行动、成本分布、强制风险、停止权缺口和保护需要。上限：不得称为开放性承担；不得诊断爱或人格，也不得要求继续承担。

路线二，有限自愿承担。结论档位：规范边界。条件：行动和真实成本有依据，方向明确，自愿性、真实的拒绝、退出或协商条件分别得到支持，并且检查了相关的替代解释；结果按“实现”“未实现”“有害”或“未知”记下，不以结构上的成功作为准入条件。另需的推理前提：无。另需的方法要求：无。可以得出：记下有限自愿承担的描述和结果的状态；失败或结果未知，不取消有依据的行动事实与自愿性事实。上限：只到行动的描述；不把个体的承担上升为群体的义务，也不授权征用、保护或资源安排。

路线三，结构后果。结论档位：条件效应。条件：一次合格的通道效应检验（§4.4）显示，这一行动经由指定的通道，对事先选定的结构结果产生了超过阈值的效应。另需的推理前提：这一次通道效应检验。另需的方法要求：因果主张的条件（§2.4）；竞争解释与残差保留（§4.8.4）。可以得出：认定指定的通道、对象和时间窗之内这一行动的结构后果。上限：结构效应不证明自愿性、爱、善、正当性、无限责任或行动授权；路线三对效应的支持不能替路线二补证，受强制的行动也可能有可以识别的效应。

可以推出：对有限的承担行动及其后果的描述。

不能推出：有没有爱的诊断；牺牲等于爱；责任等于无限承担；拒绝等于道德失败。

三、尺度与对象

九轴尺度：聚合层次看单次的承担行动、行动者个案、关系或组织的总体、成本与自愿性的分布和聚合规则；空间范围看关系与照护的现场、组织边界、数字公共空间和跨域受益的范围；时间跨度看即时行动、持续承担、耗竭、恢复与代际的时间窗；组织层级从行动角色、关系或团队、组织、制度到治理生态；因果层次看承担事件、行动—成本的互动机制、中观关系结构、制度责任安排与系统条件；观察分辨率看原始的行动与成本、承担序列、行动者个案、成本与自愿性的分布、后果指标与摘要，并记下压缩造成的损失；影响范围看直接的行动者与受益者、依赖者、间接的替代承接者、二阶外溢、跨域与代际影响；网络拓扑范围看依赖照护、受益连接、替代承接、退出路径和跨域成本网络；管辖与授权范围对承担要求、资源使用、拒绝、停止、保护和补救分别说明授权。自愿性、成本和退出上的差异要保留。

有效对象：需要分别审查行动、成本、方向、自愿性、拒绝条件和后果的人类承担安排；路线一、路线二、路线三按各自的条件判断，不先用结构后果筛选行动。

跨尺度时保持：成本、自愿性、方向、替代解释、后果与停止权。

上升到更大尺度时必须补上：自愿性的分布；代表关系；成本外溢；真实退出与代理保护。

随尺度改变：承担形式、成本位置和受益对象可以改变。

不适用的对象：没有意向、自愿性、责任或意义能力的非人系统。

不能上升为：个体的承担上升为群体的义务；人类的承担概念迁入非人核心。

四、状态、证据与变量之间的关系

状态：候选；自愿且有限；强制风险；单方耗竭；停止或退出。

可以观察的：行动所投入的时间、资源、机会，以及身体与心理成本；拒绝、退出、停止和重新协商是否真实可用；行动的方向、受益位置和可以检测的结构后果；强制、恐惧、依赖、利益与表演等替代解释。

证据要求：行动与成本；拒绝和退出的条件；替代解释；受益与后果。

输入：指向锚点（§7.3.3）；行动承接层（§7.3.5）；条件势场（§7.3.8）；权力与安全。

输出：成本分布；关系和制度的状态；停止与修复。

时间窗与时滞：说明即时成本、持续承担、耗竭与恢复时滞。

不确定性：记下依赖、恐惧、隐性强制与表达安全。

局部排除区：无法安全拒绝、无法退出或被道德压力遮蔽的位置。

受影响位置：行动者；受益者；依赖者；替代承接者。

五、承接、责任、上限与纠错

承接载体：具体行动者；关系实践；照护或责任安排。

责任主体：提出要求者；授权者；受益责任者；补救责任者。

规范地位：受规范前提“不征用爱与承担”约束，不可命令或征用。

判断上限：按路线一、路线二、路线三分别设限。路线一只作成本、方向、风险和候选行动的描述；路线二在相应的证据之下，作关于自愿性、拒绝条件和退出条件的行动描述；路线三只有在相应的通道效应检验和因果条件成立时，才作范围有限定的结构后果判断。任何一级都不得进入人格诊断、证明爱或善、推出承担义务或产生现实授权。伦理上的命名，另受治理条款“开放承担、规范前提与隐喻漂移分流”（§16.14）关于规范前提的要求约束，不能用达到路线三来代替这一要求。

行动上限：这一变量只产生关于自愿性、真实成本、方向、替代解释、结构后果，以及停止与保护的需要的描述，不授权保护措施、承担要求、资源征用或人格裁决。任何现实中的调整，都须另外通过规范桥接（§4.14.1），并具备本次明示的规范前提、逐项授权和操作程序。

反例：无法拒绝的单方牺牲被赞美为爱或责任；宣称承担，却缺少所称的行动或成本的证据。真实而失败的尝试和结果未知的情形另行记下，不能因为没有结构上的成功，就一概撤销其行动描述。

申诉：按共同的申诉与恢复原状规则（§7.4），行动者可以经由安全可达、有反报复保护的通道拒绝被代表，说明强制、成本、替代解释和退出限制，并启动与原承担判断或原要求链相独立的复核。

恢复原状：按同一规则，获准恢复原状时，由指定的责任人在规定时限内撤销承担命名和相关的要求，实际恢复拒绝、退出、记录和资源的状态。修改留有记录，并核实已经完成。

“九轴尺度”一项不是“微观—宏观”的单轴标签，而是九个轴的完整记录：聚合层次，必须说明单元、总体、分布和聚合规则；空间范围，指物理空间与数字边界；时间跨度，指时间窗、时滞和周期；组织层级，指角色、团队、组织、制度与治理生态；因果层次，指事件、互动机制、中观结构、制度和系统条件；观察分辨率，指原始事件、序列、个案、分布、指标与摘要，并记下压缩造成的损失；影响范围，指直接、间接、二阶、跨域与代际的受影响范围；网络拓扑范围；管辖与授权范围。聚合层次、空间范围、组织层级或影响范围扩大，不会自动扩大授权范围；观察得更多，不能产生更大的处置权。

身份与同一性判据属于对象界定中的同一性判据一项；关系与作用通道写在“输入”“承接载体”两项里，或归入因果主张的条件；成员与受影响位置写在“受影响位置”“局部排除区”和有关观察的各项里。它们都不能冒充尺度轴。九个尺度轴里的网络拓扑范围（记作 N）与五项规范前提（N1—N5）共用一个字母，两者不可混用；下文“本次明示的规范前提”指的是后者（§14.3）。

十一项变量共用同一条行动边界：变量本身只产生描述、证据缺口和行动需要，不授权现实中的调整。各项变量的输出上限如下。

| 变量 | 这一变量可以产生的描述或需要 |
| --- | --- |
| 结构域 | 候选结构域、边界争议和补证需要 |
| 边界与接口 | 边界状态、接口障碍、排除风险和测试需要 |
| 指向锚点 | 候选锚点、异质表达、比较结果和补证需要 |
| 生成节点 | 生成条件、生成主体、生成事件的候选分型，状态转移和补证需要 |
| 行动承接层 | 承接载体、责任主体、成本、容量、停止权、承接缺口，以及减载、补充资源或重新分配的需要 |
| 动力—承接链 | 链条的连通、时滞、损耗、中断、成本和承接需要 |
| 反馈写回 | 受理、制度要素变化、执行、持续时间、写回缺口和程序修复的需要 |
| 条件势场 | 候选条件通道、位置异质性、证据遮蔽和降低风险的需要 |
| 结构负荷 | 负荷、容量、恢复、局部过载，以及减载和补充资源的需要 |
| 演化相位 | 按所选路线的组件适用性、原型匹配与混合状态、有限定的相位机制解释或历史条件增量解释、独立的“有序退场与良性消亡”路径状态、不确定性和观察需要 |
| 开放性承担行动 | 自愿性、真实成本、方向、替代解释、结构后果，以及停止与保护的需要 |

无论这些需要看起来多么明显，任何现实中的调整，都须另外通过规范桥接（§4.14.1），并具备本次明示的规范前提、逐项授权和操作程序。变量不得自行授权测试、减载、补充资源、修复、保护、归责、试探、推进、退出安排或处置。
