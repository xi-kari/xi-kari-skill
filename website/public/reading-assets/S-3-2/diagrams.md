# S-3-2｜图示与使用说明

## 3.2　D1 基本状态词
当前交付为静态图；交互尚未实现，以下涉及选择、切换或点击的内容仅为后续设计设想。后续交互可给出一个网络事件，让读者分别判断六个判据并展示理由；允许多个词同时成立，不自动给对象评定成熟度。
