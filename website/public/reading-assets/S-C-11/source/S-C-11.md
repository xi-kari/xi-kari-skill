## C.11　历史增量与当前表示遗漏

沿用961个等概率初态，但每个队列每轮服务最多5件、没有新增任务。完整状态按F(q₁,q₂)=((q₁−5)_+,(q₂−5)_+)推进。以第二轮后的均值为预测目标，比较第一轮后的当前均值、当前均值加初始均值、完整当前状态，以及完整当前状态加初始均值。平方损失下，对每个输入纤维输出目标条件均值即达到最小期望损失。

| 预测输入 | 给定分布下的最小均方误差 |
| --- | ---: |
| 当前均值 | 0.579016561 |
| 当前均值与初始均值 | 0.271143397 |
| 完整当前双队列状态 | 0 |
| 完整当前双队列状态与初始均值 | 0 |

计算对961个初态逐个推进并保留其原有权重，没有把第一轮后的状态重新设为均匀。具体地，(0,20)推进为(0,15)，下一均值为5；(10,15)推进为(5,10)，下一均值为2.5。两者当前均值同为7.5，初始均值却不同。历史均值帮助区分当前投影折叠的差异，完整当前状态已足以确定未来。

这证明历史预测增量可以由当前表示遗漏产生，不证明真实系统一概无记忆。现实资料中还要处理测量、混杂、时间顺序、泄漏和模型选择；完整当前载体不可得时，也不能宣称已经排除历史增量。若早期经历经当前技能影响结果，当前技能充分后残差消失，只限定给定技能后的额外预测量，不否定早期经历的总作用或一般学习。
