## 8.3　S0—S6 状态原型

### 8.3.1　S0　锚点凝聚原型

S0 描述的是“候选集体正在形成”，不是“低级组织”。共同问题、候选目标或意义表达开始聚拢注意、关系、时间和少量资源，但成员构成、实际边界、角色、承诺方式与共同身份的表达仍在形成或变化。分析仍须使用本次冻结且可据以追踪对象的K；形成中的状态变化不替代同一性判断。至少一个候选生成行动者反复进行翻译、召集、试探或承担真实成本，独立承接层尚未形成。候选集体可以在这里消散、休眠、并入其他安排或转向新的目标；各路径的发生比例须有相应机会总体和观察资料，不能由原型定义推定。过程结束本身不构成失败判决。

| 检查面 | S0 诊断卡 |
| --- | --- |
| 入口 | S0-E1：在本次冻结且可据以追踪对象的K下，共同问题或意义安排造成可见局部聚集，但成员、实际边界或承诺方式尚未稳定。S0-E2：候选生成行动反复出现，承接尚薄。 |
| 退出 | S0-X1：在同一K仍适用且对象同一性可追踪的窗口内，锚点、实际边界和生成角色跨窗稳定，并出现可追踪承诺与初步承接，可检 S1。S0-X2：聚集消散、分裂、被吸收或进入休眠，不必经过 S1；原K不再适用时，另做对象转换或终止判断。 |
| 可观察 | S0-O1 竞争表述仍在协商；S0-O2 资源聚集伴随高进出；S0-O3 生成行动者承担翻译、召集或试错；S0-O4 失败试探与备选历史仍被保留。 |
| 反例 | 热点或平台推荐能制造短期同步；行政命名能制造形式团队。要观察奖励、曝光或命令撤除后，承诺和对象边界是否仍持续。 |
| 证伪 | 与匹配临时聚集相比，共同方向、行动聚集与生成角色都无区别，则撤回 S0。若稳定角色、承接与重复运行早已存在，S0 也不是主导状态。 |
| 尺度 | 必须区分生成者、早期参与者、潜在退出者与外部命名者；不能把个体人格聚合成集体状态。 |
| 证据升级 | 意义安排造成资源、行动或协调差异须 H1-instance；指定通道造成形成须 G2-instance；历史留痕按 H5，当前载体的未来作用按§4.5；当前表示之外的历史增量才追加 G3。 |
| 合同链接 | U01/U02/U03/U08/U09/U11；H1/H2/H5；G1/G2/G3；C1/C2/C4/C5/C10/C12。 |

S0 允许的结论只是在特定对象、尺度和窗口内与锚点凝聚原型相容。它不能证明参与者缺乏能力、价值或意愿，也不能授权扶持、解散、筛选或排除。

### 8.3.2　S1　生成核心奠基原型

S1 中，候选锚点、对象边界和至少一个生成角色已经能跨决策重复识别，基本规则、语言、资源通道和最早记忆载体开始奠基。主要翻译、决策、资源动员、冲突处理或关系修复仍集中在一个或少数生成角色，独立承接者很少。中心性是结构依赖，不是领导正当性的证明。

| 检查面 | S1 诊断卡 |
| --- | --- |
| 入口 | S1-E1：K、锚点和生成角色可重复识别。S1-E2：关键功能持续依赖生成核心，而非一次紧急集中。 |
| 退出 | S1-X1：新进入者形成持续承接、责任与边界接口，可检 S2。S1-X2：生成核心分裂、退出、被接管、休眠或对象消散，转入相应路径。 |
| 可观察 | S1-O1 锚点和边界初步稳定；S1-O2 关键决策依赖生成核心；S1-O3 规则和记忆载体开始重复；S1-O4 外部进入有限且定向。 |
| 反例 | 成熟组织可能仍由创始人公开宣布决定，但实际承接层已庞大；行政新设部门也可能只是上级对象的角色单元。要追踪实际执行、停止权、反馈和核心暂时离场后的运行。 |
| 证伪 | 生成核心低介入时，多中心承接仍稳定运行，则核心依赖被反驳。若锚点不稳定，但同一K仍适用且对象可追踪，可重新检验S0；若原K不再适用或对象同一性不明，应先检查对象转换或终止，或保持unknown，再对可识别对象分类。 |
| 尺度 | 冻结生成角色、早期承接者、上级命名者与外部支持者；组织图与实际通道冲突时记 conflicted。 |
| 证据升级 | 锚点或生成核心的结果效应分别需要 H1/G2；早期制度或创伤的载体效应依§4.5，留痕检 H5，历史条件残差另检 G3。 |
| 合同链接 | U01/U02/U03/U04/U06/U07/U09/U11；H1/H2/H3/H4；G1/G2/G3；C1/C2/C3/C5/C9/C10/C11/C12。 |

S1 不能被读成“幼稚”“落后”或“应被整合”。它不能赋予生成者永久领导、扩大权力、强制建制或替换他人的资格。

### 8.3.3　S2　首次扩展与承接分化原型

S2 描述边界、成员、服务对象、地域、平台接口或协作网络的持续扩展。新进入者带来不同理解、技能、资源和风险，生成核心之外开始形成承接、退出、保留异议与未决参与位置。扩张既可能提高协调能力，也会增加翻译、反馈、恢复和权力问题。分歧本身不是失稳；只有可观察机制持续阻断承接、反馈或恢复，才能谈结构问题。

| 检查面 | S2 诊断卡 |
| --- | --- |
| 入口 | S2-E1：至少一类边界持续扩展并改变关系。S2-E2：生成核心之外出现可区分承接、成本、退出与未决位置。 |
| 退出 | S2-X1：重复负荷和压力形成连通约束、持续分割通道，可检 S3。S2-X2：扩展停止、回撤、跳跃、分裂、合并、接管、休眠或崩解。 |
| 可观察 | S2-O1 进入/退出和接口构成变化；S2-O2 角色与责任分化；S2-O3 反馈量、翻译成本、时滞和恢复需求变化；S2-O4 认同、异议、退出与安全被分别记录。 |
| 反例 | 人数或用户数增长不一定改变结构；冲突公开也可能是表达安全改善，使旧问题终于可见。 |
| 证伪 | 冻结统计口径后，增长不持续且不改变边界、角色、责任、接口或负荷，则撤回 S2。若所谓分化只来自中心单方标签，也应撤回。 |
| 尺度 | 整体、中心、新承接者、退出者和外部化成本必须同时进入；观察范围扩大不增加对新成员的 J 权限。 |
| 证据升级 | 扩展或通道造成结果差异须 G2/CAUSAL；跨尺度另经 D3/E5，闭合或转换主张另检 G4；锚点协调须 H1；表达、公开与权力的观测效应须 H4；历史留痕须 H5，载体传递按§4.5，历史条件残差另检 G3。 |
| 合同链接 | U01/U02/U03/U04/U06/U07/U08/U09/U11；H1/H2/H3/H4/H5；G1/G2/G3/G4；C1/C2/C3/C4/C5/C6/C7/C9/C10/C11/C12。 |

S2 不允许把不认同、退出或模糊参与者本身命名为负向主体，也不允许用“扩维需要”授权统一思想、限制退出或清退异议。

### 8.3.4　S3　连通约束下的发展原型

S3 中，集体仍在运行或发展，但多个重复约束已经彼此连通：审批、资源、信任、责任、信息、平台或外部依赖形成互相放大的瓶颈，持续分割反馈、承接、恢复或成本回流。这里的关键不是“问题很多”，而是问题能否形成可复核的连通结构；也不是把某个人命名为壁垒。

| 检查面 | S3 诊断卡 |
| --- | --- |
| 入口 | S3-E1：至少两类约束相互强化并跨窗影响通道。S3-E2：运行仍继续，但末端承接、反馈、资源或恢复承担持续额外负荷。 |
| 退出 | S3-X1：关键关系、权限、资源或接口开始实际重构，可检 S4。S3-X2：转入回退、虚稳态、休眠、接管、强制重写、迁移或崩解。 |
| 可观察 | S3-O1 约束网络与瓶颈；S3-O2 输出仍有而损耗、返工、隐性劳动增加；S3-O3 修复反复启动却不写回；S3-O4 中心/边缘、指标/承接、名义/实际持续分裂。 |
| 反例 | 高风险环境的保护性分层和冗余可能提高可靠性；主动降载重构也可能暂时放慢产出。必须检查限制是否阻断必要反馈，或提供错误隔离与替代路径。 |
| 证伪 | 去除共同输入、测量偏差和短期峰值后，约束之间无连通关系，或承接末端的替代通道、写回和恢复持续有效，则 S3 不是主导。 |
| 尺度 | 必须拆分中心、边缘、功能单元、承接末端和外部受影响位置，允许 parallel。弱信号消失不能当问题消失。 |
| 证据升级 | 权力/中介遮蔽须 H4；指定通道与相互强化须 G2；历史形成的当前约束按§4.5，额外历史残差检 G3；跨尺度闭合失败须 G4。 |
| 合同链接 | U02/U03/U05/U06/U07/U08/U09/U10/U11；H1/H2/H3/H4/H5；G2/G3/G4；C2/C3/C4/C5/C6/C7/C9/C10/C11/C12。 |

S3 分类不能授权“打壁垒”、清洗、接管、强制改革或把过渡成本交给弱势位置。它只说明应继续区分约束网络与竞争解释。

### 8.3.5　S4　结构重构窗口原型

S4 不是“改革已经正确”，而是关键结构确实处于重构窗口：旧关系、权限、资源通道、反馈写回或边界接口正在被拆解、替换或绕开，新旧安排并存，转换成本、重复劳动、知识迁移、短期产出下降和恢复需求上升。结果仍然开放，可能改善，也可能停滞、异化、强制重写或崩解。

| 检查面 | S4 诊断卡 |
| --- | --- |
| 入口 | S4-E1：至少一个关键字段实际改变，不只是改名或宣传。S4-E2：旧新安排并存，过渡成本可追踪，K 持续核对。 |
| 退出 | S4-X1：跨窗改善通道、反馈、承接与恢复且无隐藏外包，可检 S5。S4-X2：新结构不可用，转入休眠、回退、接管、强制重写、虚稳态或崩解。 |
| 可观察 | S4-O1 权限/资源/角色/责任/停止条件真实写回；S4-O2 双重系统和转换成本；S4-O3 缓冲、冗余、冷却、停止与回滚；S4-O4 多位置结果进入真实反馈。 |
| 反例 | 大规模改名、换人或重画流程图可能是象征改革；拆旧、过载和产出下降也可能是破坏性清洗或资源抽离。 |
| 证伪 | 实际关系、权限、资源和执行没有改变，则撤回 S4。不存在可用新结构且功能持续断裂时，也不能把过程包装为改善性重构。 |
| 尺度 | 变更前基线、过渡、冷却、回滚和恢复窗均要覆盖；改革发起者、执行者、承接者与成本承担者分开。 |
| 证据升级 | 重构导致改善/伤害须 G2/CAUSAL；对象或干预转换须 G4；失败尝试是否经当前载体影响未来按§4.5，额外历史残差另检 G3，不能用“隧穿”类比代替。 |
| 合同链接 | U03/U05/U06/U07/U09/U10/U11；H1/H2/H3/H4/H5；G2/G3/G4；C2/C3/C4/C5/C6/C7/C9/C10/C11/C12。 |

“过渡谷地”最多是待检的描述，不能为无限代价、不可逆伤害、取消申诉或牺牲低权力位置提供正当性。S4 不产生拆除、清洗或强制迁移的行动授权。

### 8.3.6　S5　高效协调与弹性扩展原型

S5 描述在当前环境和时间窗内，资源、信息、反馈、责任、承接和恢复通道能够较低损耗地协同，局部扰动通常不能形成持续连通壁垒，边界扩展与收缩较有弹性。它仍可能被资源红利、成本外包、沉默、指标漂白或制度漏洞伪造。因此，高产出不是充分证据，长期存续也不是正当性的证明。

| 检查面 | S5 诊断卡 |
| --- | --- |
| 入口 | S5-E1：关键通道跨窗低损耗、可替代、可写回。S5-E2：扩展、存护与消解协同，且不靠封闭反馈或压制异议。 |
| 退出 | S5-X1：分布式承接、自我更新、恢复和新生成跨扰动成立，可检 S6。S5-X2：漏洞、异化、虚稳态、回退、功能转移、X0、接管或崩解使其不再主导。 |
| 可观察 | S5-O1 替代承接与通道真实可用；S5-O2 产出、反馈、恢复和维护同时保持；S5-O3 边界开放、保护与退出可执行，成本回流；S5-O4 漏洞审计能写回。 |
| 反例 | 资源繁荣、选择性指标、投诉渠道失效、恐惧服从或把维护债推到未来，都能制造“成功”外观。 |
| 证伪 | 纳入维护、恢复、退出和外部成本后效率优势消失，或中心低介入时局部故障迅速级联，则撤回 S5。 |
| 尺度 | 管理层总量必须拆到维护者、低权力承接者、退出者和外部影响位置；覆盖高低负荷、扰动、恢复与维护窗。 |
| 证据升级 | 高效协调成因与漏洞效应须 G2/H4；历史留痕、载体持续作用与额外残差分别按 H5、§4.5 与 G3；跨尺度复制须 D3/E5 映射与独立目标证据；闭合或转换主张另检 G4。 |
| 合同链接 | U01—U11；H1/H2/H3/H4/H5；G1/G2/G3/G4；C1—C12。 |

S5 不是“善”“成熟”或“可以输出模式”的标签。存续、增长和筛选不等于正当，也不能授权扩张、复制、接管或要求成员增加承担。

### 8.3.7　S6　自适应动态平衡原型

S6 描述集体拥有分布式承接、有效反馈、恢复、更新和新生成能力。常规波动不会长期锁定方向，自治单元能局部自稳、横向协同并获得上级兜底，候补梯队、岗位记忆、授权和交接使后来者能真正进入并修改旧安排。它通过持续校准维持功能，不是消灭波动。

| 检查面 | S6 诊断卡 |
| --- | --- |
| 入口 | S6-E1：中心低介入时，多个位置仍能感知、纠错、恢复和写回。S6-E2：新承接者、规则与边界可持续更新，不依赖同一批不可替代个体。 |
| 退出 | S6-X1：恢复变慢、波动放大、写回失效、中心依赖或承接断裂，转入回退等路径。S6-X2：使命结束、功能转移、分裂、合并、范式替换或 X0 改变对象合同。 |
| 可观察 | S6-O1 扰动后的恢复与二次失稳；S6-O2 多中心协同与兜底；S6-O3 新承接者从训练到真实接管；S6-O4 反馈、审计、申诉与规则修订持续闭环。 |
| 反例 | 强控制、弱信号消失、资源保护或中心隐性救火都能制造低波动；频繁换人和改组也可能只是人员耗材化。 |
| 证伪 | 可比扰动下恢复持续变慢、局部故障级联、纠错依赖单点，或继任者得不到知识、权限和保护，则撤回 S6。 |
| 尺度 | 需要跨扰动、恢复、继任和慢变量长窗；整体平均不能掩盖边缘伤害。冻结自治、横向协同、上级兜底与实际授权。 |
| 证据升级 | 调节、反馈和多中心安排的效果须 G2/CAUSAL；学习、制度记忆和代际承接先核载体保留及实际接续；留痕检 H5，额外历史增量检 G3；跨尺度外推须 D3/E5 与独立目标证据；闭合或转换主张另检 G4。 |
| 合同链接 | U01—U11；H1/H2/H3/H4/H5；G1/G2/G3/G4；C1—C12。 |

S6 不是绝对终态、无冲突社会或历史终点。它可以回退、分裂、被接管、转移功能、进入 X0 或崩解；它也不能替任何对象取得对他者的决策权。
